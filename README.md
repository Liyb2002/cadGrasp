# cadGrasp

**根据 working robot 的限制，联合设计工件的工作 pose 与支撑。Pose 是我们算出来的结果。**

之前的问题给定每个任务的 pose 和工作区域，再设计支撑。现在给定工作任务、工艺要求和工作机器人的限制，由系统选择工件应该怎样摆、每次处理哪里，以及需要怎样的支撑，使机器人能够在方便的工作位置和一定方向范围内完成任务。

## Ultimate demo：一台机械臂喷涂整只 bunny

一台工作机械臂在固定工位、一定的工具方向范围内喷涂。目标是覆盖整只 bunny 的表面。我们通过设计每轮的喷涂区域、bunny pose 和相应支撑，让不同表面依次进入机器人方便工作的区域。

当前 Step1 的定义：**可加工面 = 允许角度能够到达的物体表面 ∩ 工作框内的物体表面。** 先计算 +X 初始落桌兔子的世界 AABB（不绘制），工作正方体的三轴边长均为物体 AABB 最长边的一半，贴着靠机械臂的物体边界，朝物体内部伸入，共用这一面的中心。限制的是表面加工点／针尖 TCP，头部和针根可在框外。

当前工作空间为正方体，边长 **0.5 × max(物体 AABB 三边) = 77.393 mm**，贴靠机械臂的一侧向物体内部延伸。针长 100 mm、针半径 2 mm、头半径 20 mm，允许偏转 25°。当前仍为固定六 task 预览，去重后覆盖 **51.56%** 表面积；最终任务数量另求。图、代码及结果见 [whole_task/README.md](whole_task/README.md)。

**每次喷哪一块、工件怎样摆、使用怎样的支撑，需要共同求解。** 喷涂分区和各轮 pose 都不预先固定。

### 输入

- Bunny 的几何，以及整个表面都要完成喷涂的任务。
- 工作机器人的模型、固定基座、喷枪和允许的工作位置／方向范围。
- 喷涂工艺要求，例如入射角、喷涂距离和覆盖标准，以及工作台、重力与障碍物。
- 给定的工件抓取和轮次间重定位设定；物体抓取本身不作为设计问题。

### 输出

- 喷涂轮次，以及每轮实际覆盖的表面区域。
- 每轮 bunny 的朝向和位置。
- 每轮使用的支撑、接触关系和安装摆放，并联合考虑跨轮支撑复用。
- 满足工作机器人限制的喷涂路径，以及与实际支撑对应的几何、承载和运动验收结果。

### 核心耦合

喷涂区域决定机器人需要接近哪些表面；机器人的工作范围限制这些表面可以采用的 pose；pose 又决定支撑需要哪些接触和落地结构。支撑材料也会遮挡喷涂，因此分区、pose 与支撑必须协调。

当前六-task 预览严格按角度可达与框内表面求交，不补入打不到的面。后续执行还须考虑支撑遮挡，并验证实际喷涂与运动。

工具朝向符合方向范围只是筛选条件，还需验证喷枪可达、喷射通道无遮挡，以及实际机械臂路径满足关节和避碰要求。工具偏角与机械臂关节运动范围分别评价。喷涂方向范围由工位和工艺设定，不能直接当作机器人已认证的完整可达域。

支撑在每轮都须满足实际接触、承载、接地、连通与装卸要求。改变 pose 时按实际朝向更新力学条件，世界重力始终向下。先寻找满足完整喷涂任务与全部约束的方案；找到可行成品后停止，不追加精修。
