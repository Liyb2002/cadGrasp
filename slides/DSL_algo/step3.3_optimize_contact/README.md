## 目标

```text
efficiency(r) = 联合覆盖率(r) / (旧头总接触面积 + 新头接触面积(r))
```

联合覆盖使用全部旧头、新头和工件原地面支点共同求解，每个载荷还须满足所有头共享的不上抬约束。只有效率提高才改变初始半径。第一轮分母只有新头面积，后续必须加上旧头面积。提高效率可能牺牲部分覆盖，完成条件须在优化后重新判断。

## 半径约束

- 新头实际曲面面积严格大于 `0.005 × A_object`，其中 `A_object` 是完整物体表面积。`area_limit.py` 用曲面裁切面积二分找下界，不以 `πr²` 替代。
- 缩小时仍须让当前整个组合承受纯重力并且不上抬；`size_search.feasible_radius_floor()` 进一步提高半径下界。
- 扩大时受连通域、整块法向夹角、物体/地面净空的几何上界约束。
- `insertion_limit.py` 限制半径，使实际新头至少保留一个与旧头共享的完整退出方向；不是仅要求新头独自能退出。使用选头前的共同方向集，未决方向不接受。

当前 `ENFORCE_PROCESS_ACCESS=False`，不启用加工射线体积限制；真实工作面仍须避开。旧禁区约束的实现保留，但不能把它写成当前默认模型。

## 尺寸搜索

在嵌套的同中心区域内，覆盖数和总面积随半径非减。对 `[a,b]` 中任意半径，有

```text
count(r) / A_total(r) ≤ count(b) / A_total(a)
```

`size_search.py` 优先细分效率上界最大的区间，不假设效率可导或单峰。默认相对间隙目标为 0.1%、最多评价 512 个尺寸，并有相对初始半径 `1e-5` 的半径分辨率。报告最优已计算尺寸、剩余上界、间隙和 `converged`；预算终止不冒充收敛或全局设计最优。

初始、最优和最大尺寸均从导出的实际三角面重新验证面积、受力、几何及方向。Scheduler 再更新所有头的共同方向交集，旧头几何签名一致时可复用其方向证据。若最终交集为空，停止为 `no_common_insertion_direction_after_optimization`。

Step3 在候选初筛时已经排除初始面积不足或初始几何/共同方向不合格的候选；本步不会把这些候选重新救回搜索。
