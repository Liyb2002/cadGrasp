用户决定：取消“每个头先固定长向另一 pose 的地面”。头服务哪个地面、脚面由哪个身体提供、身体之间如何连接，应该根据最终共同用料一起选择。允许所有头暂时先服务一个地面；最终两个 pose 的地面需求都必须满足。

## 先列问题

1. **什么叫地面覆盖？** 实际接地集合的凸包应包住该 pose 的原有需求撒点，不要求在凸包边界造实体圈。覆盖凸包只是几何目标，完整耦合力学仍需原验收器确认。
2. **一次生长如何有意义？** 不能仅以“这一步新增包住几个撒点”打分；两个脚可能必须一起出现才有收益。候选动作至少是能接到一个未满足要求的完整材料路径，也可以是一组共享分叉。
3. **如何同时选脚和连接全部头？** 地面接触位置必须是可选的；所有原头是必选的；中间允许公共分叉。不能先把脚固定再最短连接，也不能把每个头限制到某个地面。
4. **什么成本代表省材料？** 已有头是常量，共享的新增材料只能计一次。还需固定材料尺度，否则可以把连接无限缩细，体积比较失去意义。
5. **路径如何成为合法实体？** 有厚度材料必须同时避开两 pose 的物体、完整退出扫掠和地面以下区域。中心线无碰撞、图连通都不足以保证最终实体合法。
6. **如何避免一次贪心把后续锁死？** 允许替换、剪枝、不同起点；小图使用现成求解器作对照。有限候选失败不等于几何不可行。

## 保持不变的范围与判断标准

- 首版对每个合法摆放单独求解；摆放和退出方向沿用现有外层候选搜索。身体生长方向和地面归属在内层自由选择。
- 沿用目前明确声明的六物理接触面、五标识基线；本提案没有解决或重新定义严格五头的共享接触注册。
- 原接触头实体/表面作为不可删除区域，工作物和地面的位置、原有 32,768 个载荷不变。几何分离约束不产生新物理载荷。
- 硬条件优先：保留头、两地面包围、单件实体、避障、退出、原载荷全通过。完整可行解之间比较真实并集体积，再比较运行时间和边界参数敏感性。
- 沿用现有连接尺寸作为首版材料尺度的参考，明确记录分辨率和有限厚度条件；不把它解释为强度/刚度认证。
- 体积下降可能鼓励共享路径，但不保证每个局部身体发生跨 pose 的承载角色复用；该目标要另做几何/反力诊断。

## 对应哪些已有算法

| 子问题 | 可以复用的经典方法 | 本项目仍需实现的接口 |
| --- | --- | --- |
| 两 pose 都允许材料存在的空间 | 配置空间障碍、Minkowski 膨胀、布尔运算 [1] | 合并两套扫掠；正确保留原接触头及合法连接入口 |
| 地面哪里还不够 | 凸包、支撑函数、分离约束；Qhull [2] | 将覆盖缺口转成候选落脚位置组；候选不足时扩展/细化 |
| 选落脚位置并连接全部头 | Group Steiner Tree，节点带成本的连通覆盖建模 [3,4] | 把实际材料、头、真实落脚面映射为同一张图 |
| 找一条便宜的新增材料路径 | Dijkstra 多源最短路 [5] | 边/节点权为新增材料成本，已有共同材料置零；路径必须有实体实现 |
| 改善早期贪心选择 | 剪枝、路径交换、节点插入；Steiner 局部搜索 [6] | 交换后复核两地面、连通和原力学；保留最后一个完整通过结果 |
| 小规模检查贪心是否选坏 | MILP + 网络流连通约束，HiGHS/SCIP [4,7] | 表达节点选择、group 覆盖和根连通；记录最优界/求解状态 |

这不是声称存在“直接输入几个接触头就返回最优支架”的现成程序。已有算法解决离散选择和路径问题；几何表示、覆盖要求、实体检查是本项目的接口工作。

## 为什么最接近 Group Steiner Tree

经典问题给定图和若干节点组，选一个低成本的连通网络，每组至少触及一个节点 [3]。这里建议的映射是：

- **共享材料单元**是图节点，成本是新增体积；只有实体有合格接合面时才连边。
- **每个原头**是必须接入的终端。头可以先收缩成单个图节点，新增成本为零。
- **每条地面覆盖要求**对应一组备选接地单元，组内任选一个即可满足该条要求。每 pose 有多条要求，不能只给每 pose 一个 group。
- **中间材料节点**可以成为共享分叉，也可同时带来地面接触；不存在专属于“头”“脚”“连接杆”的三套新增材料预算。

最小生成树适合作固定终端连接的对照；这里还有可选落脚位置和可选分叉。普通 set cover 没有实体连通约束。Group Steiner/连通覆盖更贴近统一选择，但节点成本、地面包含和力学约束的组合仍需建模，不能照搬经典论文的近似率。

### 将“包住撒点”写成可选落脚组

以下是本项目的数学建模推导。令 D_k 为第 k 个 pose 原有撒点的凸包，F_k 为最终实际接地集合。令 h_X(u)=max_{x∈X} u·x，则

    D_k ⊆ conv(F_k)  ⇔  h_Fk(u) ≥ h_Dk(u)，对所有平面方向 u。

对一条给定方向要求 (k,u)，把实际接地部分能够达到 u·x ≥ h_Dk(u) 的材料单元放进同一个 group。选中组内任意一个，就满足这条极值要求。地面上的其他位置和边界段不必造实体。

先取少量方向作初始约束。每次构造候选后，计算实际接地凸包，用其边界检测原需求凸包顶点。发现遗漏，取分离方向并加一条 group 约束，再求解。最终验收是完整凸包包含，不能只看有限方向是否全部达标。

新增 group 为空时，应扩大候选落脚区域、细化材料表示，或换外层摆放；这只说明当前候选不足。退化为点/线的接地集合需用仿射维度与分离测试处理，不能调用 Qhull 失败后当成已覆盖。

## 我建议的统一贪心

1. 建立两 pose 共同合法的有限厚度材料候选图和初始覆盖 groups，保留全部头。
2. 选一个头作为**计算起点**，从它所在的连通部分开始。这个 root 不代表物理底座，也不规定哪个头服务哪个地面。换起点可以重试。
3. 每轮从当前连通部分，向任意尚未接入的头、或尚未满足的覆盖 group 求候选增量路径。路径沿途命中的其他头、地面要求、共享分叉都一并算收益。
4. 按新增材料与完成要求的收益选择动作；在离散图上，已选材料不重复计费。允许少量分叉/成组动作，避免只看一条最短路径的局限。
5. 更新真实地面覆盖、所有头接入状态与材料成本；缺方向就加约束。覆盖和连接始终处在同一循环里。
6. 得到可行候选后，尝试删除冗余材料或局部路径替换。任何几何修改都需保持最终完整验收；不能只保持旧的有限 groups。

这是一种借鉴 Steiner 最短路构造的工程启发式，**不是已有近似率直接适用的标准算法**。尤其不能随意增加很多相近方向，再按“group 数”给某一侧重复奖励。需要合并相同要求，控制方向分布，并以完整可行体积比较不同启发式选择。

连接其他已存在但尚未接入的头，也是一种待满足需求。多源最短路的源只能来自当前真正连通的部分；不能把所有散开的头当成已互通的零成本源。不得通过没有实体的虚拟 group 节点把物理上分离的区域“接通”。

## 材料表示是第一项实现决策

**严格可加的首版表示：** 将共同合法空间划分成内部不重叠的有限材料单元，选中一个只付一次体积成本。相邻单元必须有有效接合面，不能只在顶点/边上碰到。斜地面处记录裁切后的真实接地面，并防止裁切留下任意薄的连接颈。

这使节点体积和选中材料并集体积一致（边界零测度除外）。图分辨率决定候选丰富程度，不等于连续空间的最优解。选中单元的真实并集仍需封闭性/连通检查；图连通不自动保证表面网格没有非流形接触。

**保留当前 loft 外观的替代：** 使用合法局部 loft 和有限厚度通道作为候选，按真实布尔并集体积计算增量。这更接近现有好看样例，但重叠 primitive 成本非加性，不能把各自体积求和后叫作真实材料最小。可用共同体素占用作计费近似，但最终必须报告实际体积误差。

建议先用小材料图确认统一选择有效，再比较单元表示与 loft 候选的外观/成本误差。首版不承诺平滑网格质量或强度；后续重建/光顺如果改变材料、脚面或头附近几何，需重新验收。

## 可以直接使用的求解工具

2026-09-27 本机只读检查：cadgrasp 环境已有 SciPy 1.17.1、NetworkX 3.6.1；`scipy.sparse.csgraph.dijkstra` 和 `scipy.optimize.milp` 可导入。没有安装 PySCIPOpt、OR-Tools 或独立 highspy；SciPy 的 MILP 接口本身可用，无需因此先增加依赖。

小图基准可以这样交给 MILP：

- x_v∈{0,1}：是否选材料节点；所有头强制选中。
- 每个 group 要求 Σ_{v∈group} x_v ≥ 1。
- 根以外每个选中节点消耗一单位虚拟流；根供应总量；流只能经过选中节点。边流上限用图节点数作有限连通容量，该流不代表物理反力。
- 最小化 Σ_v volume(v)·x_v。

这是连通 group 覆盖的有限图模型，省去了自行实现整数优化器。它对给定 groups 的最优性仍不等于完整凸包、连续几何或力学最优。分离约束加全之后仍要跑原力学验收；当前不把全部载荷直接塞进首版 MILP。

SCIP-Jack 官方资料明确支持 group Steiner、node-weighted Steiner 等相关变体，已有最短路构造和局部改善模块 [4,6]；组合约束/节点费用的具体输入转换还需核对。NetworkX 的 `steiner_tree` 接收固定 terminal_nodes，适合固定脚位置的连接对照，不会替我们完成可选脚面的 group 选择 [8]。

## 本轮反例与独立审阅

本轮只做了二维数学诊断，没有新增物理载荷，也没有运行新的 B 支架构造。

1. 基础脚点为 (-0.1,-0.1)、(0.1,-0.1)、(0,0)，需求点为 (0,1)。候选脚 A=(-1,1)、B=(1,1)。基础、基础+A、基础+B 均未包住需求点，基础+A+B 才包住。Shapely 检查结果为 False、False、False、True。这反驳了直接按“新包住撒点数”套用普通覆盖贪心的前提。
2. 需求凸包为 [-1,1]²，脚点为 (±1,0)、(0,±1)。四轴方向的极值检查全通过，但脚点的菱形凸包漏掉四角。即使方向来自需求凸包的边法向也不足；在 (1,1) 方向支撑值差为 1。
3. 独立审阅确认上述两点，并补充：重复 groups 会扭曲贪心收益；重叠杆件成本不能直接相加；根只能是计算起点；图连通、地面包围均不能代替真实实体和原力学验收。

候选方向记录：A=对几何动作直接按覆盖增益/并集体积贪心，保留作对照，因互补性和收益权重问题不作为首版主定义；B=共享材料图+groups，推荐先建立；C=有限图 MILP，推荐作 B 的小规模质量基准。本轮仅完成方案和反例核查，B 尚未实现，本文不声称它已比当前四组通过结果更好。

## 建议实施顺序

1. 固定原 pose1+3 的接触与摆放，建立共同材料图、真实落脚数据和包含检查；原好看实体留作参考。
2. 同一小图分别运行统一贪心与 MILP。记录完整通过率、真实并集体积、图成本误差、运行时间及离散分辨率敏感性。
3. 复核每 pose 原有全部 32,768 载荷、原头保留、两地面、完整退出和单件封闭实体；几何覆盖通过但力学失败需明确保留失败状态。
4. 局部剪枝/替换后重复完整验收，再接入已有外层摆放搜索和 B 五组批量。失败原因区分候选不足、贪心选择不佳、几何违规、力学失败。
