# 直接在规则身体上做统一贪心

目标：保留 reference 的“头后面直接展开一整块身体”的形状语言，同时让头的生长方向、两个地面的落脚和实体连接一起选择。单组入口为 `run_loft_growth.py`；`run_loft_batch.py` 在各自 reference 的摆放下独立运行全部五组 B 配对，逐组记录成功或失败。实测结果见 README 和各组的 `latest_run.json`。

## 四步

1. **生成可选的整块身体和短连接。** 固定原头，用头截面、向后 8 mm 的截面和地面小脚面生成直面 loft；另有头到头的整块连接候选，以及在可选投影身体之间生成的短连接（半径 4 mm，总长不超过 40 mm）。这些短连接从一开始就在同一个候选图里，锚点仅用于提出位置，图的连接必须有实际材料重叠。脚面来自两套原撒点凸包的偏移极点、外接矩形和包围盒外侧中点，包括切向长脚面和固定方向脚面。不是实体围框，也不固定哪个头必须服务哪个地面。两个姿态的物体及 500 mm 退出空间共同裁切所有候选。
2. **一次选择同时解决三个需求。** 把真实重叠的候选组成图；所有头、两个地面的覆盖方向都是待满足条件。Dijkstra 提出几条可以接到已有实体上的候选路径，再比较它们真正新增的布尔并集体积与新增满足条件的加权收益，选收益相对成本最大的动作。公共材料只付一次成本。没有独立的“最后再连起来”阶段。
3. **同一个头的身体直接长大。** 若同一头向同一地面增加脚面，先用全部脚面重新构造一整块 loft，再计算这一步实际增加的材料。填进两脚之间的材料也要付费，因而不鼓励不断叠小翅片。这发生在每个候选动作的比较之中。
4. **用实际实体闭环。** 检查真正的地面凸包和每个 pose 原来的 32768 个载荷。某个原载荷失败时，利用反力锥分离向量添加必须满足的落脚候选组，仍在同一算法里选择。通过后，带着累计约束从第一个头重新贪心，并至多再做 8 轮原载荷反馈；仅接受更小且完整通过的结果。最后逆向删除冗余候选，每次删除必须重新通过所有实体、接触、地面、退出和原载荷检查。

## 成本与形状的关系

设当前已选候选为 `S`，其实际生成实体为 `B(S)`。动作 `P` 的成本是：

`ΔV = Vol(B(S ∪ P) \ B(S) \ H)`，`H` 是所有必须保留的原头。

头是固定成本；身体不是各候选体积的直接相加。尤其同头同地面的两次扩展可能填出更宽的整体，所以计算成本时必须先重建 `B(S ∪ P)`。

收益对头、每个 pose 的地面方向、每个 pose 的载荷反馈组分别归一化；约束增加后相应组权重重新计算。候选路径生成采用可加的单体积近似，最终动作选择采用真实的并集成本。因此这是有限形状族内的工程贪心启发式，既不声称找到每次最便宜的所有可能路径，也不声称全局最优或标准次模近似率。

**当前最小化的是实体体积；同时单独报告外表面积。** 两者必须区分，体积下降不能写成面积下降。规则 loft 是明确的几何先验，不能把“好看程度相同”当作已经量化验证的结论。后处理只负责实体导出所需的极小数值修复；不会把体素网络再凸包化来决定外形。

## 比较和验收

- 同一组 Step1–4 数据、原头、摆放、原载荷、接触及退出约束。reference 的手工脚面坐标不进入候选库；原 `reference_*` 文件保持不变。
- 导出一个实际封闭连通的 OBJ / mm STL，独立重建物体与支架的平衡方程，重放全部原始反力证书，再导出 PNG。
- 有限候选族或反馈次数失败只代表本次搜索失败，不能推出几何问题无解。通过刚体反力验收不证明强度或刚度相同。
- 公共材料只计费一次描述的是实际空间并集，不证明每处材料在两个 pose 中都承载。
- 当前沿用 reference 的**六块物理接触面、五个 ID**。两个黄色面仍是两份实体；严格五头共享问题没有在这次形状更新中解决。

## 代码

- `loft_candidates.py`：自动脚面菜单、完整身体及真实重叠图。
- `loft_joints.py`：从可选身体提出短连接，加入同一个图，不预先指定需要哪段桥。
- `loft_growth.py`：统一路径候选、动态整块身体及真实增量成本。
- `loft_acceptance.py` / `loft_refine.py`：实际实体检查、完整验收后的逆向删除。
- `run_loft_growth.py` / `publish_loft_growth.py`：原载荷约束反馈、受约束重新贪心和独立验收后的发布。
- `run_loft_batch.py` / `publish_loft_batch.py`：五组独立运行、失败记录和明确区分新结果的 PNG 总图。
- `test_loft_growth.py`：共享材料只计费一次、同一动作服务两个地面并连头、短连接与脚面共同选择、整块扩张的间隙材料计费、禁止用数值清理隐藏真正断开的实体。
