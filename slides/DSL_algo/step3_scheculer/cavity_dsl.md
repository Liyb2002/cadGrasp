# Joint common-cavity search

This round starts from the qualified absolute-direction/local-compaction/floor-recovery final of each saved B set. Historical sources and witnesses are immutable. Head count is not an objective.

A shared upward opening permits each object stance to translate in XY and rotate about that opening. Candidate operations rotate a stance about its installed contact centroid, move its object centroid toward the other stances, and combine both. Small and large yaw candidates include reaction-normal alignment proposals. A coarse score combines the aggregate workstation box of installed contact/demand clouds with the union area of projected object convex outlines. This encourages overlap of the negative space used by alternative object poses. These shapes need not coexist physically. Neither the proxy nor projected outline overlap is treated as a certified final space metric.

Fixed contacts can prevent this overlap. Every proposal checks actual root solids against all foreign continuous withdrawal sweeps. Blocked contacts are removed and replaced by connected patches compiled on the actual non-working surface, with native floor clearance and each pose's local exit. Candidate radii vary, including larger patches. CUDA float64 NNLS ranks additions against sampled and failed loads, but all 32768 original loads must pass the exact Step3 classifier. No candidate gets a fabricated normal. After all affected poses are repaired, the full foreign-root check repeats, because changing one pose's contacts can affect the rest. Contact count is free to increase or decrease.

Only a complete qualified branch can continue searching. The latest copied EnvelopeGrow constructs one connected support with full withdrawal/working/floor/ground-coverage acceptance, complete 5 mm cores and documented contact-transition exceptions. Floor vertex restrictions are applied during generation. Each construction has one in-memory acceptance and no exported-body geometric replay. The actual latest Step5 aggregate XYZ occupied volume decides whether to replace the public incumbent; larger qualified branches may be compacted without replacing it. Failed repairs or constructions preserve the incumbent.

Current finite search uses two rounds, up to three distinct stance proposals per round, an exact foreign-sweep local XY compaction after qualified proposals, and qualified common-up alternatives for an incumbent whose floor orientations differ. It is not a global optimum or proof that rejected layouts are impossible. Additional yaw/translation starts or a larger real contact pool may improve a set that remains unchanged.

Run all saved sets with `PYTHONPATH=slides/DSL_algo .venv/bin/python slides/DSL_algo/step3_scheculer/run_cavity_batch.py --jobs 3`. Use `--resume` only after any previous run has finished. Results live in each set's `step3_scheculer/dsl_cavity`, public Step4 and `step5_evaluate`. The comparison with the previous qualified direction optimizer is in `output/B/pose1+3/step5_evaluate/cavity_comparison.md` and `.png`.
