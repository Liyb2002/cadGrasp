# Value network：多 pose 的接触组合搜索

状态：2026-10-02 的方法设计，尚未实现训练或替换 baseline。当前讨论以固定候选、固定接触面积为起点；网络结构、训练预算、最大头数及权重尚待实验确定。

![Value：剩余补全头数与最终退出方向分散度](value.png)

## 要解决的问题

当前 Step3 按加入一个 head 后的即时载荷覆盖增量选择候选。我们改为预测后续补全的价值：一个目前贡献小的 head，可能与后续 head 互补，以更少的头完成任务。

同时，不能各 pose 独立追求受力成功后才考虑构造。各 pose 相对于物体的退出方向若分散，Step4 往往需要把接触结构和摆放分开；方向相近则有机会将结构集中在物体的同一侧。方向相近是紧凑性的引导，不保证最终实体体积小；接触位置、地面、摆放和完整 sweep 也会影响体积。

## 状态与动作

任务包含 m 个 pose。状态 S 同时保存所有 pose 的已选 head 集合 S_k、候选池、载荷需求，以及各自剩余的共同退出方向和连接通路集合。一个动作 a=(k,h) 是为 pose k 加入候选 h。

各 pose 可以使用不同 head，不强制继承旧头或共享某个 head。目标是让所有 pose 都成功，并给 Step4 留下容易紧凑构造的方向选择。物理实体是否共享接触部位不是预设要求。

候选本身的合法性由 Step2 提供，不重复作为学习目标；已选 head 的动作由 policy 屏蔽。

## 四项条件如何处理

1. **力与力矩平衡**：最终每个 pose 的全部 Step1 原始 32,768 个载荷必须通过；每个载荷用同一组非负接触反力同时满足六维平衡。不同载荷可重新分配反力，不追加连续域载荷或反例。
2. **整体不上抬**：仅要求最终完整组合满足。对每个载荷，头部作用于工件的总竖直力非负，与六维平衡联合求解；不包括工件自身的地面反力。不要求中间前缀受力或不上抬通过，不要求单个头的竖直力非负。
3. **连接通路**：每次加头，检查该 pose 所有头可接入的公共路径连通分量。为空则该动作死亡。当前实现使用预计算的路径分量集合求交。
4. **共同插入／退出**：每次加头，检查该 pose 所有头的合法退出方向交集。为空则该动作死亡。当前实现使用预计算方向集合求交。

只增添固定头时，上述交集只能缩小，后续加头无法恢复空交集。这里“死亡”是当前候选与预计算方向／通路模型下的分支淘汰，不是对任意连续路径的无解证明。

条件 3、4 的 Step3 检查可以快速完成，因此不需要为每次候选评分运行 Step4。Step4 仍需构造真实有限厚度支撑，检查完整实体的连通、退出、工作面、地面和接地需求。头组检查不替代最终材料的复核。

## 退出方向如何比较

各 pose 的方向必须转换到同一个物体坐标系。若采用列向量，pose 的刚体变换为 x_world=R_k x_obj+t_k，则退出方向 d_world 转换为 d_obj=R_k^T d_world；平移不影响方向。实现采用行向量时须使用对应转置约定。所有方向统一为同一个相对运动的退出符号，不能混合“支撑退出”和“物体退出”的相反箭头。

记 D_k(S_k) 为物体坐标系中的单位合法退出方向集合。保留整个集合，不提前固定一条方向。定义方向分散度

\[
D(S)=\min_{d_k\in D_k(S_k)}
\frac{1}{\binom{m}{2}}\sum_{i<j}
\left(\frac{\arccos(\mathrm{clip}(d_i^T d_j,-1,1))}{\pi}\right)^2.
\]

D 无量纲，取值在 [0,1]；同方向为 0。退出方向有正负，不能用绝对点积把相反方向当相同。单 pose 单独定义 D 为 0。两个 pose 时取两组合法方向中的最小夹角：0° 对应 0，90° 对应 0.25，180° 对应 1。目标不强制跨 pose 方向完全一致，只鼓励保留相近方向。上式是目标定义；有限方向目录上的计算方式另行实现。

当前 D(S) 可以作为输入特征和搜索引导，但 value 预测的是补全后的最终 D(S_final)：后续加头可能删掉目前最有利的方向。

## 最终 value

网络评估动作 (k,h)，预测从加入 h 后到成功终局的两个量：

- N_remaining：还需要添加的 head 总数，跨全部 pose 求和，不含正在评价的 h。
- D_final：最终所有 pose 的合法方向集合能达到的最小方向分散度。

给定加入 h 后搜索找到的成功终局 S*，剩余头数直接计算为 `N_remaining = |S*| - |S| - 1`。例如当前 4 个头，加入 h 后为 5 个，最终 8 个头成功，则剩余补全头数为 3。头数和方向分散度必须来自同一个成功补全，不能分别从不同方案取最好值。

成功补全的代价为

\[
C=N_{\rm remaining}+\lambda D_{\rm final},\qquad \lambda\geq0.
\]

学习目标是指定补全搜索器、剩余头数上限和计算预算下的预期终局代价：

\[
Q_\theta(S,k,h)\approx\mathbb E[C\mid S,\text{先选 }(k,h)].
\]

**Q 越低越好。** 当前一步覆盖多少载荷不是 value 的定义。剩余头数使“很少头就成功”和“堆很多头才能成功”有区别；方向分散项让局部受力选择顾及多 pose 的构造紧凑性。lambda 表示愿意用多少个额外头换取方向一致性的改善，是待确定参数，不作为已验证设置。

网络可分别输出 N_remaining 和 D_final，再合成 Q，便于理解和调整权重。不同深度的部分分支比较时，使用“已选总头数 + 接下来这个头 + 预测剩余头数 + lambda D_final”，避免奖励已经多加头的分支。同一状态内比较候选时，前两项相同，可以省略。

不能仅在成功补全上计算条件期望而忽略失败。训练记录必须保留预算内失败和未决结果；最终标量目标需采用统一失败代价（高于允许预算内的成功代价），或另外预测完成概率并显式纳入排序。该处理尚待实验确定。失败不是合法终局，也不能用 D 小抵消受力失败。

## 数据与训练

在多个 shape 与多 pose 任务上进行比在线阶段更充分的补全搜索。采样部分状态及动作，强制先选该动作，记录后续搜索找到的成功终局、追加头数、最终方向集合与分散度、搜索预算和失败原因。包含零即时贡献候选及 baseline top5 之外的分支，避免只模仿 greedy。

“找到还需两个头的方案”仅证明两个头足够，不能直接标为数学上的最少头数。只有更少头的组合已充分检查，才能给最少值标签；否则保存找到的最好代价、已检查范围和未决状态。多次 rollout 使用统一规则和预算，不能把预算耗尽当作不存在成功补全。

第一版可使用 head 接触点的位置／法向／六维反力生成元、代表需求、各 pose 的方向与路径集合、已选标记和剩余预算，通过集合交互为所有合法动作输出两项预测。不要求对反力求解或几何检查反向传播。网络需看见全部 pose 和剩余候选，才能表达后续互补与方向耦合。

训练／测试按 shape 划分。与当前 top5、多分支无学习搜索在相同预算下比较所有 pose 的成功率、最终头数、方向分散度、时间及求解次数；另用 Step4 验证最终实际占用空间是否改善。离线标签和训练成本单独记录。

## 在线搜索流程

多 pose 状态 → 屏蔽重复动作 → 快速方向／连接通路筛选 → 网络预测剩余头数与最终方向分散 → 扩展少量低代价候选并保留多个不同分支 → 最终联合受力及不上抬验收 → Step4 实体构造与完整几何复核。

网络低分或高分不作为物理证明。最终不上抬检查不用于杀死中间前缀。任何 pose 路径交集为空则当前分支死亡；所有 pose 受力通过才是成功终局。
