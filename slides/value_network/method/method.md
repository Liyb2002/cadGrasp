# Value：共同绝对方向与实际占用空间

当前目标已改：**不优化头数；不在物体坐标系里比较方向。** 一大块连续接触区域也可以。旧的 `N_remaining + D_object` 标签和已经训练的网络保留为历史实验，不能解释为新版分数。

![新版分数怎样得到](absolute_value.svg)

## 用哪个方向

所有 pose 使用同一个工位世界坐标系。站着的兔子和侧躺的兔子，只要都沿工位 **+Z** 拿走，就是同一个退出方向；不乘各自物体姿态的逆旋转。

记 `e_k` 为物体退出方向，`d_k = -e_k` 为碰撞检查中支撑相对物体的移动方向。实际动作是**支撑留在地面，物体拿走**，不是让整个支撑向地下移动。完整碰撞检查用物体沿 `e_k` 的连续 sweep。

接触对物体的支持力由世界坐标的内法向提供。令各接触小面面积为 `A_i`，单位内法向为 `n_i`，朝共同方向 `e` 的几何偏离为：

\[
L_{align}=\frac{\sum_i A_i(1-n_i\cdot e)}{\sum_i A_i}.
\]

它是支持力方向的**几何引导**，不等于各载荷求解后的实际合反力。某个头的反力大小由平衡求解决定，不是固定等于面积。按面积计算而不是按头数计费，同一接触面分成十个标签不会被惩罚。

方向有正负，+Z 和 −Z 不算相近。跨 pose 的方向必须比较工位中的有向向量；实现中的 `absolute_spread` 保留这个区别。

## 四个条件仍然是硬约束

1. **力与力矩平衡**：最终每个 pose 全部原始 32,768 个载荷通过；非负反力同时满足六维平衡。
2. **整体不上抬**：只在最终组合检查，和六维平衡使用同一次反力求解。中间不满足可以继续加入接触。
3. **连接通路**：接触保留共同可达的路径连通分量；空交集的增量分支淘汰。Step4 还要真正造出一个连通实体。
4. **共同插入／退出**：本轮显式尝试所有 pose 的物体沿世界 +Z 退出，每个候选先通过整头连续退出。必须保留共同方向；Step4 再检查完整支撑、所有闲置接触和完整连续物体 sweep。

工作面、地板、接触保留和接地范围也沿用真实构造的检查。96 个载荷仅用于快速筛选；成功标签必须经过全部 32,768 个载荷。本轮只有固定 +Z 和有限平移搜索，失败不代表所有可能方向或连续空间都无解。

## 真正的最终分数怎么计算

方向相近不保证实体紧凑。一个直接把独立接触组都改成 +Z 的试验，在 pose3+6 反而增大了约 41% 的占用体积，因为闲置接触挡住其他 pose，导致摆放分散。

因此，成功终局先运行 Step4 构造真实支撑，再运行**原有 Step5**。令：

- `V_object`：所有保存的物体 pose 在原工位坐标中的共同 XYZ 包围盒体积。
- `V_supported`：所有物体 pose 和各 pose 中安装的同一个完整支撑的共同 XYZ 包围盒体积。

\[
C_{final}=V_{supported}/V_{object}-1.
\]

**越小越好，没有头数项。** 支撑材料体积另报，不替代 Step5 占用体积。不同 pose 不单独居中、换轴或改量纲。对于同一组 pose，这个分数与直接最小化 Step5 的 `V_supported` 等价。

对于 state `S` 和加入接触的动作 `a`，新版 value 要预测：

\[
Q(S,a)\approx\min_{\text{已找到的成功补全 }T\supseteq S+a} C_{final}(T).
\]

它是有状态的补全价值，不是每个头一个永久固定分数。暂时未找到成功补全的样本保持未标注，不凭有限搜索失败制造“绝对不可能”的标签。硬约束失败的动作由 policy 屏蔽。方向偏离、共同方向集合及跨 pose 的相互阻挡关系可作网络输入或辅助预测；不再把方向偏离简单混成头数分数。

## 新版网络需要记住的 state

状态仍包含所有 pose 的已选接触集合和候选；另外要保留工位中的接触位置、支持内法向、剩余退出方向集合及当前摆放／可用摆放范围。不能只用头编号或物体坐标中的方向判断其他 pose 是否会被挡住。网络输出预测成功补全后的 `C_final`；已有头数量不是训练惩罚。旧的身份 mask 可以继续作为输入的一部分，但旧 Q 输出的含义必须重新训练。

## 本轮实现与实验

几何搜索实现位于 [absolute_direction](../absolute_direction/README.md)，用真实几何和载荷验证新目标。后续已训练新网络，见 [train/absolute_volume](../train/absolute_volume/README.md)：由 20 个成功终局生成 1,280 个部分 state，并用另采的 320 个同组 state 检查拟合；新权重独立保存，未复用旧目标输出。

这版先针对固定已知 pose，用完整已选头身份 mask 和 pose mask 学习已验收解的体积 value、成功补全成员与摆放位置。真实绝对几何、共同路径和碰撞仍由现有代码作硬检查；尚未实现面向任意 pose 的几何 encoder。每组目前只有一个成功终局，同一终局中的未选头有相同的已观测补全成本，因此不能据此声称已经学会替代接触方案之间的体积优劣。推理不读取终局清单，由网络预测选头和摆放后重新跑 Step4/Step5；这是记忆与落地验证，不是未见组合泛化。

先联合选择世界坐标中各 pose 的 XY 摆放与可用接触：某个 pose 的头若阻挡另一个 pose 的完整退出 sweep，就从该布局的候选中排除。每个 pose 都必须仍有能覆盖全部载荷的接触组合。然后在共同绝对方向下尝试空间较集中的成功组合，复用 Step4 的完整杆件和接地生长，并用 Step5 实际测量。

这一版有限搜索先使用 +Z，不宣称找到了所有绝对方向中的最优解。搜索过程中的接触面积范围和包围盒下界只是便宜引导；实际改善必须看最终构造结果。最终逐组结果见 [实验报告](../absolute_direction/REPORT.md)。旧标签、旧训练权重和原 baseline 均保留。
