# Step5：头向最近合法地面生长的局部身体

**2026-09-28 纠正：下文六面样例已撤回，不能作为共享头 3+2 的有效结果。** 当前构造器先强制验证同 ID 的完整接触面和头实体重合，每个 ID 只建一个身体。五组保存布局均被拒绝；严格原接触配准后的地面必要条件也失败，详见 [当前状态](README.md)。以下仅保留旧构造的历史描述。

这是 pose1+3 原样例的构造方法。原样例的接触定义是五组标识、六块真实接触面，橙色有两块面；两个 pose 使用同一件刚性支架的不同摆放。

用户选择 **reference 局部身体构造作为主方案**，随后只将“固定另一地面”改为“最近合法地面”。这一步是快速、确定性的构造细节，论文中约 1/4 页即可；不再追求多轮体积优化。pose1+3 外层只保留最近地面样例的 `overview.png` 和 `shape.obj`，支持数据在 `data/`，原 reference 和统一贪心的数值记录在 `data/history/`，结果见 [README](README.md)。

- **头先长身体。** 将所有地面放在同一支架坐标系，按头实体到各平面的最短距离排序（包括自身 pose；并列按 pose 索引）。保留接触面，沿退出方向向背后延伸 8 mm；向目标平面投影，投影区域缩至 70%，用头、背部和投影脚面作局部凸包。按此顺序选择第一个裁切后仍保留原头、且连到实际脚面的候选。每个头必须有一块初始身体。
- **避开物体。** 裁掉两个地面以下的材料，以及两姿态物体完整退出扫掠占据的空间。恢复原接触头，保持接触面不变。
- **补足落脚范围。** 增加分散的小脚面，用斜向局部凸包把脚面接到身体。原样例用了八个固定脚面；自动版本按距离与新增体积选择身体，不生成外围实体框。
- **合成一件。** 优先在地面上方添加短连接。失败时，扩大两块身体之间的连接包络、减掉禁入区，让剩余材料绕障；必要时扩大到整个构造包络，使用其中能连接原身体的合法连通部分。每次实际减少连通分量，直到只剩一个封闭连通实体。兜底仍裁到地面以上并保持退出终点分离。
- **导出实体。** 构造过程保留裁切和连通性检查；默认关闭最终完整几何/受力验收与独立审计。需要时用 `--verify` 显式开启，使用原有的 32,768 个载荷，不增加样本。

原 pose1+3 的摆放、脚面坐标及归属保留在 `local_body_case.json` 和 `build_coupled_saddle.py` 的原参数中。用 `--floor-policy opposite` 选择原规则，reference 为 **141.425893 cm³**。最近地面变体只改变蓝色头的初始目标地面，体积 **135.849081 cm³**，一个封闭连通实体，两个 pose 全样本通过；构造约 1.29 秒，含退出空间预处理、完整验收和几何导出约 23.71 秒。数据来自本机一个样例，尚不是多 pose 或跨模型时间基准。

历史搜索入口对其他配对沿用同一构造：自动迁移/搜索摆放；若直接投影受阻，在投影附近寻找可连接的脚面；自动拟合局部终端。无法连接的终端不算有效脚面，仍以最终真实实体的完整验收为准。原样例固定参数的直接复现与新配对的自动参数搜索分开记录，不声称这是一套最优形状算法。

代码：[build_local_bodies.py](build_local_bodies.py)；当前快速批量入口：[run_fast_local_bodies.py](run_fast_local_bodies.py)。固定已有布局及脚面参数，持久缓存禁入区和已选构造决策；相同参数的冷、热运行使用相同网格边界表示。关闭审计不会自动把历史失败变成通过；本轮结果和计时见 README。
