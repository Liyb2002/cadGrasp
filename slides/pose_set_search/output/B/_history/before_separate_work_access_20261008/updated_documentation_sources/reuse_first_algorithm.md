# 满足全部力／力矩，减少共享支撑材料

这是用户最新目标对应的独立实现。生产 `Co-optimize` 代码和旧实验均保留；当前十组快速比较发布到 `pose_set_search/output/B/{pose1+2+…}/{whole,incremental}/`。

## 完整工作角度禁区修正（2026-10-08）

当前十组重跑结果保存在 `pose_set_search/output/B/`。从每个原始 `needs.json` 读取 `load.cone_half_deg`，B 的值为 **30° 半角、60° 总开角**。每个完整工作三角面上的所有点，沿外法线30°范围内的所有向外方向形成半无限区域；支撑不能占据其中任何位置。旧版本只挖5mm工作带，缺少此约束，旧十组结果全部找到实际遮挡反例，不能当作可行解。

`code/work_access.py` 把完整三角面与32边外接锥作 Minkowski 和，保守包含真实圆锥，径向最多多排除约0.484%。候选接触锁定和 Sobol 材料占据直接查询无远端面的半空间，不采样几条射线、不限制工作距离。实体构造使用同一禁区，只在整个候选贴合材料包围框之外截断；最终展示的蓝色支撑重新检查与所有完整外接工作锥的体积交叠。退出方向变化不改变工作法向和工作角度；平移或 Juxtapose 变换整个工作禁区。

对原工作三角面集合 $W_i$，禁区为

\[
\mathcal F_i=\bigcup_{f\in W_i}\{p+t v:\ p\in f,\ t\ge0,\ \|v\|=1,\ v\cdot n_f\ge\cos\alpha_i\},
\qquad S\cap Q_i\mathcal F_i=\varnothing.
\]

$\alpha_i$ 直接读原文件，$Q_i$ 为物体到支撑变换。整个工作三角面的所有点及30°内所有方向都需要排除；画面中的有限长度不限制搜索区域。

不可行搜索状态按整组未满足载荷数推进，允许尝试中暂时失去个别载荷，不把当前部分通过的载荷永久冻结。增量方法只有旧任务和新任务的全部原始载荷重新通过，才接纳该前缀；后续减体积操作仍须整组保持通过。失败前缀不会被报告为成功。

普通停滞先处理受力失败的任务。若仍无法改善，还检查哪些已经受力通过的配置正在遮挡失败任务：使用现有接触锁定列及覆盖计数排序，再明确提出这些 blocker 的 Juxtapose；不会把仍注册的任务偷偷平移。困难修复把 Juxtapose与其后最多3轮微调作为一个候选分支整体评分，分支失败的临时形状不进入已提交过程图。所有接受及成功仍用整组原载荷和原工作禁区判断。

基础8轮前沿搜索后，若仍不满足，最多追加3轮小步Direction及已有Juxtapose任务的Translation。它可以处理仅差少数载荷的局部停滞，不改成功标准；更长的继续搜索单独记录。LP返回数值未解决时，对同一原始列作正缩放、用小反力基在long-double中重解，并逐条回代原七维方程。容差仍为2e-9，只有有效非负反力或精确分离平面才能解决该数值分支；数值失败不能冒充物理不可行。

视频和普通过程、结果图不叠加禁区，保持单个固定等轴测视角、无视频文字，橙色工作面积和停顿1秒时的向内施力小箭头。禁区单独画在 `output/B/work_access_isometric.png`：同一pose1的8个环绕视角，琥珀色为原禁区与同一个球形显示截断面的交集，远端为圆弧。这个球面不是物理工作距离，也不修改禁区定义；实际算法仍同时排除全部活动 pose 的半无限禁区。此轮仍采用快速载荷采样，不运行完整压力证书验收。

## 通用搜索加速及历史完整验收流程

下文保留通用完整验收入口和以前的精确流程；当前十组使用 `search_only`，只做采样受力与工作禁区几何检查，不运行完整压力证书。旧体积及历史通过结论不能替代完整工作锥下的新验证。

`run_reuse_first.py` 默认使用 `--evaluation sampled`。以下精确逐候选流程保留为 `--evaluation exact` 和历史结果的构造说明。当前搜索候选改用持续的接触／空间占据状态，不生成 Boolean 实体：

- 接触点记录各 pose 的包裹覆盖和遮挡贡献。改一个 Direction 更新该 blocker 对所有任务的列；Translation／Juxtapose 同时更新移动任务的行和 blocker 的列。共享锁定计数仍大于零的点不能释放，失去最后一个包裹提供者的点不能当成接触。
- 在共同 Sobol 点上维护材料覆盖和物体／工作禁区／名义退出锁定计数，记录新增和删去的材料量。扩大采样域时统一重采样并重新比较当前状态，不把不同采样域的体积直接比较。
- 候选初筛使用原最难载荷及 guard；入选候选在采样接触模型中检查全部原载荷。复用仍保留全部原反力列的基，再回代原七维平衡；没有用面积限制反力容量。
- Juxtapose 每轮默认最多筛选 96 个候选，按 guest／host 分组并保留多种偏移与方向。此预算控制时间，不构成可行性或最小体积证明。
- 只有最终导出调用精确构造及全部原载荷／工作面验收。失败或超时不标成最终成功；默认最多回退到三个已经采样可行的整组状态。采样加入前缀没有逐个做精确实体验收，报告分别标明。`--search-only` 仅输出采样状态用于计时，明确没有最终验收。

精确构造也去重相同 body／sweep／包裹，并复用修复循环已经完成的交集诊断。保留原几何容差、接触核心、净空与载荷模型；加入分阶段计时，避免把 Boolean、接触和 LP 混成一个不明的耗时。

接触初筛还保留精确算法的原面朝向条件 `normal·local_exit <= 1e-9`，不能用射线未命中替代该条件。加速计时和验收证据见 [speed_search.md](speed_search.md)。

## 目标和变量

每个任务保存原来的世界物体摆放 `T_i`、工作面和全部 32,768 条载荷。优化变量仍是物体到支撑的变换 `Q_i`、支撑坐标中的退出方向 `d_i`，以及使用哪个原摆放作为 host。世界物体变换为 `T_host Q_i`；原世界旋转和高度保持不变，允许水平位置调整。

`Q_i = I, host = i` 是转动复用：物体在支撑中的局部摆放相同，同一个实体支撑随任务转到 `T_i`。完成任务后取出物体，再转动空支撑。局部退出方向相近，世界退出方向可以明显不同。

Juxtapose 改变困难任务的局部摆放：先取 `Q_i = inverse(T_host) T_i`，再提出地面切平面中的小偏移。该任务与 host 分别装入，物体不要求同时存在。Translation 在这个新的局部摆放上作调整，不挖横移滑动通道。

数学目标是

\[
\min_{\{Q_i,d_i,host_i\}} \operatorname{Vol}(S),\qquad
\forall i,\ \forall w\in\text{原保存载荷}_i:\quad
w\in\text{由实体 }S\text{ 的真实接触生成的可行反力锥}_i.
\]

另保留原完整退出和工作面约束。接触为原来的非负法向反力，地面为原四射线摩擦模型；第七维保留支撑合力不上抬条件。不把接触面积改成反力容量。

**支撑摆放数不是代价。** 精确评分先比较损失的已通过载荷、未通过载荷数，再比较真实材料体积；体积相同才用投影占地、Juxtapose 数打破平局。一个小支撑转动十次可以优于一个很大支撑只放一次。转动复用是优先探索的构造方式，最终候选仍按真实材料体积比较。

## 共同／相近退出方向初始化

把各任务的地面法向变到共同物体坐标中，求一个接近这些法向的方向；若公共地面合法方向不存在，保留一组相近、分别合法的方向。初始化不强制世界 `+z`，也不保证全部载荷可行。

Joint 从所有任务的 `Q_i=I` 开始。Incremental 从一个任务开始；新增任务取已有 **转动复用任务** 的局部方向平均值，不能把 Juxtapose 任务在不同物体坐标中的方向直接混合。Boolean／求解超时先尝试同一注册布局的相近方向，数值未解决不作为放弃转动复用的理由。

## 从最难载荷提出 Direction 候选

沿用现有 `Search.targets` 和 `Model.hardest`：在不满足的原载荷中寻找离当前反力锥最远的载荷，使用原尺度和含第七维的反力模型。初筛同时加入其他未满足任务的载荷及原载荷的坐标极值，最终验收仍是全部载荷。

微调方向只更新接触采样点是否被任何当前物体、工作面或退出路径锁住，以及是否进入当前贴合材料范围。多个相近方向可能共同锁住一块面积，因此同时提出：

- 每个方向切平面上两轴的有限差分下降候选，步幅 0.25°、0.5°、1°、2°、4°、8°；
- 最难任务及其他困难任务的切平面采样，步幅 0.5°、2°、5°；
- 全部退出方向一起转动的候选，步幅 ±2°、±5°。

这里求导的是原反力锥距离初筛损失对 `d_i` 的变化，采样点的释放／锁住决定接触反力锥；没有对每个微扰重建完整 Boolean。由于遮挡改变不光滑，有限差分仅用于提出候选，不能直接证明改善。

## Direction 停滞后选择性 Juxtapose

先进行至少三轮 Direction 搜索；若单独 Direction 仍不能容纳任务，再为当前失败任务提出 host 候选。host 优先已有通过任务，并按 **世界退出方向夹角** 排序。保留 guest 原世界路径、与 host 的中间方向、host 的路径三种候选，再检查地面合法性。

初始偏移包括原世界位置、地面内质心对齐，以及 1/32、1/16、1/8、1/3 个最大身位的轴向偏移。排除没有合理重叠的远距离摆放，不使用整组全部 Juxtapose／远距离分离保底。

入选 Juxtapose 分支再做 Direction 与已 Juxtapose 任务的 Translation，后者也有有限差分下降方向和多个步幅。仍处于 `Q_i=I` 的任务不能在这个分支中偷偷平移或迁移 host。分支内部可以暂时损伤旧接触；原子提交时必须重新检查整组任务，不能损失受保护的已通过载荷。每次提交后更新保护集合。

增量中，新任务尚未被接纳：即使其自身载荷通过，只要它的材料切除使旧任务失败，就允许这个新任务尝试 Juxtapose。不能因它“自己的力／力矩已通过”而排除它，转去不必要地迁移原来已通过的任务。

## 如何构造和检查真实支撑

当前各配置的 5 mm 贴合包裹取并集，切掉 **所有当前** 物体、工作禁区和完整退出。保留原接触核心处理，核心外沿用原 1% 净空。旧配置不再使用的切除可以恢复，仍被其他配置锁住的材料不能恢复。Translation 只改变设计终点，没有沿平移路径打通材料。

精确入选候选用原连续非凸扫掠、实体 Boolean、实际接触边界及每个任务的全部 32,768 条原载荷验收。用导出的最终支撑另行重提接触，保存所有载荷的非负反力并回代全部七维。面积初筛和占据采样不能替代这些检查。

## 可行后继续减体积

不会在“第一份可行支撑”处结束。先尝试把 Juxtapose 任务恢复为转动复用：提出共同／相近方向及 0.5°、2°、5° 微调，先用所有任务的原极值载荷做接触初筛，只给有希望的候选有限精确评估位置。只有整组全部原载荷仍通过且真实材料不增加才接受。初筛未入选不意味着恢复转动复用不可能。

然后为所有任务的 Direction、共同 Direction，以及已有 Juxtapose 的 Translation 继续采样多个步幅。固定 32,768 个 Sobol 空间点估计包裹并集减去当前物体／工作／名义退出后的材料占据。这个初筛不做完整 Boolean，不重复计算重叠材料。

从预测较小体积的候选中再按原接触反力模型筛选，保留 Direction 和 Translation 的候选位置。精确候选必须满足整组全部约束，并且真实实体材料体积下降超过原几何容差，才能提交。没有减少就停止本轮局部搜索。

保存每轮减体积的估计、真实体积、全部载荷数量、接受标志和原始布局。有限采样及固定预算不能保证全局最小。某次有限搜索失败也不是几何／承载不可行证明。

精确 worker 返回已经验收的双精度边界，父进程直接保存这些坐标和三角面，不重新导入 Manifold 来简化网格。报告材料体积与这个导出边界的体积一致；反力验收、工作面和图像都对应这一份实体。最终布局另行完整再生验收，避免沿用旧网格传输版本中的几何变化。

## 两种顺序

- **Joint**：全部注册 → Direction → 为失败任务选择性 Juxtapose／调整 → 尝试恢复转动复用 → 可行体积下降。
- **Incremental**：逐个注册新任务 → Direction → 必要时选择性 Juxtapose／调整 → 全部旧任务和新任务通过才加入下一个 → 最后可行体积下降。若某个前缀失败，停止加入，不把失败前缀作为成功历史。

同一个最终选择器按真实体积挑选搜索中保存的完整可行检查点，并重新提取接触和验收工作面；它不改变支撑或布局。源代码快照、输入、检查点与导出文件均保存哈希。恢复运行明确记录来源，不视作另一次独立初始化实验。
