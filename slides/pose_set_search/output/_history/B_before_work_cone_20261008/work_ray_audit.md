# 工作面射线约束：建模遗漏与现有结果反例

从每个工作面上的每一点，沿其外法线射出的整个半无限路径，都不能碰到任何支撑材料。向内的小箭头表示外部施力；外部到工作面的路径必须畅通。

当前实现仅扣除工作面外侧 5 mm 的棱柱。更远的支撑没有排除。原 WORK 检查也仅检查工作面相交和包埋，明确没有执行 processing ray volume 约束。这是候选材料与接触模型的遗漏，不能用“快速搜索、不做最终验收”解释。

**现有 20 个结果全部存在真实遮挡，当前可行结果为 0/20。** 144/166 个 pose 出现遮挡反例。每个原始工作三角面使用 28 个严格内部的重心坐标采样点，沿外法线发射无长度上限射线；命中点重新检查位于实际导出支撑三角形内部。命中是失败反例；未命中不能证明整个工作面积可达。

例如 pose1–10 / incremental / pose1：2520 条射线中 31 条命中支撑，最近命中距工作面 32.344 mm；whole / pose1 有 1636 条命中，最远约 62.813 mm。
