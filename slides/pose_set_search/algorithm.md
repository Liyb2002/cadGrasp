# 两种顺序，同一套三个 operations

此页保存前一轮算法。用户最新目标是满足全部约束后减少实际材料体积，支撑摆放次数不加惩罚；当前实现优先转动复用，再选择性 Juxtapose，并在可行后继续减体积。请使用 [新算法](reuse_first_algorithm.md)、[新结果](reuse_first_results.md) 和 `code/run_reuse_first.py`；原入口和历史源代码快照保留作复现。

每个任务保留物体原朝向、工作面、全部原始载荷、关于质心的力矩、原地面接触和第七维不上抬条件。配置变量是物体到支撑的刚体变换、支撑摆放的 host 和支撑坐标中的退出方向。工位中的横向位置可变；随物体平移加工点、质心和地面点，原始质心力矩不变。

## 几何与承载

对各配置生成原 Step3.2 同样的 5 mm 有限外包裹，在当前布局取并集，减去所有当前物体、完整退出路径和工作禁区。旧配置被替换后，不再扣它的退出通道；其材料可恢复。只有当前终点和装卸路径参与构造，不切出设计过程中的横移通道。

先按名义退出切除并提取实际接触，再保留这些接触下的合法有限深度核心；核心外切除原有 1% 膨胀退出。每个 pose 的实际接触变换回其原始任务坐标，与原地面反力一起检查全部 32,768 个载荷。反力系数非负、无上界；面积只描述几何，不能作为反力容量。

## 提出局部候选

使用已有方法找离反力锥最远的原始力／力矩需求：投影到当前反力锥得到残差，利用合法锥内点给其他载荷距离的安全上界，逐步排除不可能更差的需求。保持原力／力矩尺度和第七维。

具体计算是：对每个 pose 和其每个未满足的原始 `(力, 力矩)`，求非负反力组合到该需求的最近距离；挑选距离最大的那一对。写成式子为

\[
(i^*,j^*)=\arg\max_{i,j}\min_{\lambda\ge0}
\frac12\left\|G_i\lambda-\operatorname{target}(f_{ij},\tau_{ij})\right\|^2.
\]

这里 `G_i` 只包含当前接触、原地面接触和第七维的松弛列；`target` 使用原任务的力矩缩放及第七维零目标。每条接触列的力矩是接触点关于物体质心的力矩。工位、加工点、质心和原地面点一起平移，所以原始需求关于质心的力矩不需要重新生成。

方向和位置的梯度只通过接触几何初筛计算，不在求导时重建支撑。每个非工作三角形取四个面积积分点，检查它是否被任何当前物体、工作区或完整退出锁住，以当前可用点构成反力锥。对最差需求的距离作有限差分，提出下降方向及多个步幅。这个代理是离散的，可能出现零梯度；同时尝试单方向、联合方向、相关方向的共同转动，以及多个平移步幅，跨过接触释放事件。

设某个退出方向的单位球切向参数为 `θ`，这里的求导是

\[
\partial_\theta\,\mathrm{distance}^2
\approx\frac{\mathrm{distance}^2(\theta+\varepsilon)
-\mathrm{distance}^2(\theta-\varepsilon)}{2\varepsilon}.
\]

两次扰动只重新判断接触点是否落在当前包裹中、是否被任一任务的完整退出／物体／工作区锁住，再计算这些点的反力锥距离。释放和新增锁定一起计算。Translation 用相同方式对地面切平面内的位置参数求差分。当前方向差分用 0.75°，平移差分用物体最大尺寸的 1/100；梯度只给候选方向，最终步长仍从多个尺度中实际尝试，不是把差分尺度当作移动量。

方向候选包括单任务 0.5°、2°、5°，联合梯度 0.25° 至 8°，以及全体共同转动 ±2°、±5°。Juxtapose 后的局部平移步幅为最大物体尺寸的 1/128、1/64、1/32、1/16、1/8。本例最大尺寸约 154.8 mm，对应约 1.2–19.3 mm。每轮给不同工具预留真实几何评估名额，然后再分给不同 host 和步幅，避免一个初筛赢家占满所有名额。

初筛用当前最差需求、各失败 pose 的一条需求，以及每个 pose 原始六维载荷在各坐标上的极值，包含已经通过的任务。真正入选后重建完整材料、提取实际接触并重新检查全部原始载荷。代理排序不能认证成功。

最近点投影没有改动原反力锥：对原七维生成元作归一化，只用于数值求解，以七个变量求极锥的二次规划；随后用非负原锥系数回代，并检查每个原始生成元的 KKT 条件。完整载荷分类仍调用原独立平衡 LP，用非负扩展精度系数及原 2e-9 平衡容差批量回代，无法证明的载荷继续单独求解。地面仍是原接触点的四射线摩擦模型，μ=64，没有独立地面力矩，也没有新增接触力上限。

## Juxtapose 与原子提交

为困难任务选择已有任务的支撑摆放作为 host，保持其世界朝向，把物体表达在 host 的支撑坐标中。尝试原生位置对齐、地面切平面内的质心对齐及其附近重叠位置；优先用 host 的退出方向。包围盒重叠是候选过滤，实际物体重叠和材料代价还须记录，不把无重叠分离当作复用。

Juxtapose 后可以暂时破坏原接触，所以把「Juxtapose＋Translation／Direction 局部调整」作为一个分支评估。分支内部允许出现未合格的中间设计；最终提交必须恢复所有受保护的具体载荷。失败分支丢弃，不能以它的局部受力改善宣布原设计成功。

若一次单任务 Juxtapose 仍无法整组通过，尝试**成组 Juxtapose**：选择一个共同 host，保持每个任务的世界朝向，把几个互相阻挡的任务一起表达在该支撑摆放下。各任务先按其原始平均水平所需反力的反方向提出偏移；位移尺度采样 0、1/8、1/4、1/3、1/2、2/3 个物体最大尺寸，并用两个小错位相位打破同向重叠。退出方向尝试共同世界 +z 和略向反力一侧倾斜的近共同方向。这里的平均力只是位置提案启发式；力矩需求仍由最差七维需求、局部几何梯度和最后的全部原始载荷检查决定。需要时继续 Translation／Direction，整组原子提交，不逐个提交破坏旧任务的中间布局。

候选优先减少丢失的受保护载荷，再减少真实未通过载荷数；接近时比较真实占地与材料量。最差锥距离用于方向／位置提案，同时记录；不要求每个离散材料事件都单调改善同一个局部梯度代理。有限预算停滞不是不可行证明。

实际提交的排序是 `(丢失的受保护载荷数, 未通过载荷数, 最大投影占地, 材料体积)`，不是把几个量任意加权。受保护的是原始载荷的具体编号，不能靠另一条新通过载荷抵消旧载荷丢失。初筛的位置代价使用支撑坐标中物体实际质心的分散程度，避免不同旋转下坐标原点的平移量被误当作实际物体分离。

## joint

1. 全部 pose 注册到共享物体坐标，用原确定性共同／相近合法方向初始化。
2. 在当前布局作联合 Direction 搜索，每个角步尝试多个尺度。
3. 挑选最差任务和其他未通过任务，采样不同 host 与重叠位置。
4. 对入选 Juxtapose 分支继续 Direction、Translation，原子提交真实改善且保护已通过载荷的结果。
   单任务提案不能完成时，尝试成组提案，允许多个互相冲突的任务同时调整。
5. 重复，直到全部载荷通过，或记录未解决任务与搜索停止原因。

## incremental

1. 先构造第一个 pose；其实际通过状态成为已提交检查点。
2. 每次加入一个 pose，保留已有方向，以其平均方向在新任务合法半球内初始化。
3. 先尝试注册复用与 Direction；不能容纳时尝试新 pose 到不同 host 的 Juxtapose，并继续 Translation／Direction。
4. 新前缀全部通过才更新已提交检查点。未完成的前缀明确标记失败，可保留为后续增加材料的搜索状态；已提交检查点的载荷仍受保护。
   新增任务若连带损坏多个旧任务，允许成组重排，但提交前仍须恢复旧检查点的全部载荷。
5. 保存逐次插入结果及最终整组验收；不把未完成前缀计为成功插入。

## 实验边界

两种顺序使用同一几何、载荷、初筛、候选步幅和提交规则。报告实际计算次数及时间；增量法有多个前缀，不能用每轮相同预算冒充相同总计算预算。搜索所得 force/exit/work 结果不包含完整安装接地、实体连通、强度与机器人路径认证。

集合在此目录新建：`1–7`、`1,2,4,5,6,7,11`、`1,4,7,12,21,23,27`、`1–8`、`1–10`。第三组包含先前非法集合中的 pose，但新布局不能沿用旧注册冲突判定，也不能在没有实际新验收时把它称为已解决。

精确 Boolean／承载候选在隔离进程中使用本次冻结的源代码。候选运行超过 180s 或数值失败就明确记为 unresolved，继续其他候选；不认作物理不可行。每个完成的可行状态立即保存，防止后续异常丢失结果。`certify.py` 从最终导出的 OBJ 重新提取接触，保存所有原始载荷的非负压力基、分配与系数，并逐条回代原七维方程；这可独立于搜索轨迹重放。

若新任务的注册布局在数值上未能完成重建，使用旧检查点作为提案依据，为新任务提出实际 Juxtapose 候选；注册布局的承载状态记录为未知，不能假造为一个已经评估过的最差需求。只有替代布局完成真实几何及全部载荷检查才可提交。

工作面检查只在原检查器报告 `solver_unresolved` 时，尝试将同一材料／工作三角形的三个顶点循环换起点后重算；顶点坐标、绕向、工作面编号、几何和原容差都不变。检出真实穿入仍拒绝。这一步解决了增量第六个前缀的等式 LP 数值问题，没有放宽工作区。

结果与实际验证脚本见 [results.md](results.md)；旧版本失败或中断都保留在 `output/` 中，不能用没有最终验收的初筛分数声明成功。
