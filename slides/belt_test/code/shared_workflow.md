# 每站分开装卸：共享蓝色接触模块

2026-09-22 更新。复用同一个蓝色模块及同一种物体—蓝块装配关系；每次换站拆开、分别搬运、重新装入。没有开头单独把蓝块装到物体上的阶段，也不假设两者能一起搬运。

## 每个 dock 的顺序

1. 从准备位抓取蓝块，装入当前 dock，松手撤离。
2. 从稳定中转位抓取物体，装入已落座的蓝块，松手撤离。
3. 物体接触地面，蓝块提供辅助支撑，执行当前 task。
4. 抓取物体，退出蓝块并放回稳定中转位，松手。
5. 抓取蓝块，退出 dock 并放回准备位，松手。然后重复下一站。

**装载：蓝块先，物体后；卸载：物体先，蓝块后。** 当前三个姿态在刚体网格、均匀密度质心和纯重力假设下，撤掉蓝块后不能仅靠地面达到静力平衡。单臂搬蓝块时无法同时保持物体，所以不能直接先撤蓝块。这里仅判断重力平衡，不代表扰动稳定性或真实接触变形验证。

视频为每站完整循环，包括第三站最后的卸载。同一个蓝块和同一个物体始终可见，分别在准备区与工位之间移动。蓝块—物体不加锁、不粘接；动画只在搬运某一部件时维持该部件相对夹爪的位姿。

## 研究收益

目标是**复用同一种装配关系，让跨 pose 的装配动作更容易复用和调试**。接触区域与装配关系共用；同一局部直线装入动作仍是待验证目标，当前动画采用按姿态规划的物体退出路径。减少独立策略、示教、试配和调试属于待验证收益；不再声称只装配一次、保留跨站配准或必然节省每次换站时间。物体中转及蓝块搬运必须计入执行成本。

同一局部装配关系不自动保证同一控制器可直接迁移，也不保证装配更容易。应与各 pose 独立设计支撑比较；双方均可采用标准化 dock 和相同传感条件。详见 [设计笔记](../../../codes/algorithm_design_notes.md) 与 [收益验证记录](../../../codes/research_notes/reuse_benefit_evidence.md)。

## 几何来源与验证边界

当前视频恢复原版闭合地面环、三根 dock 支杆、矩形插接接口和 C140/C093 双接触头骨架。撤销上一版新增的 face 2992 支撑、额外连杆和开口底座。三个物体姿态、工作面、原骨架端点和接口尺寸取自旧记录；镜头距离由 1.65 m 改为 1.155 m（拉近 30%）。

原始 baseline 网格已被后续搜索覆盖，因此视频使用独立的 `original_geometry.npz` 固定恢复后的形状（`original_contacts.npz` 与旧参数保留重建来源），不再读取当前 baseline 支撑结果。物体网格来自已有仿真快照；两个接触中心由原姿态、原工作面与原采样算法恢复，接触半径按历史骨架端点核对。C093 端点吻合到数值精度，C140 重建端点偏差约 0.006 mm；这是形状恢复，不能声称旧网格逐字节恢复。原端点、插头和底座布局保持保存值。

分开装卸需要重新规划物体路径：原接触头不允许物体在地面上直接向上直线拔出，动画先作有限转动以脱离接触，再移出并抬起。此处仅调整运动，没有为路径增加接触面或改变底座。

检查覆盖整个时间轴内的物体—底座、蓝块—底座、物体—蓝块相交和两者最低高度，包含闲置 dock。采样间隔约 0.1 秒，实体相交阈值 0.01 mm³、穿地阈值 0.01 mm；这不是连续扫掠证明。机器人按约 8 Hz 解抓取及搬运中的完整工具位姿，并检查关节限位、机器人网格对地面以及采样关节速度。空手撤回准备位使用关节空间插值；卸载复用对应装载轨迹的逆向几何和 IK 分支，避免多次循环累积冗余关节姿态漂移。参考时长按最大速度比放慢后再压缩展示。

报告保留物体的纯重力平衡诊断（固定蓝块、均匀密度、摩擦系数假定为 0.3）。诊断结果不替代 dock 传力或任务承载验证，旧版示意补面得到的“全部可行”结论不沿用。

这是 `mj_forward` 位姿编排，没有 `mj_step` 动力学积分。尚未验证夹持力、全机器人与场景／自身的碰撞、蓝块—dock 防退出与传力、支撑强度、任务载荷及有限尺寸工具扫掠。加工阶段“地面与蓝块共同支撑”是研究要求，播放成功不代表承载已通过。
