## 历史六面构造提速

- **禁入区持久缓存。** 根据物体、退出方向和摆放，构造反向平移扫掠及原有 0.4 mm 间隙，保存在 `data/cache/`。输入或相关实现改变即失效。首次计算的时间计入首次运行，不藏到计时之外。
- **构造决策缓存。** 相同输入重跑时，复用已经选定的脚面归属与短连接路径，再执行原有 loft、裁切和并集；不是读取最终 OBJ 冒充重新生成。首次与缓存运行均通过相同的网格边界表示，避免数值近似导致不同连接选择。
- **默认去掉最终审计。** 不调用 `S.verify`，不重解两组 32,768 个载荷，不运行独立反力审计或浏览器交互审计。保留构造过程的头部保留、局部连通、裁切和最终单实体拓扑检查；仍导出 PNG。
- **明确记录范围。** 默认 `passed: null`、`verification.performed: false`，表示本次生成了实体而没有重新验收，不能把关闭验收写成“通过”。历史失败不会因此消失。`--verify` 才显式运行完整最终检查；独立审计不在批量流程内。

## 连接兜底（2026-09-28）

原来的短连接优先执行；只有无法合并连通分量时才调用 [connection_fallback.py](connection_fallback.py)：

1. 在两块身体的近邻端点之间建立一个连接包络，按 4、8、16、32、64 mm 逐级外扩。
2. 每个包络都减去同一个退出禁入区，并裁到两地面以上、500 mm 退出行程的终端分离半空间内。保留能以正体积同时连接至少两块身体的合法部分，丢掉无用碎块。
3. 若局部包络仍不足，则使用包含全部身体和禁入区的更大构造包络，直接计算其中全部合法材料的连通分量。采用真正减少连通分量的连接，直到剩一件实体。

兜底通过扩大可用连接区域让材料绕障，不再限于直线或一个抬高拐点。保证范围是**给定构造包络内、相同正体积连接判据及布尔容差下的可连通情况**：最终候选包含包络内全部合法材料，任意合法的添加材料方案都是它的子集。若该最大合法集合仍不能连接，不能虚报成功或据此声称任意扩大空间都无解。没有新增壁厚或强度保证。

pose6+9 使用第一个 4 mm 外扩的局部包络就从两块变成一块，新增 **16.733659 cm³**，兜底搜索 **0.0205 s**，最终体积 **445.740497 cm³**。连接包络也进入输入哈希保护的构造缓存，重跑重新生成和裁切材料。其余四组没有触发兜底，实体与更新前完全一致。

## 历史统一贪心算法

1. 从原撒点自动生成可选脚面，构造头截面—后退截面—脚面的整块 loft；从可选身体的邻近表面生成短连接。所有候选同时避开两个 pose 的物体、完整退出空间和地面以下。没有使用 reference 的手工脚面坐标。
2. 按真实重叠建立候选图。用 Dijkstra 提出连接到现有实体的动作，按真正新增的布尔并集体积和新满足的头、两地面要求一起比较；公共材料只计费一次。短连接也在这一步选择，没有固定头分工或最终单独加桥。
3. 同头同地面的扩展合为一整块身体后计费。检查实际地面凸包，再用失败的**原始载荷**产生必要的反力约束，继续同一贪心。
4. 完整通过后，带着累计约束重新贪心，最多继续 8 轮原载荷反馈；保留更小且完整通过的结果。最后逆向删除冗余候选，每一次采用的删除都必须通过全套原验收。

完整表达、成本公式和限制见 [`loft_growth_method.md`](loft_growth_method.md)。这是有限候选族内的工程启发式，没有全局最优或标准近似率保证；空间并集中的共享材料不等于已证明每处材料都在两个 pose 承载。
