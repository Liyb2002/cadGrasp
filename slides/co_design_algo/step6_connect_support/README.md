## 足够摩擦的含义

接触头仍为无摩擦的单边法向接触。地面摩擦作用在工件原支点和支撑底座。保留“地面摩擦足够”的假设，不把某个 μ 当作实测材料参数。

数值验证用四射线摩擦锥 `|Fx|+|Fy| ≤ μFz, Fz ≥ 0` 寻找一个有限的充分摩擦见证。Step5 优先用已有 `μ=64` 见证搜索紧凑可行底座；只有这一档没有合格候选时才提高到 `256,1024,4096,16384,65536`。Step6 保留该见证并独立重放，不把 64 当作物理上限。有限预算耗尽只记为连续承载未决，不能推出“足够摩擦下无解”。Step1–4 保留本次输入，Step3 的历史 μ=64 证书没有改写。

不能用“摩擦足够”代替单边法向、力矩平衡或整体不上抬。视频只在整件轨迹通过后生成，视频存在不表示承载通过。
