# 当前 Step5：固定底座、独立矩形对接

入口仍为 `base.py`；带 `catalogue.installation` 的新输入转入 `modular.py`，输出 schema 为 `stationary_base_removable_module_v1`。底座从流程开始就预先放好，工件与蓝块整体移动。初次装蓝块的 d0 与对接方向分开。当前单 pose 有限构造使用沿 -Z 的竖直对接，检查完整工件和蓝块相对固定底座的连续退出射线。

蓝块由 Step3 的实际头、有厚度连接颈、后侧梁树和一个矩形直榫构成。插座参考 `slides/belt_test/code/source_geometry.py`：插头 18×8×26 mm，配合长 21 mm，壁厚 3 mm，局部对接行程 30 mm；末端挡块限制继续插入，没有防退出锁。计算采用理想零间隙贴合，以真实接触位置建立反力；示意图原有的单侧 0.5 mm 制造间隙不作为已认证的承载接触。

底座是静态闭合地面环、到外侧插座的短连接和支柱。地面环只围绕 Step4 的需求凸包与原始地面支点，不再把整个工件俯视投影或接口位置并入圈的凸包。最多试 12 个初次安装方向、8 个有效外侧接口位置以及 11 档地面环外扩；所有几何通过的候选按实际接地凸包面积、材料面积依次排序，取得承载证书后才接受。优先缩小底座，不能宣称任意形状下全局最小。底座不需要避开“自身绕工件退出”的扫掠，改为避开工件＋蓝块的对接扫掠。初次安装仍验证包含新插头在内的完整蓝块。

底座沿用不锚固、无自重及充分地面摩擦假设。`rectangular_dock.py` 使用 18 行平衡方程：工件、蓝块、橙色底座各六行，接口作用力／反作用力共享同一列未知量。套孔四侧和末端提供无摩擦单边反力，沿拔出方向没有锁止拉力。连续载荷及样本都必须通过同一模型；单刚体旧证书不能直接沿用。

输出增加 `blue.npz`、`contact_module.stl`、`contact_module_mm.stl`，与 `base.stl` 分开制造。`base.json` 分别记录几何构造与承载通过情况；有可行运动但承载未决的几何仍保留作诊断。`audit.json` 重建初始蓝块扫掠、整体对接、原始头部保留及三刚体反力证书。

# Step5：紧贴地面需求的可插入底座

输入固定的 Step3 共同退出方向（2026-09-21 起仅取同时通过头间连接检查的子集）和 Step4 地面需求；输出底座及其一条完整直线插入轨迹。本阶段不构造连接或生成视频，但将固定接触头和候选底座视作同一个无自重刚体，提前验证工件与支撑共享反力的承载；承载通过是选定底座的硬条件。

## 目标与构造

1. 用 Step4 样本、连续载荷外包地面需求及工件原支点建立需求凸包。连续外包不能为了缩小底座而删除。
2. 以凸包为内边界，向外做条带；不把整个工件俯视投影加入底座轮廓。条带宽度仍为 `0.05D`，高度为 `0.04D`，`D` 为工件最长包围盒边。
3. 对 Step3 **全部通过连接检查的共同方向**，将工件沿相反方向投影到有厚度的底座所在高度区间，求退出障碍区。从条带中只挖去该障碍区及间隙，形成开口。
4. 生成凸包向外平移 `0, 0.001D, …, 0.200D` 的候选，并加入 `0.4D,0.8D,1.6D,3.2D` 的扩张后备。保留连通底座，且真实接地材料加工件原支点的凸包必须包含全部需求。水平退出障碍投影长度随最大搜索边界增加。
5. 将**真实底座接地材料凸包完全相同**的候选归组，只评估一次共享承载。相同摩擦锥、共面接触下，力矩对接触位置是仿射的，所以凸包内部接地点的所有力学射线均可由极点射线凸组合表示。这是完整力／力矩锥的等价简化，不是在空洞或工件原支点新增底座材料。
6. 在原有摩擦见证 `64,256,1024,4096,16384,65536` 的每一档内，按面积排序后的候选组做指数序号试探，找到完整证书后最多再试两次局部缩小，并始终保留已经通过的结果；达到次数上限便返回该认证底座。每次全量检查可能涉及近百万载荷，因此不为微小面积收益反复缩小。这代替逐一遍历全部方向×201偏移×6档。**开口几何和数值证书不保证单调；局部区间缩小是搜索启发式，不能证明被跳过候选不可行或结果最小。** 本阶段不对离散的证书通过标志求导。
7. 先用少量极值／均匀载荷与之前失败的载荷快速筛选；连续载荷探针必须用与最终连续证书一致的严格模式。通过探针后仍验证全部连续外包和全部样本。优先连续外包，是因为它通常先发现失败；不能以探针替代全量接受条件。
8. 仅对承载通过的候选构建三维网格，并独立验证实体、`0.02D` 间隙、完整退出扫掠、真实接地和单实体性。力学相同的底座仍各自检查插入几何。入选后审计重建全部矩阵、真实极点和载荷反力。

目标是快速得到有证书且尽量紧凑的底座。报告保存试探序号、候选／独立接地凸包数量、拒绝记录以及平面生成、承载／几何搜索和总生成时间。没有证书表示有限搜索未决，不能称为不存在底座；未决候选也不能交给 Step6 当作合格输入。

“无限扩大必能通过”需要额外条件：固定头必须能向无自重、无锚固的支撑传递可由单边地面反力平衡的力，有限摩擦见证和退出通道必须可行。扩大能增加抗倾覆力臂，但不自动改变力方向约束，也不能消除连续外包或数值证书的保守性。这里保持原物理模型和摩擦菜单。

底座碰撞检查使用实际有厚度材料；俯视投影只是构造方法，最终接受仍独立检查三维连续扫掠。退出方向为 `+d`，装入方向为 `-d`，工件固定。
