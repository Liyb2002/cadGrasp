# 工件—支撑需要满足的四项条件

这四项条件定义支撑设计的目标；[baseline Step3](../baseline_algo/step3_scheculer/README.md) 是搜索接触方案的基线方法，Step4 将接触面实现为完整实体并验证几何。各 pose 独立选头，不要求后续 pose 继承或共享任何旧头；共享的是最终的一件刚性支撑实体，接触区域可以不同。

工件自身不接触地面时，见[不着地公式与新图](airborne_equations.md)：保留重力及同一绕质心的需求，由支撑接触独自承担，工件地面反力为零。三个角度、两种接地状态的逐pose预计算输入见 [preprocessing](../../codes/precompute_objects/README.md)。

## 1. 联合力与力矩平衡

对每个任务 pose 和载荷，存在同一组接触反力，同时满足

\[
\sum_j F_j=mg\hat z-F_{\rm push},\qquad
\sum_j(p_j-c)\times F_j=-(q-c)\times F_{\rm push}.
\]

这里包含工件自身的地面接触；头部反力为无摩擦单边法向力 `F_j=λ_j u_j`、`λ_j≥0`，无压强上限。工件地面反力遵循求解器的单边摩擦模型。不能分别找到两组力来满足力平衡和力矩平衡，也不能把各头单独可承受的载荷集合直接求并集。几何固定，反力可随载荷改变。

## 2. 支撑整体不上抬

同一组反力还必须满足

\[
\sum_{j\in\mathrm{heads}}F_j\cdot\hat z\geq0.
\]

`F_j` 是支撑对工件的力，因此工件对支撑的总竖直作用力向下或为零。约束只对所有头求总和，不包含工件自身的地面反力，不要求每个头分别满足。它来自无自重、无锚固、无黏附支撑的单边地面接触假设，是必要条件，不能单独保证抗倾覆或完整支撑平衡。见[不上抬说明](no_uplift_intuition.md)。

## 3. 有限厚度的连通实体

存在同一件有限厚度、连通的刚性支撑 `V_support`，实现各任务的完整选中接触面：`A_obj^k ⊆ ∂V_support`。在每个实际安装摆放下，全部材料（包括闲置部分）避开工件内部、工作面和地面以下区域；接触边界允许贴合。工作面禁占用，不额外要求避开整个加工射线圆锥。接触点或细路径连通不能替代真实实体连通。

## 4. 完整实体的共同直线插入

对每个任务存在一个固定直线方向，使第 3 项的同一完整支撑与工件相对平移时，在整段装入／退出行程中都不发生内部碰撞或穿地。方向可因 pose 而异，同一 pose 内全部材料必须一起沿该方向移动。

\[
\mathrm{Sweep}(V_{\rm support},d_k)
=\{x-t d_k:x\in V_{\rm support},\ 0\leq t\leq L_k\}.
\]

在相应安装坐标系中，此扫掠不得与工件内部或地下区域相交。`L_k` 须覆盖完整退出检查；只检查终点或每个头各自有一个方向不够。代码保存退出方向，反向路径用于装入。

## Baseline 的实现与验收边界

Step3 用固定候选上的 top5 多链搜索独立求每个 pose 的接触组合，联合检查条件 1、2，并筛选接触几何、头组共同退出和基本通路。当前每 pose 的 Step1 原始 **32,768 个载荷全部通过**才算受力通过；不增加连续载荷域验证或反例，单独零加工力检查只作诊断。该有限采样标准不等于连续域证明。

Step3 输出零厚度接触面；组模式要求完整面的所有三角形顶点在组内各 pose 下至少离地 2 mm。局部退出／通路检查使用原有限厚度头作保守探测，不能据此认定最终连接体可行。

Step4 保留 Step3 接触与受力结论，构造并检查最终实体的条件 3、4，以及工作面、地面、真实接地需求和接触保留；不重复求解力和力矩。完整方案须同时满足 Step3 受力与 Step4 几何，两阶段的通过状态分别记录。Step5 占地评价只是指标，不是上述四项条件之一。
