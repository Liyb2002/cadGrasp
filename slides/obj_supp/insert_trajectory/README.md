# 单块接触头允许从哪些角度插入？

旧版图片已删除；下面保留实验方法和数值记录。当前讲解图见 [slides 图目](../../README.md)。

这是独立于 baseline 调度器的研究实验：每个物体从 Step 2 的合格候选中选 **5 个接触块**，
对每块求允许的水平插入角度集合，再展示 **5 个具体方向**。
所有接触块均单独研究；不检查它们共同装配，也不加入底座、地板、连接梁或其他接触头。

## 角度集合的含义

这里固定支撑头姿态，只允许水平直线平移。因此一个角度足以确定运动方向：

\[
\mathbf a(\theta)=(\cos\theta,\sin\theta,0),\qquad
H(s,\theta)=H_{\mathrm{final}}-s\mathbf a(\theta).
\]

`0° = 世界 +X`，`90° = 世界 +Y`。`a` 表示**运动方向**：插入时 `s` 从 `L` 减到 `0`，
支撑头由 `-a` 一侧接近最终位置。它不是“从哪一侧来”的方位角，两者相差 180°。

记工件为 `O`，单个接触头为 `H`，我们研究：

\[
\mathcal A(H)=\{\theta\in[0,2\pi):
\operatorname{int}(H-s\mathbf a(\theta))\cap\operatorname{int}(O)=\varnothing,
\ \forall s\geq0\}.
\]

允许边界接触。结果通常是**若干角度区间的并集**，可能绕过 `0°/360°`，
也可能有孤立的切向方向；不能总用一个中心角和一个张角表示。
若进一步允许三维直线运动，方向集合在球面上；若允许旋转或曲线路径，就需要保存实际姿态路径，
不能再用这一维角度集合代替。

对于保持相对位置、一起平移的多个接触头，仅考虑它们与同一工件的碰撞时，
共同允许的角度集合就是各自集合的交集。增加连接结构后还必须检查新几何。

## 如何检查整个角度区间

1. **局部必要条件。** 遍历接触区的实际源面，求
   `n_out(pt) · a(theta) <= 0` 的交集。用三角函数的零点划分连续角度区间，保留孤立切向方向。
   这一步不检查远处障碍。
2. **真实接触头。** 用 Step 2 保存的法向厚度和连续外移表皮重建各凸体单元，保留曲面接触头的凹形。
   不对整个接触头取一个会填入工件的总凸包。
3. **完整角度区间的扫掠外包。** 对 `[theta0, theta1]`，用两条边界射线和中间切线交点
   包围所有平移线段。逐凸单元构造整个角度区间的扫掠外包；若它不穿入工件，该区间全部通过。
4. **找出真正受阻的角度。** 若外包相交，不直接否决整个区间。对于找到的物体三角面 `T` 和凸头单元 `P`，
   构造平移配置障碍 `T + (-P)`，取其 `z=0` 截面，求 `-a` 射线进入截面内部的角度。
   这些角度存在实际路径碰撞；剔除它们后继续检查剩余区间。
5. **边界保留未决。** 配置障碍的角度端点向内部留 `1e-6°` 守护带。
   无法完成区间判定时继续二分；小于 `0.01°` 的剩余小段记为 `unresolved`，不冒充可行或不可行。

这里配置障碍的构造遵循平移运动的 Minkowski 差表示，具体角度区间算法在本实验中实现。
参见 [LaValle：平移配置障碍](https://lavalle.pl/planning/node161.html)。

长度取 `L = 1.1 × 工件与最终接触头联合包围盒的对角线长度`。
它大于任意工件点与最终接触头点之间的距离，所以对于任意方向，支撑头在 `s >= L` 已位于工件外。
这既使有限扫掠覆盖完整的插入检查，也排除了扫掠体完全藏在工件内部却没有穿过边界的漏检情形。
不能随意缩短这个长度后沿用原判定。

本实现要求封闭、绕序一致且体积为正的工件；按原始物体网格逐面检查，适用于凹物体。
几何长度容差为 `1e-9 × 物体最长边`。结论针对当前网格与该数值容差，不是精确 CAD 曲面的算术证明。

## 当前结果与现象

- **A1-f / C061**：完整路径允许约 `[94.736°, 271.645°]`，窗口很宽。
- **A1-f / C191**：有局部法向允许的方向，但实际接触头沿这些方向会撞到物体几何；没有通过的水平角度。
- **C5 / C192**：允许约 `[0°, 1.573°] ∪ [23.012°, 71.855°] ∪ [310.041°, 360°]`。
  第一段与最后一段在圆周上相连，但中间另有一段允许范围，必须保存并集。
- **C5 / C173**：约 `[91.249°, 180.999°] ∪ [188.736°, 192.689°]`，两段之间存在几何遮挡。

以上显示值为三位小数的近似读数；端点精度与未决区间以 JSON 为准。
本次有四块存在未决边界带：B/C174 合计约 `0.00731°`，C5/C192 `0.01368°`、
C5/C060 `0.00511°`、C5/C173 `0.01284°`。其余示例未产生未决角度区间。

选择使用固定随机种子 `20260908`，从 Step 2 合格候选中均匀、不放回地抽取五块，先选块再检查方向。
因此同时保留通过和不通过的案例，不用插入结果筛选展示对象。它们使用 Step 2 初始尺寸，
不是 Step 3 最终优化尺寸，即便编号相同也不可混用几何结果。

## 文件与复现

- `angles.py`：角度集合、扇区扫掠和配置障碍。
- `study.py`：读取现有候选、选择五块、保存区间及五个示例方向。
- `audit.py`：用独立的 `manifold3d` 双精度实体布尔交核对五个示例方向和额外的区间内部方向。
- `draw.py`：总览与逐接触块的五方向图。
- `run.py`：重算实验、核对并生成全部图。

每个物体的 `output/<物体>/` 保存 `angles.json`、`contacts.npz`、`audit.json`、
`example_intersections.npz`、`views.json`、总览及五张详细图。
JSON 分别保存 `local`、`clear_intervals_deg`、`geometry_blocked_intervals_deg`、
`unresolved_intervals_deg`、`isolated_direction_checks`，以及碰撞源面与代码、输入哈希。
`complete=true` 只表示本轮研究完成；可行角度由 `clear_intervals_deg` 和通过的孤立方向给出。

六项几何测试覆盖角度绕回、相对两面仍能切向滑动、配置障碍符号、远处障碍、
两端不碰但中间角度碰撞，以及微小裁切单元顶点不能被合并的情形。
真实物体的 75 个展示方向及 40 个额外区间内部方向，共 115 个方向，
全部通过独立实体扫掠核对；逐项结果与交叠体积保存在各物体的 `audit.json`。

```sh
python slides/obj_supp/insert_trajectory/run.py A1-f B C5

```
