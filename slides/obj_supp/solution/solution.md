# 解法：几何矩阵 × 力的三个分量 = 需求

[公式图](solution.png)接在 [demand 公式](../demand/demand_equation.png)及其球图之后。
上半先写单个力，下半重复上面的“矩阵 × 单个力”形式，用加号连接各项，
使用同一个目标需求。各力分别展开成三个分量，并留足间距。

按用户确认的展示方式，未知力完整展开为 `F_i=(F_ix,F_iy,F_iz)`。
每个力的几何矩阵为两个 `3×3` 块上下叠起来：上面是单位矩阵 `I_3`，
下面是力臂 `r_i=p_i-c` 的叉乘矩阵，力矩关于质心。

```
A_i = [ I_3       ]                     (6 × 3)
      [ [r_i]_×   ]

          [   0    -r_iz    r_iy ]
[r_i]_× = [  r_iz    0     -r_ix ]
          [ -r_iy   r_ix     0   ]

A_i F_i = [F_Dx, F_Dy, F_Dz, tau_Dx, tau_Dy, tau_Dz]^T

A_0 F_0 + … + A_n F_n = [F_D ; tau_D]

每一项都展开 A_i 的 6×3 个元素，以及 F_i 的三个分量。
```

右端是 `demand(F_push, pt)` 给出的完整力矢量与力矩，包含大小，
并非只保留单位力方向。当前 `|F_push|=0.5mg`。
第 0 项对应工件自己的地面接触，`r_0=a-c`。
接触数量不等于独立支撑实体数量。

这是平衡关系的分量展开，接触约束仍按当前模型另加：`F_i=λ_i u_i`、`λ_i≥0`，
地面接触 `F_0=λ_0 zhat`。不能把三个笛卡尔分量分别要求非负，也没有解除方向约束。
代入这些约束后，与原来的六维列 `[u_i; r_i×u_i]` 乘标量 `λ_i` 等价。

图中的等式是要求解的约束；单个接触未必能满足给定需求。多个接触也需找到
同一组力同时满足上下两块。图不宣称已求出某个支撑方案，也不加入最少接触目标。
