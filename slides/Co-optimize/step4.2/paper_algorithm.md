# 论文算法：全组连续修复与离散落座

## 问题与变量

输入是同一物体的一组任务：原世界朝向、工作面、绕质心的力／力矩需求及允许退出方向。输出是一件共享支撑、若干支撑摆放state，以及各任务的物体相对位置和退出方向。每个state可以服务多个任务。

退出方向在单位球面连续优化；已落座位置允许世界XYZ平移，工件允许airborne且不能穿地。Juxtapose离散改变host或state内的座位。物体朝向与原需求保持不变。最终目标是满足所有任务后减少实体材料体积，state数不计代价。

## 连续收益与损失

对每个任务构建当前接触的原七维非负反力锥 $C_i(x)$，最小化

\[
L(x)=\frac{1}{2n}\sum_i s_i^{-2}
\int \operatorname{dist}(b_i,C_i(x))^2\,d\mu_i(b_i).
\]

正权求积同时包含已满足和未满足需求。Direction与XYZ Translation的数值差分重新评价所有受影响pose，使接触释放的收益、新锁定的损失与改变的力臂一起进入同一目标。局部下降块及竞争Juxtapose分支固定节点、权重和尺度。

接触变化非光滑，采用有限分辨率割线、多尺度线搜索及少量明确记录的接触事件sampling。Juxtapose用于越过连续局部停滞；每个离散布局再通过全组连续修复比较。

airborne不改变质心需求或重力，只移除工件自身地面反力；原第七方程slack保留，供力和代理缓存随接地状态切换。三轴使用同一梯度范数与步幅，只有地面边界需要单侧差分和投影。

## 搜索流程

```text
x ← 保存的 Step4.1 布局，激活全部 pose
连续修复(x)：Direction + 所有可移动位置的 XYZ Translation
while 尚有原需求未满足，且结构跳步预算未用完:
    固定当前全组需求求积点和权重
    J ← 有界 Juxtapose 候选：失败 guest、blocker、必要时成对移动
    用接触／材料增删快速筛选 J
    对少量分支做全组 Direction／XYZ Translation 修复
    按共同目标选择改善分支，继续连续修复
if 仍有未满足需求:
    从自身当前布局追加有界保持 state 落座与梯度修复
if 全部原始需求通过:
    恢复转动复用，保持可行地减少材料
    复用已算出的原始需求 mask／反力，保存 PASS
    固定布局导出名义支撑 mesh
return 新搜索结果，并单独记录与旧答案的材料择优
```

所有pose始终共同参与，whole不等于全局最优证明。未可行时按积分损失下降，完整原需求可行的状态优先；可行后材料下降必须保留每pose全部32768需求通过。

## 几何与效率

贴合材料随设计布局改变，扣除所有当前物体、完整工作锥和退出路径。Direction可以恢复旧路径释放的材料；Translation同时更新接触行、阻挡列和覆盖计数。多个配置共同锁住的点只有全部让开才可用。平移改变终点，横移轨迹不挖入支撑。

候选不重建Boolean；相对几何查询、反力列与需求结果均缓存。完整原需求检查只用于可能接受的新候选。最终选中布局复用已有结果，名义mesh仅用于显示和材料体积。

## 目前证据

七组8–10-pose新搜索7/7满足原始需求：6组初次、1组追加梯度；三个新pose实例离地。新名义材料721.55cm³，旧逐组最小713.01cm³（+1.20%）；最终择优655.74cm³（−8.03%，3新／4旧）。三进程整批含出图21.38min。
