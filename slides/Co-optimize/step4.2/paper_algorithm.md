# 论文算法：多布局保留、全组连续修复与离散落座

## 问题与变量

输入是同一物体的一组任务：原世界朝向、工作面、绕质心的力／力矩需求及允许退出方向。输出是一件共享支撑、若干支撑摆放state，以及各任务的物体相对位置和退出方向。每个state可以服务多个任务。

退出方向在单位球面连续优化；已落座位置允许世界XYZ平移，工件允许airborne且不能穿地。Juxtapose离散改变host或state内的座位。物体朝向与原需求保持不变。最终目标是满足所有任务后减少实体材料体积，state数不计代价。

## 连续收益与损失

对每个任务构建当前接触的原七维非负反力锥 $C_i(x)$，最小化

\[
L(x)=\frac{1}{2n}\sum_i s_i^{-2}
\int \operatorname{dist}(b_i,C_i(x))^2\,d\mu_i(b_i).
\]

正权求积同时包含已满足和未满足需求。Direction与XYZ Translation的数值差分重新评价所有受影响pose，使接触释放的收益、新锁定的损失与改变的力臂一起进入同一目标。局部下降块及竞争Juxtapose分支固定节点、权重和尺度。

接触变化非光滑，采用有限分辨率割线、多尺度线搜索及少量明确记录的接触事件sampling。Juxtapose用于越过连续局部停滞；每个离散布局再通过全组连续修复比较。

airborne不改变质心需求或重力，只移除工件自身地面反力；原第七方程slack保留，供力和代理缓存随接地状态切换。三轴使用同一梯度范数与步幅，只有地面边界需要单侧差分和投影。

## 搜索流程

```text
候选池 ← 保存的 Step4.1 完整布局，激活全部 pose
while 尚无全部原需求与动态 base Oracle 通过的布局，且预算未用完:
    给整轮全部父布局、探针与子候选固定同一需求求积点、权重与尺度
    从每个父布局生成 Direction／世界XYZ Translation／接触事件sampling
    周期性或停滞时扩展 Juxtapose；必要时扩展地脚Oracle修复布局
    分摊96个正式候选快筛额度，同时查询受力误差与合法地脚包围
    最多8个短名单候选检查全部原始需求；不重算已有父布局的mask
    最多3个新受力、包围通过的候选查询共同连接空间
    父布局与子候选一起保留4个：受力好、包围好、地脚／布局几何不同
    保留已找到的整体可行布局及其对应连接空间见证
if 原始需求、合法包围、共同连接全部通过:
    在 Oracle 约束下恢复转动复用、减少实体材料
    复用已算出的原始需求 mask／反力
    保存固定布局、名义支撑与合法连接空间见证
冻结布局：Step5.1 → 全部地面需求凸包
          Step5.2 → 选择少量地脚并确定性连接成实体
Evaluation → 对相同完整物体 process 计算三列世界 XYZ BBX
```

所有pose始终共同参与，whole不等于全局最优证明。可行材料下降必须同时保留每pose全部32768需求与Oracle通过。需求凸包随最终XYZ位置更新，只约束最终支撑安装姿态。[Oracle细节](base_oracle.md)

## 几何与效率

贴合材料随设计布局改变，扣除所有当前物体、完整工作锥和退出路径。Direction可以恢复旧路径释放的材料；Translation同时更新接触行、阻挡列和覆盖计数。多个配置共同锁住的点只有全部让开才可用。平移改变终点，横移轨迹不挖入支撑。

候选不重建Boolean；相对几何查询、反力列与需求结果均缓存。完整原需求检查只用于可能接受的新候选。最终选中布局复用已有结果，名义mesh仅用于显示和材料体积。

## 当前证据与范围

既有单布局52组、263个pose实例完成工件需求、合法包围、共同连接及最终实体构造，含全部10个≥7-pose集合；这些保存结果不属于新多布局搜索。新默认Oracle仅使用工作三角形的外法向棱柱并集，原加工力／接触角度不变。各新实验独立记录结果；多布局保留不构成全局材料最优或连续需求域证明。
