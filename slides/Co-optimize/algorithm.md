# 多配置共享支撑：当前问题与算法

## 问题

给定同一物体的多个任务 pose、工作区域和原力／力矩需求，设计一件可反复使用的刚性支撑。物体装入、执行任务、取出；取出物体后可以改变空支撑的摆放。任务执行期间支撑静止。

一个支撑摆放 state 可以服务多个 object pose，容量不设上限。为每个任务选择支撑 state、物体相对位置及退出方向。原任务世界朝向保持不变，**相对位置允许世界 XYZ 平移，工件允许 airborne**。目标是在全部需求满足后减少共享支撑实体材料，state 数量不作为代价。

## 物理模型与 XYZ

需求绕工件质心表达，包含重力。整体平移时工件、工作面和施力点一起移动，相对质心的力臂不变，沿用原需求数组。每个pose只读取对应工作角度的一份需求；grounded／airborne 不单独生成需求。

所有接触反力沿原法向、非负且无幅值上限。接触位置与法向构成七维反力锥，保留原第七方程及非负 slack；面积只描述几何范围。物体最低点高度大于1e-9m时，删除工件自身四个物理地面反力列；回到地面后恢复。接地状态进入供力及代理缓存。

Translation 用世界三维梯度、同一范数和同一组步幅。着地边界采用向上单边差分，并把位置投影到最低点高度非负；离地后可继续上移，也可下移返回地面。[物理推导](../obj_supp/airborne_equations.md)

系统绕地面的力矩依赖最终位置。Step5 需要按各最终 state 和物体位置设计 base，必要时计入支撑自重。Step4.2保留独立的工件受力PASS，并用动态base Oracle提前审查布局：合法地脚的凸包能否包围当前位置的地面需求，以及是否存在共同材料空间连接地脚与承载接触。新实验整体PASS同时要求这两类条件。

合法材料位于所有最终安装姿态的地面半空间之上，避开所有任务的物体、完整工作锥和退出路径。只约束最终工作姿态；机器人抓起空支撑后的搬运转动没有连续合法性要求。地脚不必构成封闭实体轮廓。有限窗口查询失败也不宣称全局无解。[Oracle公式、实现与范围](step4.2/base_oracle.md)

[Step5.1](step5.1/README.md)已实现需求投影与所有需求凸包：用最终世界质心$c$计算$\tau_O=\tau_D+c\times F_D$，把每个原始样本映射到地面压力中心$(-\tau_{O,y}/F_{D,z},\tau_{O,x}/F_{D,z},0)$。所有样本保持不变，XYZ位移与airborne的高度力臂直接进入结果。工件—支撑力相互抵消，工件着地时自身地面反力与支撑地面反力共同提供总地面需求。默认不计支撑自重，与Step4 Oracle一致。

[Step5.2](step5.2/README.md)直接在Step4保存的合法连通空间中选小地脚，并裁剪、连接局部材料成为一件实体。地脚凸包是虚拟包围，不填充其内部；固定布局的确定性构造不重跑需求或pose搜索。设计到此结束。[Evaluation](evaluation/README.md)随后计算独立pose静态空间、共享state空间，以及相同最终布局下物体／Step4／Step5.2的共同世界XYZ包围盒，不加入装卸行程。当前地脚外缘选点仍会造成占地浪费。

## 初始化

全部 pose 从开始共同参与。Step3.1 将整组注册到首个参考 pose，生成5mm贴合包裹，扣除全部物体和工作禁区；Step3.2 单独显示禁区。Step4.1 初始化共同／相近合法退出方向，预留完整装卸空间。初始化承载不足的组仍交给 Step4.2。

共同物体相对方向适合转动空支撑复用，共同绝对方向适合一个state服务多个pose；两种模式可混用。

原始工作面每个点向外的完整方向锥都必须留空：

\[
\mathcal W_i=\bigcup_{f\in\mathrm{work}_i}\{p+sv:p\in f,\ s\ge0,\ \|v\|=1,\ v\cdot n_f\ge\cos\alpha_i\}.
\]

B工作半角为30°，完整禁区不设长度上限。所有当前物体、工作禁区与退出空间共同限制可用接触。

## 三个 operations

- **Direction：**固定布局，沿单位球面的数值负梯度更新退出方向；包含独立、全组联合及共同转向。
- **Juxtapose：**连续调整停滞时，离散选择失败pose或阻挡它的pose，尝试已有state中的重叠座位，补充贴合材料并扣除全部当前禁区，再做全组局部修复。
- **Translation：**在已明确Juxtapose的位置上沿世界XYZ微调；同时更新自己的接触、对别人的遮挡及共享材料增删。原注册pose先保持位置，需要改变时通过显式落座操作进入可移动集合。

平移改变设计中的落座终点，横移轨迹不作为滑道挖入支撑。多个pose共同遮挡时，联合方向／共同世界位移及有界成对Juxtapose可以一起释放接触。

## 全组搜索与接受

方向和平移共用目标：所有pose需求到当前原反力锥的积分平方距离。固定正权求积用于梯度，所有已满足区域也参与，需求变差会增加损失。一个局部下降块及其竞争落座分支共用求积点、权重和尺度。

数值差分与多步幅线搜索负责连续调整；有限sampling处理接触开关的平台，Juxtapose是结构跳步。尚未全组可行时按积分损失下降比较，全部原需求通过的候选优先。整体可行后仅接受保持全部原需求通过的材料下降，并尝试恢复转动复用。

候选只更新接触锁、覆盖计数与反力投影，不构造实体Boolean。最终选定布局复用已有原始mask和反力：**每pose32768需求全部通过即PASS**。固定布局mesh用于显示和材料体积，不触发接触重建、几何补救或重复求解。当前从保存Step4.1冷启动；整体PASS还要求动态base Oracle通过。

## 当前结果与范围

当前全52个集合完成Step4合法空间、Step5需求凸包和实际连通实体，包括全部10个≥7-pose集合。263个pose实例的原始需求全部通过。完整公式、最新结果和静态空间指标统一见[根README](../../README.md)。

法向地面压力包围沿用原模型，完整摩擦／yaw／强度及连续需求域证明不属于此构造范围。不同物体共享与机器人抓取留作[后续扩展](research_extensions.md)。最终数值在`data/results/`，`output/`只留各步骤最终可视化；中间文件用完删除。
