# Step4：固定32个候选的随机探索与短调整

这是2026-10-12讨论后确定的新实验算法。已确认的旧批次 `material_output_all52_20261012_final` 保留，新的运行使用独立批次名称。

Step4.1给出32个完整候选，每个候选都包含该set全部任务pose。所有pose从保存的注册原位开始，不枚举哪些pose应该Juxtapose，不读取历史优化布局作暖启动。共同合法退出方向存在时，候选可以相同；没有完全相同方向时，在合法方向附近保留小幅差异。重复布局共享数值计算，32个候选槽位分别保留自己的操作历史。新的初始化记录另存，原Step3/4.1输入不覆盖。

Step4.2始终只维护32个活动槽位。每个槽位每轮随机选择一个可用探索分支，生成一次试探，随后做一轮短调整，并在该槽位内决定是否接受。没有额外的角色组合种子、三分支扩展池或不断增加的候选。每轮差分读取轮开始时固定的32个候选。

```text
种群 = 32个相近的注册原位完整布局
重复8轮：
    快照 = 本轮开始的32个布局
    对每个槽位i：
        随机选择一个可用探索分支
        离散：在槽位i自己的布局内，随机选pose配对／换座
        差分：读取快照中另外两个槽位的同一pose位置，扰动槽位i
        对本次试探做一轮短调整
        在槽位i内接受改善或少量结构探索，槽位总数仍为32
    按预算检查原需求、共同连接和实际实体构造
最终补齐32个槽位的原需求检查，按剩余预算认证并选择结果
```

| 分支 | 信息来自哪里 | 操作 |
|---|---|---|
| 离散换座 | 当前候选自身的pose | 随机选pose和配对pose，创建或改变换座；也可恢复原位或交换角色 |
| 种群差分扰动 | 其他候选中相同pose的位置 | 以当前布局为起点，加两个其他候选的座位差分和随机扰动；保留当前角色分配 |

两个分支都可用时各50%。没有Juxtapose pose时使用离散分支。离散换座不通过接触位置、法向相似性预先筛选配对：选择一对pose后，尝试使用配对pose的当前安装状态，保持被移动pose的原任务世界朝向，初始化为世界XY质心对齐，Z保留当前合法高度并投影到不穿地。精确中心采用原网格质心，全部位置在一致坐标系中计算。

谁Juxtapose是搜索变量。所有pose都能被离散操作选中；创建、重新配对、恢复和角色交换均属于一个槽位的一次试探。原2–4原位复用／2–4Juxtapose目标只适用于4–8任务集合，作为搜索排序和最终统计；允许0→1→2等尚未达到目标的中间布局。原位座位不由连续调整或差分偷偷移动成Juxtapose。

差分系数沿用0.6，采用共同材料坐标中同一个pose的座位质心差，叠加原有尺度的随机扰动。两个donor随机选自其他槽位，不要求比当前候选更好。按pose整块选择参与移动的Juxtapose座位，至少选择一个。退出方向沿用原有小幅随机转动提案。

短调整只有一轮：沿用原方向／XYZ／地面高度提案，尝试有限个局部探针，最多接受一次布局调整。刚刚发生探索的布局使用自己的几何和损失；原候选的受力mask不能挂到改变后的布局上。有限局部探针是一次调整内部的计算，不增加活动候选槽位。

槽位接受依据包括组合目标进展、原受力连续损失、地脚包围缺口、必要占用盒；已经构造通过的成品使用真实完整BBX与材料量。保留最佳已认证成品作为只读结果记录，不作为第33个活动候选。少量未完成槽位允许接受结构探索，以免一次局部暂时变差永久封死组合变化；每次均记录接受原因。

全部候选使用共同的原始需求求积测度快筛。每轮最多8个新布局检查每个pose全部32768原始需求，最多3个新候选检查共同连接，最多2个构造成品。未经完整检查的布局明确标记待认证。最后对32个槽位中尚未认证的布局完成原需求检查，再对最多3个新候选查连接、最多2个构造成品并选择最终结果。局部快筛不构成物理PASS。

不改变原任务旋转、原接触反力、原需求、工作禁区、退出条件、地面和数值验收容差。Step4输出分别报告原需求PASS、Oracle PASS、构造PASS和组合目标。运行到所有52个set结束；如有失败，保存其布局、原需求失败数和Oracle原因，不把失败写成成功，也不自动继续Step5。

固定初版参数：32槽位，8轮，随机种子42，离散／差分概率0.5；原物理阶段按当前原验收执行。运行记录、初始化、槽位变更和结果保存在新的 `data/results/B/` 批次目录，B图片保持PNG、不生成HTML。

实现中离散分支随机选当前候选的pose：若它已换座，则20%恢复原位，另10%在存在原位pose时做角色交换，其余重新配对；原位pose直接尝试创建换座。槽位按组合进展和可行性排序接受改善；未完成槽位的离散结构试探若未降低组合目标进展，有10%概率保留探索，接受原因单独记录。候选数仍为32。局部一轮最多评价10个正式调整探针，内部方向／XYZ割线计算另外计数。
