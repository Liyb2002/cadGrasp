# 七组加工流程占用空间对照

统计最近完成并最终选定的七个8–10 pose set（3个本轮新方案、4个保留方案）。每一组以**同一世界XYZ轴的一个包围盒**容纳所有加工姿态，不把各pose的包围盒相加，也不把每个pose重新居中。体积单位cm³。

- 无支撑：保持数据中各pose原生摆放，统计物体在所有加工姿态下的整体包围盒。
- 有支撑：采用最终保存布局，物体和支撑分别应用实际变换，统计所有加工姿态下物体加支撑的整体包围盒。
- 此表统计加工时的空间需求，不含装卸路径、中间搬运/转动轨迹、机器人、工作禁区或尚未构建的Step5底座。

## 计算与来源

每个pose的支撑变换为 `T = native_world[hosts[k]]`，物体变换为 `T @ placements[k]`，与现有最终结果渲染一致。分别取所有变换后顶点的世界坐标极值，体积为 `(maxX-minX)(maxY-minY)(maxZ-minZ)`。

读取已有物体mesh、最终support.obj、layout.npz和原生setup.npz，核对了全部62个pose实例的变换及所选支撑的材料体积。没有运行新搜索、力矩求解、Boolean或几何修复。
