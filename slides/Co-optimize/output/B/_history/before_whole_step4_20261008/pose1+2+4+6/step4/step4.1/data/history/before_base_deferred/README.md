# pose1+2+4+6：Step4.1 退出初始化

此组没有非零共同退出方向。当前初始化使用固定多起点半球投影，求各 pose 相近且合法的退出方向；不是随机方向选择，也不保证最小切除体积或承载通过。见 [当前算法](../../../../../algorithm.md)。

Step4.1 从不可变 Step3.3 支撑构造完整退出 sweep 及净空切除。构造完成后，载荷、接地、路径和几何结果只作诊断，不否决初始化。实际数值与方向以 data/report.json、data/render.json 各自记录及输入来源为准；演示方向不是优化器选定方向，图片更新不能视作求解重跑。
