# 十个非法组：独立平移测试

不修改 Step4 算法或现有模型。固定各 pose 的旋转，复用每 pose 全部 32,768 个原始需求点；本测试只判断跨姿态的需求点地面兼容性，不构造或验收完整夹具。

位移 s_i 是物体在共享支撑坐标中的位置偏移。新安装变换为 R_i(x − s_i) + a_i；移位后的物体和需求点仍回到原来的原生世界位置，因此物体保持原来的落地姿态。

两种模式：沿自身地面的平移满足 n_i·s_i=0；一般三维平移允许支撑相对物体的安装位置也沿法向调整。三维模式并非把物体悬空抬离桌面。

地面内模式：8/10 存在平移解；其中五组在 5 mm 内，三组分别需约 77 mm、111 mm、1805 mm。两组无解由非负约束组合的抵消证据确认，不是搜索超时。一般三维模式：10/10 存在解，五组在 5 mm 内，另外五组需约 39–84 mm。

所有可行候选已由项目现有 check_floor_points 对全部原始点复核。所有输入哈希保持一致。具体逐 pose 偏移、安装变换、每个有向姿态对的高度和无解证据见 results.json。

结论限于原始需求点的地面兼容性。尚未重新构造共享材料，也未验证新的实际接触承载、退出、真实接地材料覆盖或连通；现有模型不能直接沿用为平移后的成功模型。
