# Translation：世界 XYZ，允许 airborne

当前生产 Oracle 搜索允许注册复用及 Juxtapose 后的 pose 使用三个世界坐标自由度，注册 pose 不必先 Juxtapose 才能改变位置。物体原任务朝向保持，位置可向任意 XYZ 方向调整，最低点不得穿地；离地后可下降回到地面。

另外，[installation.py](installation.py) 优化每个支撑 state 的世界 XYZ 安装位移：$T_j=(R_j,t_j^0+\delta t_j)$。$R_j$ 不变；该 state 的全部物体任务一起移动，座位 $Q_i$ 和局部方向保持。只改 $Q_i$ 不移动共同地面，改 $T_j$ 会更新所有相关地面约束、接触可用性及实际地面需求凸包。Oracle 不通过时先尝试独立和协同安装位移，再进入原 Juxtapose 搜索；方向／步幅候选仍由相同目标及 Oracle 判断。

## 一个三维梯度

[layout_update.py](layout_update.py) 对全组需求积分平方距离求同一世界梯度：

\[
g_i=(\partial_xL,\partial_yL,\partial_zL),\qquad
 t_i'=\Pi_{h_i\ge0}\!\left(t_i-\alpha g_i/\|g_i\|\right).
\]

这里 $h_i$ 是工件最低点高度。三轴使用同一差分尺度、范数与步幅池；着地边界对Z使用可行单边差分并投影下降方向。世界位移乘各host旋转转置转换为支撑局部坐标；不同host的共同移动也对应同一世界向量。

内部覆盖损失与 Direction 共用 [R6 投影基底复用](../direction_choice/r6_gradient.py)：
需求从 [精确前向公式](../../../../objects/r6_quadratic.md)生成，保留相同积分节点、权重与尺度；
接触变化后，只在有效基底丢失接触或新增接触违反对偶条件时更新投影。
平移不改变绕 COM 的需求，改变的是可用接触和实际地面反力。因此三个轴仍使用接触事件割线，
地面处保留可行单边处理。外部调用、需求积分与步幅池保持不变；显式传入的减材料目标仍使用该目标的实际值。

[proposals.py](proposals.py) 提出独立／协同三维梯度步和正反XYZ轴样本。普通差分为物体尺度的1/100，独立步幅为1/128、1/64、1/32、1/16、1/8身位；细修用更小尺度。多步幅按全组损失与原需求比较，sampling与gradient分别记录。

## 零余量地面约束

物体表面点 $p$ 的支撑接触必须满足 $\min_j(T_jQ_ip)_z\ge0$，其中 $j$ 遍历全部最终支撑 state。这一筛选同时用于接触增删缓存、连续损失与原始需求检查。没有5mm安全余量，也不膨胀 Oracle 禁区来预留脚块；任意细的正宽度合法空间保留。物体自身最低点只需 $z\ge0$，base 地脚可接地，保留数值容差。

[ground_support.py](../ground_support.py) 使用实际安装地面计算每条世界 XYZ 探针的接触进入／离开事件；零余量下沿用原差分尺度，不额外设置10mm探针。正反方向分别计算，着地处仍用可行单边探针。抬高释放的接触、接触减少与工件地面反力消失共同进入目标；不预设 +Z 比 XY 更好。

修改一个pose时更新其自己的接触行、它对其他pose的阻挡列，以及材料覆盖增删。共同移动可同时释放多个pose锁住的接触。平移改变落座终点，横移轨迹不切成滑道。

## airborne 的反力变化

物体最低点高于1e-9m时，删除工件自身四个物理地面反力列；回到地面后恢复。第七方程非负slack保留，缓存区分实际接地状态。原重力及绕质心的32768需求数组不变，不单独计算airborne需求。

所有pose的需求收益与损失共同进入 $L$。最终位置对系统—地面的力矩变化由Step5处理。[物理公式](../../../obj_supp/airborne_equations.md)

## 可行减材料与保存

[volume_descent.py](volume_descent.py) 在固定体积积分框内提出Direction和XYZ减材料候选，只接受材料下降且全部原需求仍通过的步骤。

选定结果后直接复用已有mask／反力。mesh导出保持布局不变，仅用于显示与实体体积；导出失败不改变力／力矩PASS，估计体积不能替换有实体体积的旧答案。

当前整体PASS还要求动态base Oracle的合法地脚包围与共同连接通过；减材料不能丢失Oracle可行性。旧52组固定安装位置批次保留其原来源；本次安装XYZ／零余量修改不追溯改变旧结果。详见[根README](../../../../README.md)，实现见[完整搜索](../../step4.2/base_oracle.md)。
