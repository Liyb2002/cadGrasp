## 运行与算法

起点为保存的 Step4.1 方向、零平移。方向及原始地面切平面内平移共享实际最坏力锥缺口目标；梯度与接触事件仅生成候选，步幅尝试 4、2、1、1/2、1/4、1/8、1/16。每轮最多六个实际几何候选，分别给不同工具和步幅保留名额。接受必须保住所有已通过的具体载荷并严格改善真实全局最坏缺口；近似相同收益按真实占地、平移、角度选优。累计预算：10mm 平移、15° 方向、20% 占地扩张；第一 pose 不平移。

命令：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python slides/Co-optimize/step4.2/run_placement_sampling.py --object B --search multi-step --iterations 12 --candidates 4 --finalists 6 --workers 4 --out slides/Co-optimize/data/experiments/<fresh-name>
```

## 失败原因

所有最终布局都没有接受平移。94 个平移候选记录中，84 个破坏已通过的载荷，8 个几何/净空数值验收未解决，2 个未降低真实最差缺口；这是候选记录数，包含重复端点的缓存复用。方向候选也有真实缺口平台及几何数值失败。具体轨迹在各 set 的 `data/sampling_trace.json`，计数见 `candidate_summary.json`。没有候选因占地预算而被拒绝；不能把失败都归因于占地上限。失败不证明不存在小布局解，也不能据此确认平移算法有效。

仅缩小步幅的对照批次 `../multistep_two_tool_B_20261007` 完成 1/7；扩大端点跨过接触切换后，新版完成 2/7。旧 packing 批次的 7/7 不能当作本次算法证据。
