# B：准备一个用户给定的抓取输入

用户最终定义：**抓取位置由用户指定，求抓取不是贡献；kinematics 是支撑设计约束。**
本目录的辅助搜索仅用于准备一个示例输入。之后将其冻结，支撑优化不能自动移动它。
固定抓取位置不固定插入路径；机器人可在保持物体—夹爪相对位姿的条件下平移、转动和走分段路径。

## 当前示例与实际结果

`example_user_grasp.json` 给定 B 的一个固定相对抓取位姿和 69.783mm 中央指垫间距。
相对位姿 `T_object_hand` 把手坐标映射到已注册的物体公共坐标，平移单位为米：

```json
{
  "object": "B",
  "poses": ["pose_1", "pose_2", "pose_4", "pose_6"],
  "T_object_hand": [
    [-0.26535090546227424, 0.8488337999087537, -0.45724181469198194, 0.004323824549239152],
    [-0.47755174952560675, 0.2962723512245584, 0.8271438934217579, 0.0912419807140095],
    [0.8375758016414893, 0.4378400096294735, 0.32674592954202075, -0.07275293669330841],
    [0, 0, 0, 1]
  ],
  "gap_m": 0.06978260192871094,
  "station_offset_m": [0.45, 0, 0.15]
}
```

权威验证为 [user_fixed_validation/report.json](user_fixed_validation/report.json)。
输入原样固定，没有位置搜索或再对中。检查结果：

- 原装 Franka 手部接近、闭合及非指垫碰撞：通过。
- 完整指垫避开四个 pose 工作面并集：通过。
- 双侧实际指垫接触：通过。
- pose1、2、4、6 的物体抓取端点 IK、手臂自碰撞／物体／地面检查：均通过。
- 基于实际裁剪接触斑、摩擦系数 .8 的准静态重力平衡：均通过。没有真实质量、夹持力上限或动态／强度接受证书。

![一个固定抓取位置在四个姿态中的示意](user_fixed_validation/grasp.png)

尚未通过：最终支撑共同抓取、实际装载路径、完整转移轨迹和最终承载支撑。
这些需要 Step5 在固定抓取约束下设计实际材料并回验。没有把物体抓取端点通过称为完整 Step4/夹具通过。
`constraints_for_step5.json` 输出固定相对位姿、接触区域、可用装载 pose 和 SE3 路径接口。

另验了一个保持该抓取不变的物体自由空间分段运动：抬高 30mm，再横移 25/20mm
并转动 20°，采样 IK／碰撞通过，物体—手相对位姿最大误差为 2.22e-16。
记录为 `user_fixed_validation/free_space_path.json`。它直接验证固定抓取允许转动／弯折路径，
没有最终支撑参与，不是插入或完整任务转移证书。

## 为什么先前没有找到

先前的 100 对候选按靠近重心排序，只试了 15–70mm 宽度与单一 103mm 指垫深度，
属于有限且偏向中心的采样。B 的非工作面实际约占 75.15%，可用远离工作面的区域未被优先访问。
辅助准备扩大到 4–80mm、按工作面距离排序、15°朝向采样和三种接触深度，并按两侧首次实际接触对中。
在前 20 个手部配置中准备了 8 个装载候选，来自 4 对不同接触；其中 4 个候选四个姿态端点都通过。
这些采样改进只说明示例输入可以获得，不作为支撑方法贡献。

同时修正了两个模型接口问题：中央指垫间距比双指关节原点间距多 3mm；
官方固定底座碰撞网格在安装面下延伸约 32.5μm，不能把其安装接触当移动连杆穿地。
对应测试已加入。通过首次接触对中避免将一侧刚性指垫继续穿入物体来强行获得另一侧接触；
0.4mm 总闭合量仅作两侧接触斑的数值探测。

## 历史诊断

- `stock_expanded`：因发现固定底座地面判定问题而中断，未完成，不作可行／不可行结论。
- `stock_calibrated`：初步宽度校准，未对两侧首次接触对中，候选不能当最终输入证据。
- `stock_first_contact`：准备 8 个候选并保存实际接触、各 pose IK、碰撞、重力结果；选第 5 个作为固定示例。
- `common_proxy`：早期 5mm 全非工作面薄壳的共同抓取诊断。8 个输入没有完整共同通过：
  3 个端点手臂碰撞，2 个手部碰撞，2 个最大开口不足，1 个保持失败。不是最终支撑，也不限制 Step5 重新设计材料。

所有实验保存实际启动代码与输入哈希。此前 `single_load_B_20261007` 结果保留，不能将旧 1,200 候选失败解释为物体不可抓。

旧初始化／搜索已迁到 [Step5.1](../../../step5.1/README.md)、[Step5.2](../../../step5.2/README.md)，原路径为兼容别名。
