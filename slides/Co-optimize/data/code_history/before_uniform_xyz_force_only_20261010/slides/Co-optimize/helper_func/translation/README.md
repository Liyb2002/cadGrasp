## XYZ 候选与材料下降（2026-10-10）

新增高度自由度保留原来的 XY 梯度及候选顺序。含高度的梯度／接触事件候选由 [proposals.py](proposals.py) 单独提出，不改变原有采样分组。全部需求已满足后，[volume_descent.py](volume_descent.py) 在同一个占据积分框内对材料体积做 XYZ 数值下降，并用所有 pose 的原始需求检查每个接受步骤。

最终选择始终保留同组已验收的最小体积解；只有真实验收通过且实体材料更少的新解才能替换。高度候选失败、超时或者产生更多材料，均不能使最终所选结果退步。新冷搜索与保留结果在输出中分别记录。

## 当前XYZ扩展（2026-10-10）

已Juxtapose的pose可沿世界XY及+z平移；物体朝向保持原样，位置投影到最低点z≥0。`layout_update.py`负责局部／世界坐标转换、边界投影与单边差分。梯度仍对所有pose的需求距离计算收益和损失。抬高后删除物体地面反力，保留第七方程的非负slack；缓存按实际接地状态区分。绕质心的需求沿用原数组，不重新采样。Step5系统—地面的基座设计仍需按最终位置计算。

# Translation

`translation(objective,current,...)` 仅修改已显式Juxtapose的配置，原注册复用配置保持位置。两个坐标对应世界水平面，以物体最大尺寸归一化；任务朝向与世界高度不变。

对同一个全组需求积分平方距离求有限差分，而不是对通过数量或最远需求求导。正反扰动均重新计算所有pose的接触增减、力臂和共享遮挡。梯度能同时记录某pose改善、另一个变差。默认差分1/512身位、最大每pose步幅1/32身位；由联合斜率／正曲率计算建议距离，并做Armijo回溯。

平移的是设计中的落座终点，未挖重定位滑动通道。候选更新表面接触多边形，不重建三维Boolean。全组满足需求后才降体积，并先固定共同体积积分域，防止包围盒变化污染差分。真实接受沿用原完整载荷和几何检查。
