# Step4.2：共同方向探索与物理梯度的混合求解

入口：`physics_guided_hybrid.py`。从各组自己的 Step4.1 原始退出方向开始，不读取旧版成功方向。固定全部 pose、原始支撑和每个 pose 的 32,768 条载荷。

## 为什么融合

旧版共同方向搜索能一次改变多条退出通道，跨过共同遮挡的障碍；单靠局部梯度可能被这些障碍困住。之前的获取代价 LP 又允许支付代价使用尚不存在的接触，其反力权重不等于真实支撑当前最缺的反力。混合版保留共同方向探索，并将局部反馈改成真实接触锥的承载残差。

## 求解过程

1. 精确构造 Step4.1 初始化，检查全部原始载荷。数值未解的初始化单独记录，仍允许测试其他合法退出方向。
2. 从原始支撑的实际接触边界建立潜在接触池；不凭空添加接触面，不重新采样载荷。
3. 对失败载荷求真实反力锥投影。设残差 `r = A f − b`，候选归一化反力生成元为 `a`。增加该反力的收益为 `max(0, −a·r)²/2`；这是保持已有反力、增加一个非负系数时可达到的残差下降量。由此判断恢复哪些接触最有价值。
4. 用投影的分离平面扫描全部原始载荷，补入遗漏的困难载荷，再精确投影候选；这是工作集选择，不宣称求到了所有载荷的精确最大残差。
5. 沿用旧版共同方向的思路：先取共同趋势，再投影到各 pose 的合法退出半球。球面覆盖是确定性的，按物理接触收益排序。乐观接触锥只用于必要条件筛选，只有验证了分离证书才能拒绝候选；候选通过筛选后仍要精确构造、检查全部载荷。
6. 对有希望的真实支撑做联合梯度调整：冻结一轮的物理接触价值，优化加权遮挡代价。每个退出方向有两个自由度；接触兼容性的敏感度解析计算，轨迹距离场的敏感度数值计算，联合切平面更新采用 SLSQP。
7. 精确重构候选，接受真实承载缺口下降，或同一组冻结价值下的非线性遮挡代价下降。后一类允许暂时承载退步，让多条通道逐步让开。实际检查的较好状态始终保留。
8. 局部停滞时，尝试共同趋势的局部邻域、单个方向的邻域，以及几个不同的真实支撑起点；最终返回全通过状态或本次预算内较好的真实状态。

## 几何和接受规则

完整退出始终保留物体最大尺寸每侧 1% 的余量。实际与全部名义退出兼容的承载接触核沿用共用例外规则；局部接触遮挡模型使用名义轨迹，不把这项例外误当成必须额外后退的间隙。距离场及正穿透的 p=8 聚合只指导优化，不能代替精确实体检查。

本轮按用户要求暂缓连通性优化。成功要求每个 pose 的全部原始载荷通过，并且完整退出及 1% 几何规则通过；连通性另外记录。这不代表完整夹具的地面承载、强度和机器人路径都已解决。

混合版仍包含有限方向探索，并非纯梯度下降。默认最多 1,200 个探索提案；每个阶段最多 12 轮梯度更新，多阶段总轮数可能超过 12。结果比较必须注明预算，不能把预算增加产生的改善全部归因于建模变化。
