# Step4.2 算法记录：调整退出方向，恢复承载与连通

记录日期：2026-10-05。本文件记录当前已运行版本；下一步的位置平移尚未实现。

## 问题与设计变量

Step3.3 提供一个共享初始实体 S0：共同非工作表面的包裹壳与接地圈。各 pose 的物体在原始 mesh 坐标中重合；同一个支撑随各 pose 的保存变换安装、翻转。初始物体摆放、工作面、质心、原始地面模型和载荷都固定。

当前可修改的是每个 pose 的直线退出方向 d_i，而不是接触片的位置。修改方向后，重新从 S0 扣除全部退出扫掠，恢复不再被通道占用的原始材料。没有移动初始物体、旋转退出或增加连接杆。

设 W_i(d_i) 为完整物体沿方向 d_i 平移的连续扫掠实体，候选材料为：

`R(d) = S0 − union_i W_i(d_i)`

删块之后的最终支撑是 R 的一个子集。每次方向改变都重新从 S0 构造，不能在上一轮已经切碎的支撑上继续单向删减，否则无法恢复材料。

## 初始化与合法退出

Step4.1 使用各 pose 自己的原生世界 +z 作为退出方向，转到共同支撑坐标后通常是不同方向。这种初始化容易切掉大量共享材料。

Step4.2 复用已有保存方向作为热启动，并尝试让各方向向共同趋势靠拢。合法半球属于每个 pose 自己的地面：在共同坐标中，以该 pose 的世界 +z 转换得到 n_i，要求 `d_i · n_i >= 0`。不是所有 pose 使用同一个世界半球。

完整构造使用至少 500 mm 的平移长度，并保证终点物体完全脱离初始支撑。连续扫掠由物体及相应平移棱柱做实体并集，不以离散截图或凸包代替。接受时还检查物体沿路径不进入自身地面、剩余材料与完整扫掠无体积重叠。示意图的箭头和前 100 mm 展示不决定实际切除长度。

## 候选的承载检查

1. 构造 R，并提取正体积材料的真实内边界与原始允许源面的接触交集。
2. 排除工作面及不符合初始退出速度的接触残片。对当前纯平移，接触源面外法向与任一退出方向的点积不能为正；这用于避免把共面零体积残片误当作有效承载接触。
3. 对每个 pose，用真实接触点、原始法向及原始质心重建力和力矩生成元；沿用保存的原生地面摩擦模型和 no-uplift 方程。
4. 检查该 pose 的全部 32,768 个固定需求。所有 pose 全部通过，才允许把候选当作承载可行状态。

不重新撒点、不减少失败载荷、不增加自由力矩或受拉接触。理想源面生成元和接触法向可用于便宜筛选、失败载荷诊断，但不能替代真实材料的完整检查。求解超时或数值异常标为未决，不构成不可行证明。

## 先判断碎块的价值

材料连通分量有两种删减方式：

- 如果某个正体积连通块独立满足所有 pose 的全部需求，保留它，其他分量可以一起删除。最终还检查完整退出和材料体积分割。
- 如果承载需要多个块，按体积从小到大逐块试删；每次都检查“当前剩余块减去这一块”的全部需求，全部通过才真正删除，再测试下一个块。

不能把所有在原集合中分别可删的块同时删除；它们可能互为替代。单块不能独立承载也不表示无用，多个块可能提供互补反力。逐块试删得到的是当前接触配置和删除顺序下的必要集合，不是全局最少块数。

当前“有价值”仅按承载需求判定。接地覆盖或强度加入后，某些当前可删材料可能需要恢复。正体积判断排除数值薄片，并不提供最小厚度或结构强度保证。

## 搜索策略与接受条件

先检查保存方向能否通过保留一个承载充分的分量直接完成。否则尝试共同方向趋势，将每个方向分别投影到自身合法半球；使用确定性的球面方向菜单和局部角度细化。随后逐 pose 调整方位和离地分量，使被该退出通道单独占用的原始材料重新出现。

常规连接搜索用单个分量的完整承载 pose 数、最差承载率和总承载率引导。困难六 pose 组还使用两种引导：最差 pose 的承载数优先；或先识别必要接触块，再减少必要块数量与块间距离。距离与源面邻近性仅是搜索启发，最终通过必须依据真实实体和全部需求。为控制成本，部分候选只检查最大的三个分量，因此搜索未解也可能是候选检查预算不足。

两段平移、失败载荷反力面引导和联合反力约束方向搜索已作有界实验，尚未补齐剩余两组；它们不是当前 18 组成功结果采用了更一般路径的证据，也不是默认入口全部执行的搜索阶段。

最终 PASS 同时要求：所有原始承载需求通过；合法完整退出；一个连通的正体积支撑；扫掠重叠及材料分割误差通过构造容差。只做一次构造接受，不做导出模型回放。未要求最小材料量、最小包围盒或全局最优。

## 代码、运行和输出

在项目根目录运行：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  .venv/bin/python slides/Co-optimize/step4.2/run.py --jobs 2
```

`--sets <set>` 选择组；`--fresh` 从保存方向重新构造和分类。默认复用来源与输出哈希有效的完整通过记录，未完成组继续有界搜索；存在未完成组时批次退出码为 2。

入口为 `step4.2/step42_connected_all.py`，分派在 `step4.2/step42_dispatch.py`。主要构造与单块检查在 `step4.2/step42_connected.py`；接触修正在 `step4.2/step42_contact_consistency.py`；困难组引导在 `step4.2/step42_value_guided.py` 和 `step4.2/step42_balanced.py`。`helper_func/step42_geometry_cache.py` 缓存完全相同几何和位移的连续扫掠，修改方向或几何会改变键，没有角度量化近似。

结果入口：[B 汇总](../output/B/README.md)。各组仅公开 `overview.png` 和 `exit_motion.png`，模型为 `remaining_support.obj`、`removed_support.obj`、`restored_support.obj`；原始需求判定、来源、搜索记录放在内部 `data/`。旧阶段记录归档，不改写成新的成功证明。

## 下一步：退出方向与小幅位置平移共同优化

用户提出新增一个 operation：物体的初始位置也可以小幅平移，从而增加退出通道与材料连接的空间。下一版本将考虑每个 pose 的方向 d_i 和位置偏移 t_i，而不是只调整方向。这是初始摆放变量，区别于物体沿退出路径运动。

尚需明确平移坐标、幅度与合法范围；优先研究保持姿态和落地的地面内平移。不同 pose 的物体不再完全重合后，必须重新定义共享支撑坐标中的物体、工作面、接触和扫掠，保证同一个实际支撑在各安装状态中成立。接触点与质心的坐标关系、地面需求及覆盖要一致变换，并重新计算真实接触的力矩生成元与全部承载检查，不能把物体相对支撑的移动当作无影响的整体平移。

目标仍是尽量保持物体重叠，同时恢复合法退出、承载和连通。现有 18/20 结果作为固定位置基线保存；本次只记录扩展方向，不改变几何或运行位置搜索。
