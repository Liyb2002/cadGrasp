# Step4.2：Sampling + Gradient 并行求解

入口：[physics_guided_parallel.py](physics_guided_parallel.py)。继承混合模型的真实接触锥反馈、精确几何与 1% 退出余量；每组仍从自己的 Step4.1 初始化开始，不使用旧版成功方向。

## 两条流如何合作

采样流沿用共同方向趋势：先生成共同趋势，再投影到各 pose 的合法退出半球。在球面覆盖中穿插共同方向和单方向的小邻域，各角度尺度轮流测试，避免把全部预算花在粗尺度。

梯度流从有希望且不同的真实候选启动。每个分支最多两轮联合方向更新，最多八个分支；某个分支停滞或落入不好的区域，就换起点。采样流不等待这个分支结束。两条流拥有独立的几何求解对象、投影缓存和写入目录，梯度结束后将实际构造结果交回主流候选池。

物理反馈来自当前真实支撑的反力锥投影残差 `r = Af − b`。候选归一化生成元 `a` 的增益为 `max(0, −a·r)²/2`，据此给恢复接触分配价值。梯度在全部退出方向的切平面里联合优化加权遮挡目标；保留承载改善或冻结接触价值下的非线性遮挡改善，允许必要的中间退步。

候选池按真实载荷覆盖保留较好状态和几个不同方向的状态；局部接受看实际承载缺口或几何进展，最终成功只看完整验收。代理模型用于导向，不作为承载证明。

## 数值与预算

反力系数保持非负、无容量上限。优先使用稀疏活动锥求解；大问题兜底采用迭代最小二乘，再精修小活动集并扫描全部生成元检查 KKT，避免巨大的稠密增广问题。快速必要条件筛选只保留少量困难载荷；每次精确构造和最终验收仍检查每个 pose 的全部 32,768 条原始载荷。

默认最多 1,200 个采样提案，最多八个两轮梯度分支。采样与梯度在同一组内并发，因此耗时比较需要注明硬件并发条件；不能仅凭墙钟时间宣称计算量降低。原输入、源码与输出哈希随 report 保存。主流的 `exact_evaluations` 目前只计采样流，分析梯度成本时需另看分支日志，不能将该字段当作两条流的总成本。

## 最终验收

所有 pose 全部原始载荷通过，完整退出、终点分离、体积分割及每侧 1% 余量通过精确实体检查。按当前用户要求，连通性另外记录；这不代表完整夹具的地面承载、强度或机器人路径已经解决。
