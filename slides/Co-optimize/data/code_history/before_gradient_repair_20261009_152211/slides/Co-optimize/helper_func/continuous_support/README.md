# 共享的连续覆盖目标

三个operation共用 `CoverageObjective`。直接读取不可变 `needs.json` 的连续域：原工作面位置、原30°半角、原0～0.5mg加工力、原物体自身可达性。力与力矩由同一作用点／同一加工力生成；不独立抽六维wrench，不修改32768个原保存载荷。

固定位置与方向时，需求是加工力大小的仿射函数。原非负、无幅值上限的七方程反力模型形成凸锥，需求线段与锥的交集是区间。`coverage.py` 求可支撑大小区间，占原大小区间的比例；原面积／立体角加权的确定性求积节点再积分这个比例。LP的primal basis和dual plane同时更新多个方向的区间界，避免每个节点都解独立LP。纯重力不通过时，保留一般非零下端点／空区间处理，不能默认从零开始。

搜索用全组平均未覆盖比例，加极小的材料项；全部积分覆盖后切换到材料目标。这里的梯度是对此目标做中心差分，而不是对32768项通过数量或单个最远需求求导。

`contacts.py` 在原非工作三角形上计算完整工作锥、物体和全长退出扫掠的带符号约束。细分原接触面，线性插值约束并切出边界；边界顶点随方向／位置移动。按同一面法向和顶点力臂生成原反力列，不用面积乘权重伪造压力容量。整组所有配置的排除共同参与。此接触边界为分片线性近似，拓扑变化仍有不可导点；评价不做实体Boolean。

默认工作面每三角形一个位置节点、一个径向Gauss节点、四个方位节点；更细一级检查同一布局。此积分不是整个连续域的包含证书。原完整工作禁区一直用于搜索排除，最终接受仍检查真实接触／核心／1%净空／完整退出与全部原始32768载荷。材料估计沿用共同Sobol空间点；它属于体积求积，不是操作候选抽样。
