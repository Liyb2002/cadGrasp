# Step4.1：多配置装卸初始化

为同一物体的每个任务配置初始化装卸方向，并从共享包裹与接地环种子构造初始支撑。优先使用共同合法方向；没有共同方向时，初始化相近合法方向。代码保存退出方向 d，装入沿 −d，退出沿 +d。

每个配置都需要自己的装卸路径；切除所有完整退出扫掠的并集，构造1%净空并重建可用接触。力学和接地检查作初始化诊断，不因未通过承载而抹去构造结果，也不代表完整夹具通过。

```sh
.venv/bin/python slides/Co-optimize/step4.1/run.py --help
```
