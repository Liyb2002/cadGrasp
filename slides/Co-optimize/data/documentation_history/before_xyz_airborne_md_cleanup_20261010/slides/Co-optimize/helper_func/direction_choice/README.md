# Direction choice

`direction_choice(objective,current,...)` 对全组需求到原可支撑反力锥的积分平方距离求有限差分梯度。每次扰动重新评价所有pose，包含其他pose的收益与损失；不选择单个最远需求，覆盖比例不参与修复梯度。

落座与退出方向相同的pose采用共享参数联合差分，其他方向分别更新。这样可计入一起移动才能释放的接触。

两个球面切坐标通过指数映射更新单位方向，保持原合法半球。边界使用可行单侧导数并投影下降方向，避免把非法扰动截断后当作中心差分。默认角差分0.75度、每pose最大步幅2度。较小联合扰动核对下降斜率，正曲率用于计算建议步幅，之后Armijo回溯。

全部求积需求及零力／最大力边界满足后，接口下降材料体积并保持每pose的需求条件。最终真实网格和原32768载荷的接受由Step4.2完成。详细公式见 `../../step4.2/continuous_algorithm.md`。

共享更新停滞时再检查各pose独立方向。预测与更小扰动不一致时，缩小差分再核对；若接触法向集合发生变化，则明确标记有限割线的接触事件更新，并细化步幅，不冒充匹配的局部梯度。
