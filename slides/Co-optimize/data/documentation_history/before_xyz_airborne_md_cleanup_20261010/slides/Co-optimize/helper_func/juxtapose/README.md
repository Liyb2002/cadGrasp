# Juxtapose

入口：`juxtapose(objective, current, budget=4, refine=...)`。它是停滞后的**离散跳步**，独立于两个连续更新接口。

优先考虑覆盖不足的pose及正在阻挡它们的配置。按世界退出方向接近程度选择已有host，在世界水平面内对齐物体中心，保持任务原世界朝向和高度，拒绝几乎不重叠的远距摆放。还允许跳回原注册／转动复用布局，以减少永久增加的材料。

有界枚举少量guest/host组合，计算每个布局的整组覆盖和材料估计。给选中的一个跳步做Direction和Translation局部连续修复，比较修复后的结果。原始跳步可以暂时退步；实际可行支撑另行保留，未完成真实检查的分支不能替换它。没有随机落座采样，也不承诺一次跳步必然更好。
