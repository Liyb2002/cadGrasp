# whole 搜索的实际实现

本页描述已完成42组可行性基线的初版搜索。新增的可行后多个布局／修复分支减材料实现，见 [论文算法](paper_algorithm.md) 和 `helper_func/compact_volume.py`；它不冻结早期 host，保留多个答案并按实际体积选择。两种延续方法各自结果与原基线均保存。

整组 pose 从 Step4.1 就全部激活；whole 指所有配置始终共同评价，不代表已证明全局最优。每个配置保存物体到支撑的变换 Q、支撑摆放 host 和物体相对退出方向 d。必须满足 T_host Q 的旋转与世界高度等于原任务 T_i；Translation 只改变允许的地面内位置。转动支撑复用不受摆放数量惩罚。

## 共同评价与最不满足需求

保持原始 32,768 载荷／pose、力／力矩归一化尺度、非负无界法向反力、原地面模型和第七维不上抬约束。每个接触贡献法向及相对于原物体重心的力矩，构成原七维反力锥。先检查全部原载荷，再在全部失败需求中找距当前反力锥最远的一项；原始极端需求同时作为快速筛选的保护项。

最远距离通过原七维反力锥的非负投影计算，检查 KKT 残差。方向变化仅影响接触释放／锁定，不改变载荷与工作锥。面积只表示几何范围，不是反力容量。

尚未全组可行时的比较顺序为：全组未满足原载荷数、同一当前需求库中的最大投影距离与距离和、材料估计、占地等次要指标。允许个别任务退步，只要整组评价改善。全部可行后只接受仍全组可行的材料下降。

## 三种操作及多个步幅

**Direction 优先。** 在各方向的二维切平面，用 ±0.75° 的接触增删查询估计当前最坏距离的中心差分；不为求导重建真实支撑。尝试联合负梯度步幅 0.25°、0.5°、1°、2°、4°、8°，以及单 pose 0.5°、2°、5° 和整组协同 ±2°、±5°。多个相近退出方向可能共同锁住同一接触，联合方向候选用于打破单方向微调无效的平台。接触可用性是离散的，梯度用于提出候选，实际选择依靠重新评价。接近可行且剩余失败少时另尝试 0.03125°、0.125°、0.25°。

**停滞时选择性 Juxtapose。** guest 是失败任务或当前明确阻挡失败接触的配置。优先已通过且世界退出方向相近的至多四个 host。保持 guest 原世界朝向和高度，将其落到 host 的支撑摆放下。位置候选包括零偏移、质心地面投影对齐，以及最大物体尺寸的 1/32、1/16、1/8、1/3 偏移；仍要求包围盒有至少 3% 的体积重叠。方向候选为 guest 原世界方向、两者中间方向及 host 世界方向。没有强制世界 +z、远距离分离或整组重新落座保底。

**Juxtapose 后 Translation＋Direction。** 分支局部修复仍比较整组。Translation 只允许已重新落座的配置在世界地面内移动；从最坏需求引导的方向和不同步幅提出候选，联合方向微调再检查所有新增和损失接触。可行后体积优化使用 1/128、1/32、1/8 身位平移步幅；也可尝试恢复原注册布局来减少材料。平移改变设计终点，不在支撑中打通平移滑道。

## 候选为何不需要 Boolean

每个原物体三角形有七个接触查询点，包括三个近顶点，保留接触法向和力臂。接触可用性同时要求原非工作域覆盖、退出领先侧合法，以及不被任一配置的物体、完整工作锥或退出空间锁定。

持久数据记录材料覆盖次数与每个 pose 的阻挡计数。改方向更新相关阻挡列；平移更新该配置自己的接触行及对其他配置的阻挡列。材料占据用同一个 Sobol 采样域比较增删；扩展采样域后重新比较基准，避免候选使用不同分母。供力列相同可复用分类结果，反力基仅在所有列仍存在且严格重放原七方程通过时复用，容差保持 2e-9。

名义材料估计与最终 1% 净空／接触核心几何存在差别，采样排序只用于搜索。每轮只对筛选出的少数候选检查全部原载荷；候选阶段不执行实体 Boolean。

## 材料构造与完整工作禁区

纯 Direction 始终从不可变的新 Step3.1 真实种子重新切除。Q 改变后则从每个 pose 原始 5 mm 贴合包裹域重建并集，再扣除全部当前物体、工作禁区和装卸路径。这样旧 sweep 不再需要时材料可恢复，新的贴合支撑也能生长；不能只对上一步空洞做单向删减。

工作禁区覆盖每个原始工作三角形所有点、原始 30° 半角的全部向外半射线。沿用 32 边外接保守锥，最大径向保守量约 0.484%；Boolean 盖面超过整个未切材料域，候选查询不设长度上限。Direction 不旋转加工禁区；Juxtapose／Translation 随配置变换完整工作锥。

## 最终真实检查与图

候选阶段结束后，最多三项真实候选重建原接触核心与核心外 1% 退出净空，检查完整路径和末端分离，导出 float64 网格并回读检查物体／工作锥／退出空间交叠。近共面数值问题仅用同一原排除域重新处理边界，原 1e-10 m³ 几何容差不变。

从最终真实接触三角形提取供力列，按原七方程复核全部原始载荷，并做原工作面检查。只有全部通过才发布 PASS。若 Step4.1 已实际可行，则保留它作为最终回退，并拒绝实际材料体积超过该基准的候选。最终失败只能留下诊断与真实失败记录。

过程图读取真实保存的选中布局，重建名义过程网格，用固定参考姿态和等轴测视角画材料增删；最后一格及最终各 pose 图使用验收后的实际 support.obj。过程网格不等于最终净空证书。普通图不覆盖工作禁区，Step3.2 的独立环绕图保留禁区展示。
