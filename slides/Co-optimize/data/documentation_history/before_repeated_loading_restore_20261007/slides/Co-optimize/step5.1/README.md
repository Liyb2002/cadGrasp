# Step5.1：支撑与装载路径初始化

2026-10-07 当前定义：Step4 接收用户指定的物体抓取位置，以 kinematics 约束设计；
求抓取位置不作为贡献。Step5.1 初始化抓取区域的薄支撑、几何锁、物体—支撑布局，
以及一个任务姿态的初始装入路径。固定抓取位置不固定装入方向；允许保持抓取并平移、
转动或沿分段路径装入。锁先按几何保持处理，不计算强度。

也不构成新的一次装入方案通过证据。
现有 `step41.py` 仍实现历史逐 pose 退出方向初始化；直接运行不意味着已经满足
一次装载／固定抓取／机器人路径约束。新流程复用其种子、扫掠切除、净空和接触重建工具，
但只为一次装入路径构造通道。新定义要求抓取区域的薄支撑与几何锁；旧初始化代码尚未加入这两项设计。
