# Juxtapose operation：重叠放置，决定怎么补支撑

配合 [Direction](../direction/README.md)，构成 [Step4.2](../../step4.2/algorithm.md) 的两个 operations。这里先实现一份独立几何演示，生产搜索尚未接入 Juxtapose。

## 当前示例：固定 pose1 的支撑，装入 pose2

使用隔壁 Direction 的 B/pose1+2+4+6 shape：读取它起点的 Step3.2 包裹和四个保存方向，重建同一份蓝色支撑，放在 pose1 的原生摆放。支撑始终保持这个位置与朝向；pose2 使用自己的原生物体朝向，试图装入这个位置。两个面板是同一支撑的两种分别使用方式，不是同时放两个物体。

视频按顺序展示：

1. 保持 pose1 的支撑，尝试装入 pose2；物体在真实首次碰撞附近停止，无法落座。
2. 撤回物体，把新物体和装卸路径需要挖掉的旧材料标红，再删掉。废弃原 pose2 配置，不继续将其旧退出路径作为新要求。
3. 从底部向上长出绿色支柱。只在可从下方接近的非工作面选择接触，补短脚梁与原蓝色材料的连接，不为新物体或它的 sweep 再造完整包裹。
4. 重新装入 pose2，展示它与新增底面支撑接触。最后绿色并入蓝色，同一件支撑仍可分别放入 pose1 和 pose2。

初始 pose2 物体占据与支撑相交约 **47.0 cm³**。本例删除约 **52.2 cm³**、新增约 **52.5 cm³**，最终为一件连通实体；新增材料在 pose2 上形成约 **1,243 mm²** 的真实接触。支柱及连接经过全部当前物体、工作区域和完整 500 mm 退出空间切除，最终两个物体占据、四个配置的名义退出体积交集均小于 `1e-10 m³`；四个原始工作面检查通过。

这份示例以底面几何选择接触，尚未根据最差力／力矩优化材料，也未执行全部原始载荷、1% 净空、安装接地或强度验收。新增面积不直接等于承载容量。保留原 Direction 起点的几何，接地安装仍沿用其待验收边界；这里不把构造底部平面宣称为合法工位地面。

## 输入与目标

输入是当前共享支撑、各任务的相对配置与退出方向，以及一个在当前布局上 Direction 已停滞的 pose。选择另一个已有 pose 作为 host，让待处理任务尝试使用 host 的支撑摆放：利用已有材料，还缺的承载由新增接触与材料补足。

Juxtapose 可以理解为高端版 translation：直接根据 host 和目标重叠关系确定最终相对位置，一步尝试终点，而不是反复做微小平移。它要输出的不只是“移了多少”，还包括“在哪里加、怎么连、加多少”。

## 操作过程

1. 选择若干 host。保持待处理任务的世界朝向、工作面和原始力／力矩，将其物体表达在 host 的支撑坐标中。物体在支撑坐标中的朝向可以与 host 物体不同。
2. 根据现有接触、包裹与可用空间提出重叠的最终放置；优先尝试 host 的世界绝对退出方向，必要时交给 Direction 调整。不同 host 和重叠程度产生不同候选。
3. 使用 Direction 同一套最不满足力／力矩的计算，在新布局上求实际缺口。检查已有接触，再寻找有利的接触位置和法向；候选区域必须不被任何配置的物体、工作区与装卸路径占据。
4. 借用 baseline 的联合接触反力评价，比较新增接触的实际收益，再生成相应有限厚度材料和连接。材料范围由所需接触与几何空隙决定，可以提出不同接触组合和补材料量。
5. 新物体及装卸空间也可能要求挖掉旧墙。重新构造共享材料，统计新增／恢复与删除／失去，提取所有 pose 的实际接触并验收全部原始载荷。

旧任务配置由新配置替换，不叠加保留已经废弃的旧物体占据与旧退出要求；旧通道不再被其他任务使用时可恢复材料。设计重定位不产生使用时的滑动通道，实际装入与退出必须按最终配置验收。

## 输出和选择依据

每个候选输出 host、最终物体相对布局、退出方向、建议新增接触、补材料及连接区域，以及要求删除的旧材料。报告新增体积、删除体积、占地变化、各 pose 载荷结果和最差缺口。

不能只看净体积或新增面积：新添的材料必须提供有用接触，删去的墙不能破坏其他已通过的需求。全部候选使用共同验收与载荷保护，改善接近时优先材料和占地代价较小的设计；不宣称全局最小或必然成功。
