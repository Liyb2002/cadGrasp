# Step4.2 operation demos

两个工具都从最不满足的反力、反力矩出发，更新所有 pose 的可用接触，比较真实全局误差后再接受。

- [Translation](translation/README.md)：同一 B 物体的四格最终布局调整视频、生成代码和动画记录。
- [Direction](direction/README.md)：最大反力差、接触区域与方向的求导链、球面梯度更新；含 `pose1+2+4+6` 既有视频及数值导数检查。

原模型的接触压力无界且非负。接触面积是几何量，不能直接当成承载容量；接触位置和法向决定反力锥。两份文档明确区分真实锥距离与连续几何引导函数。Direction 文档使用残差“预测减目标”和二分之一平方距离。

这些是独立 operation 的数学与演示，不代表七组 B 都已通过小幅移动解决。Direction 视频是既有示意动画，不是逐帧验收的梯度轨迹；Translation 是重定位紧贴包裹并重新扣除各当前退出空间的布局动画，完整 B 工作区、退出和受力验收仍需原算法。
