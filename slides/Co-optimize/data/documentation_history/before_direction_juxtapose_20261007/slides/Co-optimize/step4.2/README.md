# Step4.2：两种工具、多个步幅

从保存的 Step4.1 方向与零平移开始，同时尝试方向调整和地面切平面内相对平移，每个计算更新尝试七档步幅。更新所有配置的接触、物体位置和装卸禁区；保护已通过载荷，按真实全局最坏反力锥缺口改善选择，收益接近时优先较小占地。平移是设计布局修改，不是物体在支撑中滑动。

`step4.2/` 已恢复为实际代码目录。批量入口默认 `multi-step`，不调用分离保底；单组需要显式 `solver.py --search multi-step`，历史默认 `contact-recovery` 保持兼容。旧 `--search two-tool` 含分离保底，不能作为小步搜索的成功证据。

算法、预算和运行命令见 [algorithm.md](algorithm.md)。最新七组完成 **2/7通过、5/7未通过，没有接受平移**，见 [实验报告](../data/experiments/multistep_two_tool_v2_B_20261007/README.md)。生成平移候选时如何保留或替代旧承载仍需改进。

原始输入和已发布输出保留。完整夹具连通、安装后整件接地合法性与强度尚未验收。支撑摆放的多对多分配与不同物体共享是后续扩展。
