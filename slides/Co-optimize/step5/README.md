# Step5：按最终布局设计 base

Step4 得到工件可承载的共享支撑、每个任务的支撑摆放 state 和物体相对位置。Step5 从这个最终布局出发，处理系统—地面的力／力矩需求。

| 阶段 | 内容 | 实现 |
| --- | --- | --- |
| [Step5.1](../step5.1/README.md) | 按实际受力位置重算每个pose的地面压力中心撒点，画出各pose及共同支撑坐标下的点云 | 已实现 |
| 后续 base 构造 | 利用这些需求和各state的地面接触，补充共享底座材料 | 尚未实现 |

所有原载荷样本固定，Step5.1不包含sampling搜索。airborne无需新的绕质心需求；最终质心高度改变绕地面的力矩，因此地面撒点必须重新投影。

这里的系统是物体加支撑。工件—支撑反力相互抵消；着地时工件自身地面反力和支撑地面反力共同提供总地面需求，离地时则由支撑地面反力承担。Step5.1输出的是总地面需求，不在工件着地时预先扣除一个未知的工件地面力。

当前沿用objects模型，支撑自重默认不计；给定支撑质量／物体质量后，`--fixture-weight-ratio`可确定性加入支撑自重。不能凭支撑体积假定材料密度。
