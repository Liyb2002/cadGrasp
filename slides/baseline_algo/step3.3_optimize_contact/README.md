# Step 3.3：优化本轮接触区的尺寸

保持此前每块的实际几何不变，只调整 Step 3.2 本轮选中块的同中心半径。曲面裁切、连通性、整块法向夹角和净空沿用 Step 2；每次尺寸变化重新求整个组合的共同反力。

```text
efficiency(r) = 联合覆盖率(r) / (此前全部接触面积 + 当前接触面积(r))
```

每块接触的实际曲面面积必须严格大于物体总表面积的 **0.5%**：`A_contact(r) > 0.005 × A_object`。这里的分母是物体完整网格的总表面积，和 Step2 的 1% 初始目标使用同一基准。scheduler 排除初始面积不满足该条件的候选；不会自动扩大这些被排除的初始候选。

`area_limit.py` 用实际裁切曲面面积二分寻找半径下界，始终取满足严格不等式的一侧，不能用平面圆的 `πr²` 替代。随后只在面积下界与几何/插入上界之间优化；最终从输出三角形重新核验面积。`adjustment.json` 的 `area_constraint` 保存基准、门槛和半径区间。

在满足面积条件的尺寸中，只有效率提高才改变当前尺寸，否则保留原尺寸。第一轮分母就是这一块面积。后续轮次分母必须包含此前面积；否则“旧块已有的覆盖 / 趋近零的新块面积”会造成虚假的无限效率。

搜索不假设效率单峰或可导。对于 a ≤ r ≤ b，覆盖数和总接触面积随半径单调，因此：

```text
count(r) / A_total(r) ≤ count(b) / A_total(a)
```

`size_search.py` 据此细分上界最高的区间，记录最优已算尺寸、剩余效率上界和收敛间隙。当前默认相对间隙 0.1%。0.5% 面积下限防止接触退化成点；它没有引入接触压力上限或连接件强度约束。

每轮输出到 `output/<物体>/<pose>/step3.3_optimize_contact/round_001/` 等目录：`adjustment.json`、`state.json`、`adjusted_contact.npz`、包含所有固定接触的 `contacts.npz`、需求掩码、效率曲线和调整图。

Step 3 在本步完成后检查覆盖；选中时的 100% 不能跳过尺寸优化后的重新判断。

scheduler 还会在本步结束后按 `contacts.npz` 的实际几何更新插入方向，并在同一轮目录写入 `insertion_directions.json`。文件包含每块自己的方向集和代表插入向量，不求跨块交集。旧块尺寸固定，因此其几何签名相同的方向结果可以复用；本轮尺寸变化的块重新检查。

为了把实际结果交给 Step5，当前保持原来的效率目标，同时限制尺寸搜索保留当前块至少一个独立插入方向。`insertion_limit.py` 在原几何半径上限内，二分查找保守的可插入半径上限；方向未决视作未获证实。随后只在该范围内优化效率，并重新检查初始、最优与最大尺寸的实际方向。`insertion_constraint` 记录限幅区间和判据，不声称未决角度之外的全局尺寸最优。

最终方向仍由 scheduler 按实际几何重新生成；若数值检查仍无法保留当前块的独立方向，保存并停止为 `no_individual_insertion_direction_after_optimization`。Step2 初始面积预筛可能漏掉“缩小后才可行”的候选，这一问题仍待解决。

曲面面积一致性核对保留随坐标尺度和三角形周长变化的浮点误差界；0.5% 下限另作严格检查，不通过容差放宽门槛。

统一运行入口见 [Step 3 scheduler](../step3_scheculer/README.md)。

## 加工禁区约束

读取 Step2 保存的禁区，对实际接触头持续约束半径。初始头部必须先通过禁区检查；扩大遇到真实冲突或未决边界时，二分保留已证实通过的一侧，再与原有包裹角、物体／地面净空、独立插入方向约束共同确定半径上界。面积仍严格大于 0.5%，覆盖／总面积目标不变。

固定中心的裁切区域及固定顶点外移构造具有包含关系，因此缩小时可以复用较大已检查头部的分离结论。最终 initial、adjusted、maximum 三个输出状态均从实际三角面重新构造头部检查；不能将初始 Step2 的 `valid` 直接当成扩大后的资格。`adjustment.json` 保存 `work_volume_constraint`、几何限制原因以及各最终状态的禁区复核。
