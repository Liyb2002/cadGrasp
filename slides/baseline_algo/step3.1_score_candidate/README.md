# Step 3.1：计算本轮各候选的联合贡献

**所有头最终连接为一个刚体，允许局部下压，但每个输入的同一组反力必须满足 `sum(head_force_on_workpiece_z) >= 0`，不计物体脚底反力。** 这条整体约束与力、力矩平衡同时求解，不是每头分别限制，也不是先求解再筛选。[passive_supports.md](passive_supports.md) 保留先前独立支撑假设下的历史讨论。[Step 5](../step5_connect_support/README.md) 负责实际单体连接和完整承载、滑入检查。

每轮读取同一个物体的需求，以及此前 Step 3.3 固定的全部接触区。对每个尚未选中、Step 2 几何合格的候选，合并其真实曲面顶点反力列与已固定接触的反力列，再求六维共同平衡：

```text
G_(已固定接触 ∪ 候选 ∪ 原地面支点) λ_i = need_wrench[i], λ_i ≥ 0
sum(头部反力的 y 分量) - N_i = 0, N_i ≥ 0
covered = 本轮满足的需求数 / 本轮需求总数
```

排名前还必须通过纯重力（工作力为零）下的联合平衡检查，失败行标为 `rejected_rest_equilibrium`，不参与排名。`sample_coverage.npz` 分别保存 `insertion_eligible` 和最终 `eligible`，不将合法的部分覆盖与硬约束失败混为一谈。

第一轮已固定集合为空；后续各轮使用此前实际优化后的几何。每条需求重新分配全部反力，零单块贡献和零即时增益的候选都不预筛掉。已选编号与无效几何不重复评分。Step 3.1 保存整张贡献表，Step 3.2 才作出选择。

`joint_samples.py` 用完整非负 LP 的可行反力基批量证明其他需求可行，用经过检查的分离平面批量排除其他需求；未决需求继续求完整 LP。`wrench_cone.py` 保留独立求解与供给锥表示，用于核对和连续域反例搜索。

数值求解器返回未知状态时，会对同一组原始方程重试其他求解方式与正比例缩放。若仍未决，只在精确有理数分离面满足全部原始生成元点积非正、目标点积严格为正时判为不可行；否则报错。对偶约束缩放仅用于找到候选分离面，最后的证明仍逐项使用原始浮点值对应的精确有理数。评分定义、排名和碰撞容差不随回退改变。

初始需求为 Step 1 的 32,768 个随机样本。若 Step 3 找到可达、允许但未满足的连续域载荷，会把该反例明确加入后续轮次；原 `samples.json` 不变，新增载荷保存于 Step 3 的 `search_loads/`。此后搜索比例是这份扩展需求表上的完成比例，不冒充未经偏置的随机面积估计。

输出：`output/<物体>/<pose>/step3.1_score_candidate/round_001/` 等轮次目录，包含 `contributions.json/csv`、`sample_coverage.npz` 和状态。布尔矩阵同时保存 `eligible`，不参与本轮的行不能按零分候选解读。

统一运行入口见 [Step 3 scheduler](../step3_scheculer/README.md)。
