# Step2：200 个接触中心、接触圆与退出方向

本页描述当前 Z-up 实现；完整流程见 [baseline_algo.md](../baseline_algo.md)。输入为 Step1 的固定姿态与完整网格，本步不选择最终头、不造框架或底座。

## 当前筛选策略

`support_policy.py` 中 `ENFORCE_PROCESS_ACCESS=False`：不启用加工射线体积禁区，但接触面仍须避开真实工作面。`bearing_direction.py` 不再用竖直法向符号筛选候选，仅排除空或非有限法向。因此向上、水平、向下作用于工件的接触都可以成为候选；整体受力和共同插入在 Step3/5 验证。

加工可达射线示意、禁区分区代码属于可选工具，不是当前默认候选过滤流程。Step1 对工件遮挡的可达性检查仍然开启。

## 中心分配

`surface.py` 保留非工作面且 `z ≥ 1.5 mm` 的真实曲面，按共享边连通关系与外法向主方向（±X、±Y、±Z）分片。不连通的层和正反面分别计算真实表面积。

按每片面积配额分配总共 200 个中心；每片取理想配额的向下或向上整数，总数恰为 200。片内再按实际裁切面积递归分成等面积小格，每格取一个实际曲面点并保存源三角形。可见性、网格面数量和层间空间距离不决定点数；很小的片可能因有限配额没有中心。

## 接触圆与实体净空

以每个中心为球心，用球形邻域裁切曲面，只保留与中心沿真实共享边连通的部分。初始目标面积为物体完整表面积的 1%；按实际曲面面积拟合，不使用平面圆面积。面积不足或连通分量合并造成跳变时允许较小接触。

整块任意两处外法向夹角不超过 90°，超角则二分缩小同中心半径；不能删掉不合格面来拼圆。圆弧离散为 128 边形，目标面积相对容差为 `1e-4`。

随后按 `0.01 × 物体包围盒最长边` 的法向深度构造真实接触头，并检查物体、地面净空及头部外移。碰撞失败直接保留失败状态，不自动缩圆、换中心或补面积以挽救。

Step2 可保存面积不足 0.5% 的头；Step3 会按初始面积严格大于物体总面积 0.5% 再过滤。因此“Step2 几何合格”不等于“进入 Step3 排名”。

## 共享有限方向表

`insertion_directions.py` 调用 `withdrawal.py`。方向向量使用世界坐标，支撑沿 `+d` 退出，装入沿反向。所有候选使用同一份方向 ID 表。

方向表含 15° 方位、20° 仰角的离散方向，以及两极、工作面背向和候选法向/切向等方向。先排除向下穿地面和工作面面积加权外法向外侧的方向；切向允许。每个头依次检查：

1. 所有实际接触面的局部必要条件 `n_out · d ≥ 0`。
2. 有限厚度头实体沿该方向的完整连续退出扫掠，直到与工件包围盒分离。

实际凸单元的平移扫掠由初末顶点凸包表示，使用实体求交检查；浮点体积容差为 `1e-11 D³`。保存阻挡、未决和已验证方向，未决不当成通过。有限表耗尽不能证明整个球面或带旋转路径无解。

Step3 会维护已选头的方向交集；尺寸变化后重新计算实际头的方向。本步不保证尚未设计的框架和底座也能沿这些方向退出。

## 输出与运行

输出统一位于 `output/<物体>/<pose>/step2_local_support/`，包括原始中心、接触圆、资格/审计结果、实体几何以及 `insertion_directions.json`。非法候选和失败原因保留供核查。

从总入口重跑单案例：

```sh
python slides/baseline_algo/step3_scheculer/run_all.py B --pose pose_2 --from-step 2 --through-step 2
```

方向检查可按候选并行：`CADGRASP_DIRECTION_WORKERS=4`。工作进程不写输出，主进程保持候选顺序，每 10 个候选或 10 秒刷新进度，完成或异常时也刷新。`--force-directions` 强制重算，否则同输入可使用已验证缓存；两种计时不可混作从头运行。

中心配额、曲面包含、几何和方向均有独立检查。运行和计时选项见 [完整运行说明](../baseline_algo.md#运行)。
