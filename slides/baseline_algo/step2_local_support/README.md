## 按表面积分配点数

用户要求每单位真实表面积具有相同点密度，多层结构每层都计入面积，遮挡不减少配额。
旧方法的初始样本虽然按面积均匀抽取，随后三维聚类却把邻近层合并；三层等面积平板曾得到 0、100、0 个中心。

当前 `surface.py` 的做法：

1. 保留非工作面、`z >= 1.5 mm` 的实际曲面。工作面与地面带仍是已有的候选域限制。
2. 依据真实共享边连接关系和外法向的主方向（±X、±Y、±Z）划分表面片。
   不连通的层及正反面分开；这个分组只用于分配点数，不是支撑的接触形状，采样域仍保留各种朝向。拟合后的候选不再按竖直法向符号筛选。
3. 每片按 `q_i = 200 A_i / A_eligible` 分配点数。使用累计面积配额取整，总数恰好 200，
   每片得到 `floor(q_i)` 或 `ceil(q_i)`，误差小于 1 个点。面积是真实三维面积，不是投影面积。
4. 得到 n 个名额的表面片，递归按真实裁切面积分成 n 个等面积小格，每格选一个实际表面点。
   分割方向用于布置片内位置，不改变该片的点数。圆心保留源三角形索引，不取离开表面的空间平均点。

不使用可见性、射线遮挡、跨层距离或三角形数量决定配额。很小的表面片若配额不足 1，允许因取整没有中心；
没有承诺 200 个有限点命中任意微小区域。A1-f、B、C5 的零点小片合计分别占可撒点面积 0.213%、2.913%、3.783%。
片内等面积格的最大相对面积误差均小于 `6.1e-11`。这些小格只用于撒点，不作为接触支撑。

多层验证已通过：三层等面积分到 **67、66、67** 个点，五层分到 **40、40、40、40、40**。
层间距从边长的 `1e-6` 到 `1` 改变时，点数与各层的平面内分布保持一致；改变各层面积或网格疏密也经过测试。
完整回归共 14 项，另对三个物体的全部 600 个中心核对了原始表面包含、配额和实际面积。

## 每个中心的接触圆

圆仍以物体总表面积 1% 为目标，允许更小：曲面与以该中心为球心的球相交，保留含中心且沿真实共享边连续的部分。
使用真实曲面面积拟合半径，不用 `pi*r²` 代替；圆弧采用 128 边形，目标面积相对容差 `1e-4`。
连通区域不足目标，或连通分量合并使面积突然跳过目标时，保留较小的圆。

整块接触面任意两处外法向夹角必须 **≤90°**，包括不相邻的源面。
超角则二分缩小同中心半径，不能靠删个别面拼形状；恰好 90° 允许，点积容差 `1e-10`。
旧的 45° 内凹预筛不恢复。圆可以跨内凹角，但仍须满足上述整体角度限制。

最后检查整圆沿外法向伸出 `h = 1% × bounding box 最长边` 的完整体积，以及连续外移接触头的净空。
它们不能侵入物体或地面。碰撞失败不自动缩圆，也不换中心或从旁边补面积。
本步只判断候选接触头，不证明整根支撑连地或整件支撑可以插入。

## 加工禁区筛选

禁区在拟合候选之前计算一次，保存为本目录输出中的 `work_volume.json/npz`、`work_volume_audit.json`。它只依赖 Step1 的物体姿态、完整工作面、外力角度与可达性规则，不依赖已选支撑。

对每个初始圆检查完整接触边界和 `geometry.head_cell` 构造的实际连续外移头部。若包围整个头部的盒子与禁区分离，可直接证明其内部实体分离；盒子相交则逐实际凸单元检查，不能据包围盒否决。实体包含接触面，因此通过实体检查也涵盖整个接触界面，边界触碰同样禁止。

没有避开禁区就直接 `valid=false`；保留原始圆、中心、面积与碰撞见证，不通过缩小或删面挽救该候选。`work_volume_collision` 表示有实际可达碰撞见证，`work_volume_unresolved` 表示未能证明分离；两者都不进入评分。局部几何已经失败的候选不重复做禁区查询。

Step3.1 沿用 `valid` 过滤和原联合覆盖评分公式；3.3 使用同一 `LocalClearance`，扩大半径时仍不限制实际接触面朝向，最终按导出的接触三角面重建头部复核。Step4 设计各件底脚，Step5 对完整连接实体继续检查。同中心优化后可能可行、但初始圆不合格的候选，这一版直接排除。

`audit.py` 从导出的三角面独立重建头部并重放禁区检查。输入和算法哈希变化时旧资格失效；`--rebind` 只验证已经与当前输入一致的数据，Step1 变化后须重建 Step2。

## 加工可达禁区

\[
\mathcal V_{\mathrm{access}}=
\bigcup_{\substack{pt\in S_{\mathrm{work}},\ \|u\|=1\\
u\cdot n_{\mathrm{out}}(pt)\ge\cos30^\circ\\
\operatorname{reachable}(pt,u)}}
\{pt+s u:s\ge0\}.
\]

`pt` 是工作面的任意点，`u` 为推力反方向的外向单位作用线，`s` 是以米计的空间距离、无上界。`reachable` 使用 Step1 的同一数值规则：从 `pt + ray_offset*n_out` 沿 `u` 的完整半射线不得与物体网格相交；本批输入的 `ray_offset` 为 10 µm。力大小不决定射线长度。

这不是从旧无限锥中简单减掉物体实体。若射线被物体挡住，该射线对应的加工方向无效，物体背后的部分也不应继续保留。另一方面，删掉一条被遮挡的碰撞见证，不能证明其他射线也不与支撑相交。

### 表示与精度

`visibility.py` 在源工作三角面和方向集合上建立自适应分区。用局部方向斜率 `u ∝ n_out + slope_x*e1 + slope_y*e2` 表示 30° 锥，初始为 32 边外切多边形，随后在存在遮挡的部分细分方向。

对位于射线起始平面前方的物体三角面，其在源平面上的投影为 `xy - height*slope`：

- 方向分区顶点的所有投影的凸包覆盖该分区的可能遮挡区域。
- 当遮挡面的朝向符号在整个分区内一致时，各顶点投影的交集是由该面始终遮挡的源区域。
- 始终遮挡区域略作内缩后删除；可能遮挡区域略作外扩，其外部是已确认不受遮挡的源区域。剩余部分继续细分；未细分完的边界单独保存，不能标成已确认可达。

当前方向细分为完整锥 → 32 个扇区 → 每个扇区四个子三角形；归一化位置边界余量为 `1e-7D`，并将 Trimesh 射线检查接受起点后方 1 µm 内交点的规则纳入可能遮挡范围；`D` 是物体最大尺寸。已确认可达的源位置保持为连续多边形，使用约束三角剖分保留孔洞。每个方向分区尚未解析的源区域使用凸包覆盖，以限制细碎边界的数量；这个操作只扩大不确定部分，不会把它标成可达。线段、点状的源边界也被保留，因为它们沿方向锥延伸仍可能形成三维体积。裁剪与不确定凸包补入的累计参数测度另作记录，它们不是物理体积，也不作为净删除比例。

因此保存的是可达空间的**显式几何界限**：已确认不受遮挡的部分，以及仍需保守处理的过渡边界。方向外包络仍最多比圆锥径向多约 0.484%。这不是宣称已经精确解析了所有遮挡边界。

2026-09-11 全流程续跑时，C5/pose_2 的近重合边界触发 GEOS `TopologyException`。`--visibility-retry` 现在通过 `visibility_overlay_retry.py` 先启用已有的可能阴影并集恢复，再逐工作面处理：只有几何库发生叠加错误的面回退为“原始完整工作三角面 × 完整方向外包络”，明确标为未决，其余面继续原算法。这个回退扩大保守禁区，可能额外否决候选，但不会漏掉受影响面的加工作用线，也不把数值错误当作净空或真实碰撞证明。失败面索引、异常、未量化的额外外包范围和恢复代码哈希保存在 `work_volume.json`；仍须通过独立射线审计。旧恢复入口及其既有证据不改写。

### 下游的读取与验收

`WorkVolume.read()` 只加载保存的源片和方向分区，不重建可达性，也不依赖选中的接触或插入轨迹。Step2、3.3 与 Step5 查询整个有限厚度实体与这些无限射线族的相交：

- 与整个外界限分离，可接受为禁区避碰通过。
- 找到实际圆锥内、通过 Step1 可达性检查的交点，才记录真实可达作用线冲突；工作面起点的接触也需要可达方向见证。
- 只碰到过渡边界或圆锥外包络、没有找到真实可达交点时，记录 `visibility_or_envelope_unresolved`，不能判为通过，也不把被遮挡的射线写成碰撞证明。

边界接触仍禁止。工作体积仅约束支撑最终位置；完整插入扫掠、支撑间避碰和安装顺序仍由 Step5 检查。
