# 两操作 DSL：最近头合并，随后削减整头以释放退出空间

## 最新实验：先在所有头上释放共同退出空间

用户随后确认先单独检验退出空间优化。入口仍为 `merge_release.py`，使用 `--global-release --merge-trials 0`；这样先排除整体凸包合并制造的新阻挡，保留初始化的头，从整个集合中寻找可削减材料。原合并实验保留为对照，下面较早的合并接受条件不应误读为这一实验的局部削减条件。

每轮在已检查的世界 XYZ 方向中，选择各 pose 归一化阻挡体积的最大值最小的参考方向。对所有头计算与该方向下所有 pose 连续退出扫掠的交集，从这些阻挡区域的边界提出局部切除体。用真实 CSG 阻挡体积的数值差分决定是否有下降方向，回溯调整切除尺寸。损失为 `最大归一化阻挡体积 + 0.1 × 平均归一化阻挡体积`；平均项用来避免多个 pose 并列最坏时，改善其中一个却得不到下降信号。

每次候选重新验证剩余接触的全部载荷、模块连通、工作面、地面以及每个 pose 仍有退出方向；通过后提交真实几何，重新计算方向集合并选择下一轮参考方向。只有共同方向实际通过连续路径检查，才能报告共同退出成功。中途阻挡体积下降并不要求离散球面点的集中角度立即下降；集中角度和共同方向数量仍单独报告，不能用代理损失替代它们。

零切除和差分候选用同一布尔运算分解计算损失：固定头的阻挡，加上待削减头不与固定头重叠部分的阻挡。不能用不同运算树的历史体积作为差分基线，否则接触边界处的数值差异可能产生虚假的正梯度。

停止条件为找到共同方向，或预算内没有通过硬约束的下降候选，或达到步数预算。后一种失败只针对本次有限方向和切除体参数化，不证明所有合法削减都不存在。输出保留每轮参考方向、真实切除体、梯度、载荷检查和拒绝原因；最终仍构造完整 Step4，并测量 Step5。

参考方向并非永远固定在初始菜单：第 0、8、16 轮在当前可行方向和参考方向之间加入归一化插值方向，再用连续扫掠验证。最终用同一套细化后的方向重新检查初始化头，进行公平比较；细化采样单独找到旧几何原本就有的路径，不能计为削减的收益。

完整夹具的连通还要求每个保留头能接上支撑。当前保守版本从初始完整构造保存一个真实连接见证；削减不仅要保留头与连接体的连通，还不能切掉该连接端口的完整 5 mm 核心。最终构造优先尝试接近的退出方向，必要时尝试保留下来的原退出见证。保护一个原端口会限制可搜索的形状，不证明换端口后也无解；完整支撑的方向仍需另行报告。

实现中另外修正了两项数据问题：不再通过插入三角形重心重复细分未改变的接触三角形；不相交的切除盒不应把凸接触体分成多个无关片。历史退出检查接收的凸体缺少 `metadata` 时，在本实验内存中补空字典，不虚构来源面，不修改原 DSL 文件，也不绕过完整退出检查。

连通分量按有向体积为正的材料壳统计；有向体积为负的封闭空腔内壁不算另一块材料。回归测试同时覆盖保留孔洞、真实断开、连接端口损伤，以及未改变的三角形／凸体不应重复碎分。

`global_release_v7` 进一步按真实物理几何处理共享材料：初始化中已经相连／重叠的头直接归为同一物理模块，保留全部原接触关系；不能把这些实体仍计为互不相干的多个物理头。削减在完整物理头并集上计算损失，同一个切除体同步作用于所有模块和所有 pose 的接触。已删材料用 `原头实体并集 − 当前头实体并集` 定义，而不是把各标签的删除记录相加；后一种方式会把其他标签仍保留的材料误判为已删除。保留连接见证时也从原连续实体直接减去真实删除材料，避免拆开再拼回接触界面。

最新完整批次为 `global_release_v7`；前面的版本属于开发诊断，不能替代最新批次结论。初始化接触区域数与真实物理模块数分别报告，跨 pose 模块需列出各自实际接触的归属。

## 目标与边界

从 `DSL_algo/` 已有独立可行初始化出发，保留原物体 pose、真实表面和全部原始 32768 个力／力矩需求。不预设 +Z，不清空初始化重新搜索，不添加新接触中心。

目标是使每个 pose 的可行退出方向集合在**原 task 的世界 XYZ**中更集中／拥有共同方向，并将必要接触整合到少量紧凑实体头上。承载、shared no-uplift、实际接触、地面和装卸是硬约束。接触面积减少本身没有奖励。

一个模块有两个接触面，不等于同一接触面被两个 pose 使用。跨 pose 多面模块只有在各自实际使用时不干涉、能承载并能退出才有意义。物理模块数、接触区域数、跨 pose 模块数分别报告。

这两个操作的能力有边界：合并不会自动使两个接触面的位置重合；削减只能从现有接触中留下子集，可能改变剩余区域的重心，但不能把接触迁移到原区域之外。因此当前实验检验的是“已有接触能否整合成紧凑、多面实体，并释放共同退出空间”，不是已经解决“任意移动头的位置并保持承载”。

## 坐标与初始化

合并必须在明确的候选夹具坐标内做，不能直接比较不同物体坐标系的数字。初始化阶段使用原 DSL 的安装候选及平移修复，仅确定一次实际安装关系；随后固定各 pose 的安装变换，不通过分开摆放获得编辑收益。

初始化头及其原生退出见证来自 `independent_poses_cached_v17`，不是在新指定方向下重新搜索的头。历史安装变换只是未接受候选；必须重新检查当前头的地面及完整头并集退出。安装修复不移动接触区域在物体上的位置。若限定的安装初始化失败，如实报告，不改变物体 pose、载荷或放松约束。

本轮先在候选安装关系中研究两个操作。没有强制将不同 pose 的物体叠到一个姿态，也没有优化单个头的表面中心位置；后者如需实现，另开版本。

## 操作一：最近头合并

按不同物理模块的实际边界距离近似排序，稳定 ID 打破平局，使用确定性 greedy；不 sampling。

新增真实连接实体，形成 `C = A ∪ connection ∪ B`。首版用两模块实体的凸包作为粗连接／头体，允许明显增大；原接触区域、法向和位置保留，因此原力学可行解仍可使用。不能从这一点推导新增实体不会侵入物体、工作面、地面或退出通道。

这里的“保证力、力矩”严格指原接触模型不变时的可行解继承：旧解仍可在原接触上施力，新增接触无需施力，各 pose 分别继承自己的解。它不表示粗合并体已经可制造或可装卸，也不是材料强度或变形的证明。进入物体内部或遮挡接触的材料必须在削减后消除，才能接受实体。

合并的原始中间态可以挡路。必须先执行下面的削减，再评价整个“合并→削减”候选，不能因为未削减的中间态更差就立即拒绝。

接受的合并是真实几何并集的一个连通头，不是只改 ID。通常少一个模块；如果削减到全部接触消失，相应零面积删除另行记录，不能计入虚假跨 pose 复用。

## 操作二：削减完整合并头

允许删除整个 C 内的材料，包括 A、B 和新增连接体，而不是只缩小两端接触片。采用局部切除体的连续尺寸参数，实际做 CSG 差集；可以形成凹陷、孔洞以及明显的外形变化。

同样的切除体作用于真实接触三角形。接触面只能变成原表面的子集；删掉的孔洞不能被后续凸包／boundary fan 填回。零面积接触区域移除，旧 wrench 缓存清除，从剩余真实位置和法向重建生成元。

削减后的模块必须保持必要连通性。原初始化接触中心只是坐标参考，如果该点已被切掉，不能仍当成接触点或继续使用其旧承载数据。

## 梯度到底优化什么

首版对真实 CSG 参数使用数值差分梯度：计算当前头并集与各 pose 的**连续 500 mm 退出扫掠**的实际相交体积。以最坏 pose 的阻挡及最佳共同参考方向为连续优化信号；参考方向由当前退出集合读出，可以随几何更新，不是预设的退出约束。

梯度仅提出切除尺寸更新。相交体积减少不是通道已经打开的证明，更不等于承载通过。每次局部削减先验证全部原始载荷及连通性，失败则回溯。最终整个候选重新计算完整头并集的退出集合，才能决定接受。

使用有限三维方向评估点，加水平点和初始化见证；不是只检查 +Y/+Z。有限菜单未找到路径，不证明所有角度都不可能。差分步长、切除步长、回溯次数、方向预算和停止预算都写入运行报告，不把确定性缩面积或随机删除冒充梯度。

## 接受条件与紧凑度

最终候选必须满足：

1. 所有 pose 的全部原始力／力矩需求及 shared no-uplift。
2. 实际头模块连通，所有安装地面合法，工作面不被材料覆盖。
3. 每个 pose 对完整头并集均有经过连续检查的退出路径。
4. 退出方向集中程度不恶化，且方向集中、共同开口或模块紧凑度至少一项改善。

“紧凑”不能只看模块数。首版用 `模块数量 + 权重 × 各模块空间跨度的平方和`，跨度按初始化头的典型尺度归一化；单位、权重、实际跨度均报告。长杆串起两个远头可能降低计数却增大这个代价，不能自动接受。

首版的方向集中度定义为：在已检查的单位方向中选择参考方向 `d`，对每个 pose 的可行集合 `E_p` 求 `min(e∈E_p) acos(d·e)`，再选平均角度最小的参考方向；同时报告这些角度的最大值。平均角度和最大角度都不得变差，共同可行方向数量不得减少，紧凑代价也不得增加。至少平均角度、共同方向数量、紧凑代价之一严格改善才提交候选。空集合直接失败，不能靠角度平均掩盖某个 pose 已无退出路径。

这意味着承载是硬约束，方向集中与实体紧凑是改善目标，接触面积不是目标。“删除得越多越好”不成立；保留全部载荷所需的接触后，若进一步削减不能改善方向或紧凑度，就停止。最近的一对失败时继续检查下一对；本轮不采样，预算内全部失败则保留原可行状态，不强行合并。

这个代价是少量紧凑实体的代理，不是完整外观美观指标，也不是“同一接触面真的复用”的证明。原接触区域的分布不适合整合时，仅连接和削减可能无法解决；不能偷偷加入位置重搜。

## 第三阶段与完整成功

头编辑结束后使用原 DSL 的支撑／地面生长器，注入优化后的真实头实体，保留它们的接触及被切掉的几何。构造不能重新生成完整连接，恢复已删材料。

完整 Step4 仍检查全部头、新增支撑、工作面、地面、原地面需求覆盖、接触保持、闭合连通以及连续退出。力学使用修改后的接触重新 CPU 验证。只进行一次内存构造接受，不增加导出后几何接受重放；Step5 对接受的实际实体测量。

完整支撑新增材料可能缩小退出集合，因此头级共同方向不能直接冒充完整夹具的共同方向。最终重新在内存实体上读出方向，区分头级与完整夹具结果。

## 首轮诊断记录

`merge_release_pilot` 对 `B/pose5+7` 的小预算试跑已完成：两个合并候选、每个最多三步梯度，总运行时间约 16.40 秒。初始化和最终完整 Step4/Step5 构造成功，但两次合并均未接受，物理头数仍为 8，退出方向集中度没有改善。这只证明本组原可行方案被保留，不能算合并优化成功，更不是 B 全部 pose set 的结果。

这一诊断随后发现有连通计数错误：封闭孔洞的负体积内壁被误计为独立实体。因此部分“继续削减会断开”的拒绝不能作为真实断裂的证据。该错误已修正并加入回归测试；本段仅保留开发历史，最终成效以 `global_release_v7` 完整批次为准。阻挡体积下降仍不能替代真实退出或完整夹具接受。
