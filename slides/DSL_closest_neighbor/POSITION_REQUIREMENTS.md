# DSL：从初始化头出发，联合优化头位置与退出路径

本目录重新建立，用于讨论和实现当前需求。此前同名目录已删除，未找到 Git 跟踪文件或可恢复副本；本次没有恢复旧代码、视频或实验结果。`DSL_algo/` 保留原样，作为初始化及已验证算法的参考。

本文件是当前需求定义，不是已经实现或验证成功的算法说明。

## 1. 三个阶段，顺序不能混淆

### 第一阶段：已有可行初始化

每个 pose 已有一组头：物体表面上的真实接触区域、接触位置、法向，以及自己的可行退出路径或方向集合。

复用 `DSL_algo/` 的有效初始化及原始物体、pose、32768 个载荷数据。检查数据版本与来源，不重新生成 pose 或载荷。初始化只证明各 pose 的独立接触与退出可行，不自动证明所有头已经组成一个完整可行夹具。

### 第二阶段：联合优化退出路径和头在物体上的位置

**必须真的挪动物体表面上的头。** 在物体上画出的接触色块应随优化改变，而不是只把整组头在共享夹具坐标里平移或旋转。

从初始化或当前已接受状态出发，对现有头做局部、连续的表面位置编辑，同时评估／优化各 pose 的退出路径。物体 pose 保持固定，方向都在原 task 的世界 XYZ 中表达。

要求已接受的每一步仍满足原来的承载要求，并保有该阶段检查范围内的可行退出路径。允许内部生成不可行试探，失败则回溯，不能把它们作为新的可行状态。

**不接受以下替代实现：**

- 先指定一个方向，再从整套候选库重新搜索头。
- 清空初始化头后从零搜索，声称是已有头的局部优化。
- 只调整整组安装位置，声称头在物体表面移动了。
- 仅修改接触 ID、力学权重、法向或位置数字，没有生成相应真实接触几何。

### 第三阶段：把优化后的头放到一个共同夹具中

第二阶段得到更一致的世界退出路径和相应接触设计后，才处理各 pose 的安装变换、实际头实体、连接、接地及完整支撑构造。

不能为了提前把各个物体叠到同一个参考 pose，限制或替代第二阶段的头位置优化。第三阶段可以借鉴原 DSL 的安装与构造方法，但必须保持物体和其对应头的接触关系，并重新检查全部实体的干涉与退出。

最终必须检查完整支撑，包括当前 pose 不使用的头、连接和地面结构。第二阶段自己的头能退出，不意味着第三阶段新增材料不会挡路。第三阶段失败要单独记录，不能倒称第二阶段从未优化过，也不能称已经得到完整可行夹具。

## 2. 第二阶段的状态与可编辑变量

每个 pose 的子程序包含：

- 固定的物体 pose、质心、原始力／力矩需求、地面与工作面定义。
- 初始化头的身份，以及当前位于真实物体表面上的接触区域。
- 头中心或表面锚点的位置、对应 source face、实际接触三角形及法向。
- 当前可行退出路径／方向集合及通过验证的路径见证。

首版将头数和目标接触面积保持在初始化水平，优先研究位置变化本身。曲面上挪动时重新生成对应位置的真实贴合区域；曲率变化产生的法向、接触三角形和力矩变化必须进入计算。调面积、添加或删除头如需引入，另行明确，不能偷偷作为重新搜索的 fallback。

表面位置可以用当前三角形上的重心坐标、跨相邻面更新等局部参数化表达。跨面时仍要留在真实、允许接触的表面上；不能在空间中线性插值出虚构接触点或法向。具体参数化尚待设计。

## 3. 挪动后如何保持力与力矩要求

位置改变本身没有承载不变的保证。对新接触点 `p`、真实法向产生的接触力 `f`，力矩重新计算为：

```text
tau = (p - center_of_mass) × f
```

每个候选从真实新接触几何重建全部力／力矩生成元，清除旧位置的 wrench 缓存。验证原来的全部 32768 个需求，以及原有 shared no-uplift／向下合力约束；保留原力学模型和数值容差，不增补、删减或重采样载荷。

接受规则是“真实几何变化 + 原约束通过 + 目标改善”。可用可行性余量、活动约束或优化梯度生成移动建议，但不能以代理分数代替完整承载检查。步长过大则回溯减小；没有有效局部移动时保留旧解并明确报告停止原因，不能转而清空头重搜。

这里要求每个被提交的离散状态可行。若要进一步声称整个连续编辑轨迹都可行，需要另外给出沿编辑轨迹的检查或证明；仅检查两个端点不能支持该结论。

## 4. 优化目标

主要目标是使各 pose 的退出方向集合更容易拥有共同的**世界 XYZ**方向，同时保持承载与退出可行。

- 共同方向尚不存在：优化集合之间的距离／共同方向的阻挡余量，使它们靠近。
- 共同方向已存在：扩大共同可行区域或提高退出净空，避免只有极窄的一条通道。
- 面积、头数及最终支撑体积不是第一阶段目标的替代量；不能因为删了面积就声称退出更统一。

退出路径与头位置必须在同一状态上联合评价。方向可以作为联合优化变量，也可以从当前几何的可行集合中读出；具体实现尚待设计。无论采用哪一种，不能退化成“外层方向枚举、内层独立从零搜头”。

可行集合、布尔碰撞及 LP 可行性本身不提供稳定梯度。任何光滑代理都必须说明作用范围，并由真实接触、原载荷和连续退出检查把关。有限方向未发现共同路径，不是全方向不存在的证明。

## 5. 提交与验证范围

```text
复用初始化
    ↓
提出已有头在物体表面的局部移动 + 相应路径调整
    ↓
生成真实接触几何，重算力／力矩与路径
    ↓
所有受影响 pose 满足原约束、统一目标改善？
    是：联合提交；否：回溯，保留原可行状态
    ↓
局部优化结束后，处理共享夹具安装、连接和接地
    ↓
完整 Step4 构造接受，再做 Step5 实际体积测量
```

报告要分开列出：独立初始化成功、接触位置优化成功、共同路径见证、完整支撑构造成功和实际体积改善。不得将其中一项代替其他项。

保留原 DSL 的单次构造接受策略，不额外增加导出后几何接受重放。代码未实现前，不记录虚构的试跑或成功率。
