# 历史 dock 方案的求解对象：区域、实体与装入方向

2026-09-23：当前主线已改为 [一体支撑的多姿态共同设计](multipose_rigid_fixture_design.md)。[当前参数表](../../slides/params/README.md) 已明确 A_obj^k、A_floor^k、共享 V 与 d_k，k 遍历全部任务；两个分镜仅为例子。终态无体积穿透和物体相对固定 V 的有限装入扫掠分别检查。支撑摆放的自由度与几何参数化仍待算法推导。下文为 2026-09-21 双实体及组合 docking 模型的历史记录，不是新方案的参数表，旧扫掠和共同搬运假设不得直接套用。

2026-09-21 用户确认的历史定义如下；当时的 params 四栏图已经被上述新定义替换。Parameters 指最终求解对象，不是节点数、杆粗或搜索预算。

\[
(A_{\rm obj},A_{\rm floor},V_{\rm support},V_{\rm base},d_0,d_1,\ldots,d_K).
\]

| 对象 | 含义 |
|---|---|
| A_obj | 跨任务共享的工件接触区域：位置、形状、范围。 |
| A_floor | 同一个公共底座的实际接地区域。 |
| V_support | 实现工件接触区域并连接标准插头的蓝色实体。 |
| V_base | 实现接地区域并连接全部插座的固定底座。 |
| d_0 | 蓝块相对固定物体的初次直线装入方向。 |
| d_1, ..., d_K | 各任务姿态下，工件与蓝块组合相对底座的直线装入方向。 |

**操作运动决定哪里必须留空，支撑要求决定哪里需要结构。** 两条装入约束是：

\[
\operatorname{Sweep}(V_{\rm support},d_0)\cap\operatorname{int}(\mathrm{Obj})=\varnothing,
\]

\[
\operatorname{Sweep}(V_{\rm support}\cup\mathrm{Obj},d_k)\cap\operatorname{int}(V_{\rm base})=\varnothing.
\]

Sweep 使用实际装入的有限行程，方向指向落座终点；允许表面接触，不允许实体穿透。第二式使用对应任务姿态，并检查整个底座，包括闲置插座。标准接口固定时，d_k 必须符合相应配合轴。

任务几何、姿态、工作区和载荷是要求；共享接触、接地区域与两个实体须满足各任务的支撑、连通和工作区避让条件。初始物体摆放可配合初次装入方向选择。机器人能够抓起并保持组合体作为假设，关节轨迹、逆运动学和一般机器人避碰不作为本篇的求解对象。

具体怎样表示接触区域和连接实体仍是下一层算法问题，尚未选定参数化。现有 [15 秒视频](../../slides/belt_test/shared_workflow.mp4) 保留为流程动画，不改变上述研究范围。
