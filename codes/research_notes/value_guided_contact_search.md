# Value network 引导的接触组合搜索

2026-09-23 状态：论文主线已选择 [一体支撑的多姿态共同设计](multipose_rigid_fixture_design.md)。本文件保留已讨论的单姿态选头方案，尚未实现；它是候选求解工具，不自动成为新方案核心方法。先明确跨姿态共享的变量、约束及计算瓶颈，再决定如何使用学习。本次不启动训练或修改 baseline。

2026-09-22 用户确认研究方向：在多个不同 shape 上做昂贵搜索，学习部分接触组合的后续完成价值；运行时由 value network 指导多个候选分支。外层选择接触中心，内层共同调整全部已选头的尺寸。本文件记录方案，尚未实现网络、生成训练集或运行对照实验。

当前 [baseline](../../slides/baseline_algo/baseline_algo.md) 的十条 top5 搜索保留作对照。本文不改变当前初次安装、任务对接、接触模型或验收条件；第一阶段仍研究单 pose 的找头问题。网络结构和搜索宽度是拟用起点，不是实验确定的配置。

## 1. 要学的是后续完成价值

搜索选头深度最多为 3，但候选多，且每次联合受力、几何检查和尺寸优化昂贵。只比较当前增加多少覆盖，不能表达接触之间的后续互补性。

例如已有 A，还能加两个头。评价候选 B 时，希望知道：加入 B 后，剩余候选中是否容易找到合适的 C，并通过整组尺寸调整获得合法头组。这个价值依赖 A、B、剩余候选、需求、几何条件和计算预算，不是 B 自身的固定贡献。

用 `V(s, k, budget)` 表示当前状态 s 在剩余 k 个加头名额、给定后续计算预算下的完成价值估计；`Q(s, i; k, budget)` 表示当前选择候选 i 后的估计。实现可直接为所有候选输出 Q，不必分别训练 policy、value 两套网络。

价值标签来自指定后续搜索器在给定预算内的实际结果，不代表已知全局最优值，也不等于对“存在任意可行补全”的证明。第一版以 Step3 连续验证通过为完成目标；Step5–6 的完整设计结果另列，不把头部成功标成整件成功。

## 2. 无序头组与可调整尺寸

最终接触设计是无序集合：相同实际几何的 `{A,B,C}` 与 `{B,A,C}` 是同一个设计，不把选择排列当作不同物理解。仍可通过逐次加入中心构造这个集合。

第一版外层动作从现有约 200 个候选中心中选一个未选中心；已选中心固定，不在本轮引入连续移动中心或任意曲面区域生成。

每次加头后，内层固定中心，轮流调整全部已选头的半径：固定其他头调一个，再轮流更新。旧头可以随新头加入而改变大小。“共同优化”表示评价和调整整组，不要求所有半径同时更新，也不保证找到全局最优尺寸。

```text
当前头集合及实际尺寸
    → 网络提出若干接触中心
    → 各分支加入对应中心
    → 轮流优化全部已选头的半径
    → 联合受力、几何与共同方向检查
    → 保留多个不同状态，继续扩展
```

状态必须包括实际尺寸、共同方向、剩余名额、载荷／反例和验证状态。相同中心集合可能因局部尺寸优化得到不同几何，不能只按中心 ID 去重。相同几何若预算、反例或验证上下文不同，也不能直接复用其完成价值。局部优化路径不同可能得到不同结果，这不改变最终设计的无序性。

本次没有决定取消 baseline 的逐轮纯重力、整体不上抬或连接构造筛选。首个同规则对照应保留这些条件；若以后允许仅完整组合满足、而中间前缀不满足，须单独定义变体。无序表示不会自动恢复被前缀规则排除的组合。

## 3. 跨 shape 的统一表示

训练使用不同 shape、姿态和任务，但统一编码需求集合与候选供给集合。共享表示使同一个网络可用于不同实例，不意味着不同 shape 的可行域相同，也不自动保证泛化。

| 输入 | 需要保留的信息 |
|---|---|
| 需求集合 | 配对的力与力矩、代表载荷及已发现的困难载荷；不能把六个分量独立打乱 |
| 每个候选头 | 区域内多个点的法向与力臂，以及真实面积、尺寸和必要局部几何信息 |
| 尺寸变化 | 若干代表半径下的供给与方向信息，表达该中心的一族可能接触区域 |
| 当前头组 | 已选标记、实际半径和实际供给几何 |
| 剩余候选池 | 全部候选的表示及状态；评价 B 时必须看得到可能与它互补的 C |
| 任务与约束 | 原地面支点、接触模型参数、初始安装与任务坐标关系、共同方向及连接／碰撞条件 |
| 搜索状态 | 剩余头数、预算和验证状态；尚未检查不能编码成已通过 |

需求力按 mg、力矩按 mgD 归一化，位置和半径按特征长度 D 归一化；供给生成元的力臂也使用相容尺度。需求、供给、地面及方向必须采用明确且一致的坐标约定。

“供给集合”表示真实接触的反力生成能力，不是各头单独通过的载荷掩码；组合受力仍须合并生成元联合求解。几何碰撞、有限厚度连接与装入条件不能仅由六维力旋量集合恢复，需额外编码并由几何验证器检查。

代表尺寸只是网络输入摘要，实际半径优化仍为连续搜索；平均法向和初始面积不足以替代区域供给。代表载荷压缩可能漏掉关键需求，不能替代最终全量与连续验证。

## 4. 拟用的小型集合网络

优先复用 Deep Sets／Set Transformer，不把新网络架构作为论文主要贡献。初始配置如下，宽度与层数尚待实验：

| 模块 | 拟用起点 |
|---|---|
| 每个代表尺寸的供给点编码 | 共享两层 MLP＋集合池化，再融合该头的多个尺寸特征 |
| 需求编码 | 共享小 MLP 与集合聚合，使用代表载荷并纳入已发现的困难载荷 |
| 候选特征宽度 | 128 |
| 集合交互 | 两个注意力模块、每个 4 个 attention heads；候选之间交互，并结合需求与当前状态 |
| 候选价值输出 | 共享两层 MLP，每个未选候选输出一个 Q 分数 |

```text
需求集合 ─────────→ 需求编码 ───────────┐
                                      │
候选头的多尺寸供给 → 共享头编码 → 集合交互 → 各候选 Q
                                      │
已选标记、实际尺寸、地面／方向与剩余预算 ──┘
```

一次前向计算输出整个候选池的分数，不必对约 200 个候选各自运行一遍完整网络。多个候选可以同时有高价值，不要求用 softmax 将它们解释成互斥的正确答案；若将分数解释为成功概率，需明确固定的后续搜索器／预算并检验校准。

不使用候选编号的序列位置编码，各候选共享编码和输出层。交换候选顺序，分数随对应候选一起交换；已选集合的表示不依赖输入排列。真实空间位置、半径与法向仍作为物理特征保留。两个 attention 模块是试验起点，不由“三个头”推导得到；增加深度不能补回输入中丢失的尺寸和互补信息。

## 5. 昂贵搜索产生训练数据

1. 在多个 shape、姿态和任务上进行比运行阶段更充分的搜索，保存部分状态及候选扩展。
2. 对选定扩展继续补全，并在每次加头后共同调整尺寸；记录后续搜索器、随机种子、计算预算、最终几何与验证结果。
3. 用搜索实际得到的后续结果监督候选价值。只模仿 baseline 的 top5 选择会继承其偏好，需主动收集 top5 外和失败分支。
4. 已找到认证补全是明确的成功证据；预算耗尽、数值未决、几何构造失败分别记录。未找到补全不能当作不存在补全的证明；某一具体完整组合失败也不能证明该部分状态的全部后续失败。

可以学习固定预算下的搜索成功事件，或基于可比较后续结果的排序；具体损失、重复补全次数和未决样本处理尚待确定。昂贵标签成本并未消失，而是放在训练阶段并期望在后续实例上摊薄，需单独报告。

训练／验证／测试按 shape 划分，同一 shape 的不同 pose 或近重复形状不能分散到两侧造成泄漏。需要在未见 shape 上验证泛化，不能以训练实例的大量中间状态数代替独立 shape 数。

## 6. 运行时仍保留多个分支

网络在昂贵的全候选联合评价之前排序；只替换现有完整评分之后的抽选，不能省去主要评分成本。便宜的确定性筛选仍可先做，真正扩展的分支继续执行原有物理与几何检查。

用有限宽度 beam search 或其他已有多分支方法，保留若干不同的部分组合，并留少量探索名额。预测低分只改变优先级，不作为物理不可行证明。已检查相同状态的结果尽量复用；网络误判时，多分支和探索为其他补全保留机会。

例如已有 A、还能加两个头时，一次网络计算估计各个 B 的后续价值，只对少量高价值及探索分支真正搜索 C、联合调尺寸和验证。这样避免对所有 B、C 组合执行昂贵评价；节省量与漏解风险由实验决定。beam 宽度、探索比例、候选数和预算尚未确定，不将讨论中的示例数字作为正式默认值。

## 7. 可导性与实验边界

外层选中心是离散动作，内层是连续半径优化。网络参数可通过监督损失反向传播，但不要求梯度穿过曲面裁切、碰撞、LP、尺寸搜索或连续验证器；本方案不要求端到端可导，也没有选定 PPO 或 AlphaGo 式自博弈训练。

覆盖数量是跳变计数，几何和方向资格也可能突变。现有局部代理／面积割线用于提出尺寸，完整检查决定接受，不是原始设计问题的精确梯度。是否替换尺寸优化器是独立问题，本次先复用它。

首轮比较当前 top5 十链、无学习的多分支前瞻搜索，以及相同搜索框架下的 value 引导版本。使用相同输入、物理规则和验证器，比较相同墙钟预算下的 Step3 连续认证成功率、首次成功时间及昂贵评价次数；训练和数据生成成本另列。完整支撑通过率单独报告。只有更高预测准确率或更高样本覆盖率不足以说明搜索改进。

## 方法来源

以下为可直接借用的方法依据，不表示已有 cadGrasp 训练结果，也不据此主张新颖性：

- [Zaheer 等，Deep Sets，NeurIPS 2017](https://papers.nips.cc/paper/2017/hash/f22e4747da1aa27e363d86d40ff442fe-Abstract.html)：集合编码与排列不变性。

- [Gasse 等，Exact Combinatorial Optimization with Graph Convolutional Neural Networks，NeurIPS 2019](https://arxiv.org/abs/1906.01629)：学习搜索中的分支选择，同时保留求解器验证。
